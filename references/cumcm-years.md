## 二、A / B / C 的定位与风格差异

- **A 题（机理工程派）**：连续系统、物理/工程第一性原理，靠微分方程、静力学、几何/天文/逆问题等"吃功夫"的机理模型取胜。重推导深度、物理量纲、数值一致性。难度最高、决定性强。
- **B 题（应用决策派）**：离散优化/策略调度/几何定位，常扣社会热点。重"把规则形式化 + 算法可复现 + 方案可落地"。
- **C 题（数据应用派）**：数据密集型，统计/机器学习/评价+优化闭环。上手快但不易高分；重数据预处理、可解释性、业务闭环。

## 三、十二年高分共性（照着做）

1. **机理 / 指标先行，算法为辅**：先用第一性原理或指标体系把问题说透，再选算法；忌"算法罗列＋黑箱调用"。
2. **数值求解 + 误差/灵敏度/稳定性分析是国一标配**：参数摄动 ±5%/±10%、误差区间、多工况对比、交叉验证。
3. **结果自校验**：把结果对照已知量（真实轨道 / 模板几何 / 真实日期地点 / 基准方法）证明可信。
4. **每问一条完整链**：问题 → 模型 → 求解 → 结果 → 检验，结论回应题目每一问。
5. **可落地可执行**：优化题给具体方案/时间表，决策题给可操作建议，而不是只给一个数。
6. **规范**：摘要四要素含数值、符号表、三线表、高分辨率图、GB/T 7714 参考文献。

## 四、高频失分点（红线）

- 假设不切题 / 不自洽，堆砌无理由。
- 公式只抄不推导；不问就套 AHP/TOPSIS/智能算法，缺可解释性。
- 目标函数漏成本/约束项（损耗、风险、不确定性）。
- 只做描述性统计不做建模预测；预测与优化脱节。
- 无灵敏度 / 误差 / 交叉验证（硬伤）。
- 单位 / 量纲错误；结果与附录代码数据对不上、不可复现。

## 五、选题与备战建议

- 喜欢硬核物理/数学推导 → **A 题**；喜欢策略/调度/规则建模 → **B 题**；喜欢数据分析/机器学习/业务 → **C 题**。
- 赛前把 `model-recipes.md` 八大题型配方各写一份可运行的 Python 模板，实战直接套。
- 近三年真题每题精读一篇国一论文，重点学「摘要怎么写、灵敏度分析怎么做、图怎么画」。
