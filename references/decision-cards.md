# 决策卡片制：一次一张卡，边做边教，一小问一小问推进

> 定位：这是「强制确认门禁」的**交互执行规范**。把"给多个方案"从"一下子抛一堆选择题"改成**一次一张决策卡片**——每一步只让用户做一个决定，讲清这个决定是什么、为什么、选了会怎样。宗旨三件事：**不让 AI 失控**（每步都停在你确认之后）、**一边做一边教会**（每个决策都解释给你听）、**不让你到后面不知道 AI 在干嘛**（进度永远可预期）。

## 一、核心原则（四条）

1. **一次一张卡**：任何时刻只抛出一张决策卡片、只问一个要决定的事。严禁一次放出一批选择题让用户"挨个选"。
2. **一小问一小问**：严格按题目小问顺序推进。第 1 问完整做完（方法→建模→求解→检验→确认结论）才进第 2 问；**绝不提前抛出后面小问的决策**——你的思路没捋到那，AI 不许先跑。
3. **先讲方法，再定方案，再求解**：每问开始，先给 3–4 个**都很好的候选方法**并讲清各自优劣，你选定大致方案、确认"我明白了"之后，才开始这一问的求解。
4. **边做边教**：每个决策卡后附一句"为什么这么推荐 / 为什么排除其他"，让你始终知道 AI 在干嘛、为什么这么干。

## 二、卡片标准格式（每张卡长这样）

```
📇 决策卡片 N/总 · 环节：模型选型 · 第 1 问
────────────────────────────
【要决定的事】第 1 问用什么方法预测供货量？

【候选方案】
 A. 灰色 GM(1,1) —— 数据量小时稳定，趋势捕捉好；缺点：对波动不敏感
 B. ARIMA        —— 经典时间序列，可给预测区间；缺点：需数据平稳化
 C. 随机森林     —— 能吃多特征，非线性强；缺点：需较多数据、解释性弱
 D. 组合（A+B 加权）—— 稳健，可对比择优；缺点：工作量略增

【我的建议】B（ARIMA）——数据 48 周足够、能直接给 95% 区间，命中题意。

【你选哪个？】A / B / C / D / 或说"再讲讲 B 和 D 的区别"
────────────────────────────
```

- 一次只有"一个要决定的事"；候选 3–4 个（用户反馈偏好三四个都很好的，别只给 2 个凑数）。
- 每选项三行内讲清：**它是什么 + 优点 + 缺点/代价**。
- 【我的建议】必须有——这是"边做边教"，也是替你把关，但最终由你拍板。

## 三、三种用户回应怎么处理

| 用户说 | 你怎么办 |
|---|---|
| "选 B" / "B" | 复述确认（"好，第 1 问用 ARIMA，给预测区间"）→ 写进 `decision_log.py` → 进入该问求解；求解完给「一句话验收 + 关键数字」→ 确认明白后进下一问 |
| "再讲讲 B 和 D 的区别" | 展开这两项：各自适用数据量、能否给区间、实现成本、在哪类题翻过车——直到用户能拍板，**不要催** |
| "都不太满意" / "还有没有别的" | 补 2 个新候选（不同原理），重新出卡；**不替用户硬选** |

## 四、按小问推进的节奏（每问一个闭环）

```
第 N 问：
  1. 方法卡 —— 3–4 个候选方法，讲优劣，用户选（决策卡）
  2. 求解   —— 建模 + 代码 + 结果数值（关键中间结果汇报）
  3. 检验卡 —— sanity check 结果 + 该问必做检验（决策卡：是否补灵敏度/换算法互验）
  4. 结论卡 —— "一句话验收 + 关键数字"，问"这问清楚了吗？进下一问吗？"
  5. 用户确认后 → 进入第 N+1 问（重新从方法卡开始）
```

- **卡与卡之间不跳步**：第 N 问没确认，绝不开始第 N+1 问，更不提前抛第 N+1 问的决策。
- 每张卡决策后同步写 `decision_log.py`（谁/选了啥/为什么/取舍/风险）——既是"留痕"，也是给论文「设计意图」和 AI 报告攒素材。

## 五、PDF 题面读取（拿到题先做这个）

拿到 PDF 题面（或附件 PDF）先跑 `scripts/pdf_extract.py` 全文提取到 txt，**逐页完整读取后再拆问**——禁止只看一页或凭印象答题：

```bash
python scripts/pdf_extract.py 题目.pdf --out 题目.txt   # 全文提取，AI 读这个
```

- 提取结果含逐页标记与完整性报告；若报"空页"（扫描件/纯图片），用视觉/OCR 读取，**勿遗漏**。
- 读完后按题面实际小问结构拆问，再按本文件第四节逐问推进。

## 六、与「紧急模式」的衔接

紧急模式（`emergency_run.py`，用户显式点名才触发）下：门禁降级为"自主决策 + 决策留痕"，但**卡片仍在**——只是 AI 代替用户快速选卡（每张卡仍写 `decision_log.py`），并在每阶段结束给"一句话验收"。节奏加快、确认不消失。详见 `references/emergency-mode.md`。

## 七、红线

- **绝不一键生成全部成果**：即使"全自动/直接完成"，也只解锁连续执行，不解锁自主决策（见 SKILL 门禁）。
- **绝不一次抛多张卡**：用户没说要赶进度，就别用"这里有三件事要你定"堆过来。
- **绝不跳过"确认明白"**：用户说"行，继续"≠ 用户懂了；方法卡阶段要确认"我明白了"再求解。
