# 降 AI 味 / 降重改写对照库（脚本命中后，照这一页逐条改）

> 定位：`writing-deai-dedup.md` 讲「原则与清单」，本文件给**可直接套用的改写**——`dedup_scan.py` 报出哪句命中，就到这里找对应句式换掉。原则只有一条：**空泛→具体带数字，套话→删，长句→拆**。

## 一、问题重述转述三步法（降重的头号战场）

题目原文是最容易被查重的文字，重述必须「不像原句」。三步：

1. **压缩**：题干一段话 → 只留「已知条件 + 目标 + 约束」三个量，其余背景句全删。
2. **符号化**：把文字描述改写成符号/变量，例如"每天消耗水 a 升、食物 b 千克" → `消耗 c=4kg/天`。
3. **换视角**：把题目的叙事顺序换成"我的求解视角"，例如题干按"背景→现实→要求"写，你按"输入→模型→输出"写。

> ❌ 照抄式：`某地区有 402 家供应商为其供货，近半年有部分供应商出现断供，现需预测未来 24 周的供货能力。`
> ✅ 转述式：`输入为 402 家供应商近 48 周供货记录；剔除 37 家近半年断供商家后，目标是给出未来 24 周供货量的 95% 分位区间。`
> （变化：补具体数字、把"部分"落实为 37 家、把"预测供货能力"换成本模型术语"95% 分位区间"。）

## 二、标准定义 / 公共算法转写（避免与教材/范文撞字）

GM(1,1)、熵权法、AHP 等公共方法的**步骤文字**最易与网上范文重复。固定转写套路：**先给公式，再用自己的符号体系复述一句"它算什么"**，不整段抄"标准步骤"。

> ✅ 熵权法：`信息量越大权重越大。对第 j 项指标，先归一化算比重 p_ij，再算熵 e_j=−kΣ p_ij ln p_ij，权重 w_j=(1−e_j)/Σ(1−e_j)。` ——公式 + 一句机理，两行讲完，不复制教材的"第一步…第二步…"。

## 三、改写对照库（Top 20，按类查）

### A. 套娃连接词（先砍这一批）

| ❌ 原句 | ✅ 改写 |
|---|---|
| 首先…其次…最后… | 按「问题→方法→结果」平铺；或改动作编号"第一步拟合、第二步校验" |
| 综上所述 | 删掉，直接给结论数字 |
| 值得注意的是 | 删；真的转折才写"但需注意：交叉验证 R² 仍为负" |
| 与此同时 | 删或换"同时"，别成段连用 |
| 换句话说 / 换言之 | 删（重复即冗余），或换成更短的"即" |

### B. 空话句（零信息，最该删）

| ❌ 原句 | ✅ 改写 |
|---|---|
| 具有重要的理论意义和实践价值 | 删；或"它给 Q3 定价方案提供了弹性系数 b=−0.83" |
| 发挥着重要作用 | 删；或"亮度与负载交互项 p<0.05，是主影响因子" |
| 不可或缺 / 至关重要 | 换成"结论对 X 最敏感：±10% 摄动下变化 15%" |
| 日益重要 / 越来越重要 | 给趋势数字："该指标在 2021–2025 权重从 0.12 升到 0.31" |
| 提供了有力支撑 | 换成"据此，7 月补货量定为 1.2 吨" |

### C. 政论腔 / 模板句式（评委一眼识破）

| ❌ 原句 | ✅ 改写 |
|---|---|
| 随着…的发展 | 换具体时间+事件："2021–2024 平台交易额从 80 亿增至 210 亿后…" |
| 在…背景下 | 删，直接写问题："选考地理人数下降 23%，师资缺口凸显" |
| 本文建立了…模型，采用了…方法 | 换成"把…建模为…，用…求…" |
| 科学合理 / 切实可行 / 行之有效 | 换成"回测误差 6.2%、±10% 摄动下结论稳定" |
| 本文首先…其次…最后（摘要） | 按四要素平铺，每句带数字 |
| 进行了…分析 / 做出…贡献 | 换成"回归/聚类/分解……得到……"具体动词 + 结果 |

### D. 模糊词（给到数字或范围）

| ❌ 原句 | ✅ 改写 |
|---|---|
| 大约 / 大概 | "约 6%" → "6.2%"；"大概 6%" → "6.2%（±0.4）" |
| 较为 / 比较 | "较为接近" → "偏差 <3%"；否则删 |
| 一定程度上 | 删，或"在 ±10% 内成立" |
| 初步 | "初步结果" → "10 次重跑均值，std=0.03" |

## 四、句群功能重组 + 段落类型分支（打断连续重复的硬招）

换近义词只能破"词级"重复，连续字符匹配要破"句级"重复——靠**重组句子功能顺序**。记一个动作链：**先保存信息，再改变信息之间的连接方式**。

**通用重组动作**：

- 改变判断起点、主谓关系、句子功能分配和承接方式；
- 拆分或合并句子（保留时间/空间/步骤/因果次序）；
- 密集并列项分层说明；普通列举调序、归类或换承载句法；
- 改变句群模块顺序，但不改变事实归属与判断强度；
- 可在同段内新增 1–2 句能从原文直接推出的承接/限定，替代不了事实。

**段落类型 → 改写分支**（对应 `writing-deai-dedup.md` §3.6 的完整表）：

| 段 | 例 | 关键动作 |
|---|---|---|
| 方法段 | "先归一化，再算熵，最后定权" | 方法名/公式/步骤**保护**；改写"用途/关系说明/承接句/结果解释" |
| 案例/实体段 | 某地区 / 某供应商 / 某样本 | 案例事实点**全保留**；按时间/空间/功能/结构/过程重排 |
| 概念/理论段 | 定义 + 分类 + 机制 | 概念外延/条件/方向**保护**；换解释路线 |
| 价值/结论段 | "意义重大 / 应加强" | 补对象关系+适用边界；落点写"给谁、做什么、预期效果" |

**固定术语与专名保护（不要生造近义词）**：

- 模型名、算法缩写、公式、指标名、单位、图号、专有名词、政策文件名、正式称号——**一律不改**。
- 术语密集句：把长列举分散到不同句、改句子起点与谓语、把"条件-行为-结果"拆到不同句群、用总领句+解释句重新分配术语；**不用生造近义词替换标准名称**（如 GM(1,1) 不可写成"灰色单变量模型"）。
- 二轮打断：改写后重跑 `dedup_scan.py 论文.md 题干.txt --dup-span 7`，只对仍重复的**纯中文连续片段**继续处理；含数字/公式片段是保护内容，不强行清零。

## 五、改写五刀（记不住整表就记这五刀）

1. **换序**：把"方法+结果"倒成"结果+方法"（"用最小二乘得 b=−0.83" → "b=−0.83（最小二乘）"）。
2. **拆句**：一句一个意思，长定语拆成两句。
3. **加数**：每句尽量落一个数/范围/置信。
4. **换动词**：抽象的"进行/实现/处理"换成具体的"拟合/求解/清洗/归一化"。
5. **删**：删掉后不损失信息的句子，一律删。
