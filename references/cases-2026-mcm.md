## ⬛ MCM A：Modeling Smartphone Battery Drain（智能手机电池耗电建模）

**题型定位**：连续系统机理建模 / ODE 参数辨识。**这是六题里唯一有"方法禁令"的题**——官方题面用整段黑体强调：*"projects based solely on discrete curve fitting, time-step regression, or black-box machine learning without an explicit continuous-time model will not satisfy this problem's requirements"*，并在结尾再重复一次。

> ⚠️ **本题最大的送死方式**：上手就 LSTM/XGBoost 预测 SOC。哪怕预测精度 0.99，也直接不满足题目要求 → 与 O 奖无缘。**必须先有显式连续时间方程，数据只用于参数估计与验证（"Data as support, not substitute"）。**

### 交付目标
- **一句话**：建立锂离子电池 SOC 的连续时间动力学模型 $\mathrm{SOC}(t)$，在真实使用条件下预测 time-to-empty，并给出用户可执行的省电建议与 OS 级策略。
- **四问交付**：
  1. **连续时间模型**：从最简放电描述起步，逐步扩展屏幕、处理器负载、网络、GPS、后台任务等分项。
  2. **Time-to-empty 预测**：不同初始电量 × 不同使用场景下的耗尽时间，量化不确定性，指出模型何处准、何处不准；回答「哪些活动最耗电、哪些出人意料地几乎不影响」。
  3. **敏感性与假设**：改假设 / 改参数 / 改使用波动，看预测怎么变。
  4. **建议**：降亮度 / 关后台 / 切网络模式各能救回多少续航；OS 如何据此实现更好的省电策略；延伸讨论电池老化与推广到其他便携设备。

### 模型链（推荐三层递进，评审最吃"由简到繁"）
- **第 0 层｜最简守恒**：$Q_{\text{nom}}\dfrac{d\,\mathrm{SOC}}{dt} = -\dfrac{P_{\text{total}}(t)}{V_{\text{oc}}(\mathrm{SOC})}$，即 SOC 变化率 = 瞬时功率 / (标称容量 × 开路电压)。**先把这个方程写出来，题目要求就已满足底线。**
- **第 1 层｜功率分项可加**：$P_{\text{total}}(t) = P_{\text{idle}} + \beta_{s}\,b(t)A_s + \beta_{c}\,u(t) + \beta_{n}\,r(t) + \beta_{g}\,g(t) + P_{\text{bg}}(t)$
  - $b(t)$ 屏幕亮度（0–1）、$A_s$ 屏幕面积、$u(t)$ CPU 占用、$r(t)$ 网络吞吐、$g(t)$ GPS 开关。
  - 亮度—功耗建议用**非线性**（OLED 近似线性于像素亮度，LCD 背光近似 $b^{\gamma}$），这是拉开差距的细节。
- **第 2 层｜等效电路 + 温度 + 老化（拿分关键）**：
  - **一阶 RC 等效电路（Thévenin）**：$V_t = V_{oc}(\mathrm{SOC}) - I R_0 - V_1$，$\dot V_1 = -\dfrac{V_1}{R_1C_1} + \dfrac{I}{C_1}$；恒功率放电下 $I = P/V_t$ 是**隐式**的，需每步解一次标量方程（这正是"物理机理"的体现）。
  - **温度耦合**：内阻 Arrhenius 修正 $R_0(T)=R_{0,\text{ref}}\exp\!\big[\frac{E_a}{R}(\frac1T-\frac1{T_{\text{ref}}})\big]$；产热 $\dot T = \frac{1}{C_{th}}\big(I^2R_0 - \frac{T-T_{amb}}{R_{th}}\big)$ → **SOC–温度双向耦合的 ODE 系统**，一举解释"低温续航崩、重载发烫"。
  - **有效容量衰减**：$Q_{\text{eff}} = Q_{\text{nom}}\big(1 - k_{cyc}\sqrt{N_{cyc}} - k_{cal}\sqrt{t_{\text{age}}}\big)$（$\sqrt{}$ 律来自 SEI 膜生长），对应第 4 问"电池老化"。
  - **速率效应**：Peukert 定律 $Q = I^{-(n-1)}\,C$ 或 KiBaM 双池模型（可用容量/束缚容量两腔室，带恢复效应）——**KiBaM 是本题最容易做出创新点的模型**，它天然解释"歇一会儿电量回弹"。

### 数据与获取（题目要求开放许可）
- 电池规格：厂商 datasheet（Samsung/LG/Panasonic 18650 或手机拆解报告）——标称容量、$V_{oc}$–SOC 曲线。
- 公开数据集：**NASA Prognostics Center 电池老化数据集**、**Oxford Battery Degradation Dataset**、CALCE（马里兰大学）锂电数据集——都是 open license，可直接引用做参数辨识与验证。
- 分项功耗：Android `BatteryStats` / `dumpsys batterystats` 导出、GSMArena 续航测试、学术文献里的手机组件功耗表。
- **自采数据是加分项**：三人各记录一周手机电量+使用日志，做交叉验证，论文里放一张"实测 vs 模型"叠加图，说服力极强。

### 求解与 Python 要点
- ODE：`scipy.integrate.solve_ivp`（刚性建议 `method='BDF'` 或 `'Radau'`，温度耦合易刚性）。
- 隐式电流：每步用 `scipy.optimize.brentq` 解 $P = V_t(I)\cdot I$。
- Time-to-empty：`solve_ivp` 的 **`events` 参数**设 `SOC - 0.0` 事件并 `terminal=True`，直接输出耗尽时刻（比循环判断优雅得多）。
- 参数辨识：`scipy.optimize.least_squares`（带 `bounds` 保证物理可行）或 `differential_evolution` 做全局初值。
- 不确定性：参数后验用 `emcee`（MCMC）或简易 bootstrap → time-to-empty 的**置信区间**，直接回答第 2 问"quantify uncertainty"。
- 敏感性：Sobol 指数（`SALib`）比单因素扫描高级一档，且能回答"哪些因素出人意料地不重要"。

### 检验套路
- **量纲检查**：$P/V$ 得电流(A)，除以容量(A·h)得 1/h，量纲必须对得上（写进论文里显示严谨）。
- **边界 sanity**：$b\to0,u\to0$ 时续航应趋近待机时长（20–40 h 量级）；满载游戏应 3–5 h；数量级不对说明参数错。
- **能量守恒**：$\int P\,dt$ 应等于电池额定能量（$Q_{\text{nom}}\times V_{\text{nom}}$，如 4000 mAh × 3.85 V ≈ 15.4 Wh）。
- **步长收敛**：$\Delta t$ 减半结果不变。
- **交叉验证**：留出一部分实测放电曲线不参与拟合，报 RMSE / MAPE。

### O 奖亮点建议
1. **KiBaM 恢复效应 + 实测回弹曲线对照**：绝大多数队只写一阶线性放电，能做出"间歇使用比连续使用总续航更长"的定量结论，是全场少见的物理洞察。
2. **SOC–温度双向耦合的相图**：画出 $(T_{amb},\ \text{负载})$ 二维平面上的 time-to-empty 等值线热力图，一图讲完"低温+重载双杀"，是评审最容易记住的图。
3. **把第 4 问做成 OS 控制器**：将省电策略写成最优控制问题（$\min$ 耗电 s.t. 用户体验约束），用 Pontryagin 或 MPC 给出"亮度随剩余电量动态调度"的策略曲线 —— 从"建议"升级为"可实现算法"，格局立刻不同。
4. **Sobol 敏感性回答反直觉问题**：明确指出"某些因素影响出人意料地小"，直接命中题目原话，评审会认为你真读懂了题。

### 高频失分点
1. ❌ **用机器学习/曲线拟合当主模型** —— 直接不满足要求，最致命。
2. ❌ 只写 $\mathrm{SOC}(t)=\mathrm{SOC}_0 - kt$ 线性放电，无任何机理层次，模型太薄。
3. ❌ 参数凭空取值不给来源、不做合理性验证（题目明确要求 "clearly justified and validated for plausibility"）。
4. ❌ 数据来源不是开放许可 / 未规范引用（题目明确要求 open license + 文档化）。
5. ❌ 忘记温度，导致无法解释题干开头就提出的"冷天掉电、重载过热"现象——**题干提到的现象没解释，等于没答题**。

## ⬛ MCM B：Creating a Moon Colony Using a Space Elevator System（太空电梯建月球殖民地）

**题型定位**：大规模离散优化 / 多目标运输规划 + 不确定性与可靠性。**六题里工程量最大的一题**（难度公认 B ≈ D 居首）。

✅ **确证题面参数（官方 PDF 原文，可直接用于建模）**

| 参数 | 确证值 |
|---|---|
| 殖民地规模 | 约 100,000 人，2050 年开工建设 |
| 总建材需求 | 约 **1 亿公吨**（100 million metric tons） |
| 太空电梯系统构型 | **3 个 Galactic Harbour**，理想沿赤道相隔 120° |
| 单个 Galactic Harbour | 1 个地球港 + **2 条 100,000 km 长系绳** → 2 个 apex anchor，多台电梯并行 |
| 单港年运力 | **179,000 公吨/年**，且**零大气污染** |
| 传统火箭运力 | 单次 **100–150 公吨** 量级 |
| 运输两段式 | ① 地球港 →（电梯）→ apex anchor；② apex anchor →（火箭）→ 月球殖民地 |
| 后续需求 | 建成后需**常态化补给水与物资** |

> 🔑 **先做量级 sanity check（这是本题第一个得分点）**：3 港 × 179,000 t/yr = **537,000 t/yr**。1 亿吨 ÷ 53.7 万吨/年 ≈ **186 年**！纯电梯方案根本赶不上任何合理工期。**这个数字必须在论文开头算出来并明确写出**——它是全篇论证的逻辑起点，说明"必须混合方案 / 必须扩建 / 必须就地取材"。
> 参考：某国奖队（大连理工 RE-DLSM 模型）用 ε-约束 + Minimax Regret 得到 **132 年**的折中最优工期，思路是"电梯打底 + 火箭补峰 + 分阶段扩容"。**注意：132 年是该队在其假设口径下的解，不是标准答案**，你队须按自己的假设自行求解并标注口径。

### 交付目标
- **一句话**：在成本、工期、可靠性、环境影响的多重权衡下，为 1 亿吨月球建材 + 长期补给设计最优运输方案，并对比"纯电梯 / 纯火箭 / 混合"三种情景，给决策机构写政策建议信。
- **典型分问结构**：① 三情景运力—成本—工期对比；② 最优运输量分配与调度；③ 故障/不确定性下的稳健性；④ 建成后的水与物资常态化补给；⑤ 环境影响量化；⑥ 给 MCM Agency 的建议信/备忘录。

### 模型链
- **主模型｜多阶段混合整数规划（MILP）**：
  - 决策变量：$x_{h,t}$ 第 $h$ 港第 $t$ 年电梯运量、$y_{t}$ 第 $t$ 年火箭发射次数（整数）、$z_{h,t}\in\{0,1\}$ 扩容/启用决策。
  - 目标：$\min\ \sum_t \frac{C_{\text{ele}}x_t + C_{\text{rkt}}y_t}{(1+r)^t}$（贴现总成本）或 $\min T_{\text{完工}}$。
  - 约束：$\sum_{h,t} x_{h,t} + 150\,y_t \ge 10^8$（总量）、$x_{h,t}\le 179000$（单港运力上限）、发射场年发射次数上限、预算年度上限。
  - **一定要贴现**：跨 100+ 年的项目不贴现，成本比较毫无意义——这是拉开档次的经济学细节。
- **多目标处理**：成本 / 工期 / 环境（CO₂ 与颗粒物）/ 可靠性四目标 → **ε-约束法**或加权法求 **Pareto 前沿**；用 **Minimax Regret** 或后悔度矩阵做稳健选择（比单纯加权更有说服力，且能规避"权重怎么来的"这一致命追问）。
- **可靠性/故障模型**：
  - 系绳断裂、电梯停机、火箭发射失败（历史成功率约 95–98%）→ **两状态 Markov 可用率模型**或**可用度 $A = \mathrm{MTBF}/(\mathrm{MTBF}+\mathrm{MTTR})$**。
  - **蒙特卡洛**叠加故障情景 → 工期分布（而非单点值），报 P50 / P90 完工年份，**这是本题最容易做出"专业感"的一步**。
  - 抗毁性：3 港中 1 港失效时的降级运力（120° 分布正是为了冗余，题面暗示要讨论这点）。
- **水与补给（第 4 问）**：**系统动力学 / 库存模型**。人均耗水 ~50–100 L/day（NASA ISS 回收后约 20 L/day），10 万人 → 年需水量量级估算；引入**闭环回收率 $\eta$**（ISS 现约 90%+），则净补给量 $\propto (1-\eta)$。
  - 💡 **就地资源利用（ISRU）是本题最大创新空间**：月球两极永久阴影区有水冰，若就地开采可把补给需求砍掉一个数量级。把 ISRU 投资额作为决策变量，做"运输 vs 自产"的权衡，是全场极少数队能想到的角度。
- **环境影响**：电梯零大气污染（题面明确）vs 火箭尾气（每次发射数百吨 CO₂ + 平流层黑碳/氯）→ 量化对比表 + 折算社会成本（碳价 $\times$ 排放量），把环境目标货币化后并入总成本。

### 数据与获取
- 火箭数据：SpaceX Starship（100–150 t 到 LEO）、Falcon Heavy 官方参数与发射价格（$/kg）。
- 太空电梯：**ISEC（International Space Elevator Consortium）** 年度报告、Edwards & Westling《The Space Elevator》——系绳材料、运力、成本估算。
- 月球基地需求：NASA Artemis 计划文件、ESA Moon Village 研究、ISS 生保系统（ECLSS）水回收率。
- 月球水冰：NASA LCROSS / LRO 探测数据（南极永久阴影区）。
- 碳排放：ICAO/IPCC 排放因子，碳社会成本取 $50–190/tCO₂（EPA 2023 区间）。

### 求解与 Python 要点
- MILP：`pulp` + CBC（零成本、易复现）或 `scipy.optimize.milp`；规模大用 `OR-Tools` CP-SAT；有许可用 Gurobi（`gurobipy`）。
- 多目标 Pareto：循环 ε-约束逐点求解，`matplotlib` 画 3D Pareto 曲面或平行坐标图。
- 蒙特卡洛：`numpy` 向量化 + `scipy.stats`；工期分布画小提琴图/CDF。
- 系统动力学：`solve_ivp` 或简单差分迭代（库存递推）。
- **可视化建议**：三情景运量堆叠面积图（时间轴 1 亿吨累积进度）+ 甘特式分阶段扩容图 + Pareto 前沿 —— 美赛吃图，这三张能撑起全篇。

### 检验套路
- **量级 sanity（最重要）**：前述 186 年估算；单港 179,000 t/yr ÷ 365 ≈ 490 t/day，除以单舱运力得日发车次数，看是否物理合理。
- **守恒**：各年运量之和 = 1 亿吨（用 `check_results.py` 核对论文数字与 `results.json`）。
- **极端情形**：火箭成本 → 0 时应退化为纯火箭方案；运力 → ∞ 时工期应趋于建设速度约束——退化行为对了，模型才可信。
- **敏感性**：贴现率 $r$（0%/3%/7%）、火箭单价、$\eta$ 回收率、发射成功率对最优方案结构的影响（**报"方案是否切换"比报数值变化更有价值**）。

### O 奖亮点建议
1. **把"186 年悖论"作为全文叙事主线**：开篇算出纯电梯不可行 → 逼出混合方案 → 再逼出 ISRU/扩容 → 结论自然收束。美赛极吃这种"有故事的论证"。
2. **Minimax Regret 稳健决策**：绕开"多目标权重主观"的致命弱点，直接回答"不知道未来参数时该怎么选"，档次高于加权求和。
3. **ISRU 内生化**：把月球水冰开采作为决策变量而非外生假设，得出"投 X 亿美元建 ISRU 可省 Y 万吨运输"的临界点，是本题最稀缺的创新。
4. **P90 工期而非单点工期**：给出带故障的完工年份概率分布，并写"以 90% 置信度在 XXXX 年前完工"——决策者语言，直接命中"给 Agency 写建议"的角色要求。
5. **抗毁性分析**：论证 120° 三港布局在单港失效下的运力保留率，呼应题面构型设计意图，显示读题极细。

### 高频失分点
1. ❌ **不做量级估算就闷头建模**，得出"20 年建成"之类与 179,000 t/yr 硬约束矛盾的结论——逻辑自毁，直接出局。
2. ❌ 跨百年项目不贴现，成本数字失去意义。
3. ❌ 三情景只做定性对比，没有统一口径的量化表（成本/工期/排放三列必须齐）。
4. ❌ 忽略"建成后常态化补给"（第 4 问），只算 1 亿吨建材就收尾——**漏问等于漏分**。
5. ❌ 故障只做单点敏感性，不做概率分布；"可靠性"沦为一句空话。
6. ❌ 25 页写不完：本题分问多，**必须提前规划页面预算**（建议 模型 8p / 求解结果 7p / 稳健性 3p / 建议信 2p / 其余 5p）。

## ⬛ MCM C：Dancing with the Stars 赛制分析（粉丝投票逆推与评分公平性）

**题型定位**：**统计逆问题 + 潜变量推断 + 机制设计**。参赛 13,185 队（全场最多），O 奖 19 个（也最多）。开放度中等、难度较低，是"性价比"最高的热门题——**但正因人多，平庸解法毫无出头机会，必须在"逆问题不确定性"上做出深度**。

### 交付目标
- **一句话**：从 34 季公开数据中，仅凭评委打分与淘汰结果**反推不可观测的粉丝投票**，评估两种评分合成规则的公平性，量化职业舞者与名人特征的影响，并设计更公平（或更有观赏性）的新赛制。
- **四问交付**：
  1. **逆推粉丝票**：由评委分 + 淘汰名单反推每对选手的粉丝得票（**不可观测量**），并评估推断的准确度/可信度。
  2. **规则公平性对比**：**按名次合成（rank-based）** vs **按比例合成（share/percentage-based）** 两种规则的公平性差异，解释历史争议案例（"明明分最低却没被淘汰"）。
  3. **影响因素**：职业舞者水平、名人知名度/职业背景/年龄等特征对成绩的影响。
  4. **新赛制设计**：给节目制作方一套更公平或更具观赏性的机制，并论证其性质。

### 模型链（核心：这是一个"只有不等式信息"的逆问题）
- **关键洞察｜数据是"不等式"而非"等式"**：我们**观测不到**票数，只观测到"谁被淘汰"。被淘汰者的合成分最低，即
  $$S_{\text{elim}} \le S_j,\quad \forall j \neq \text{elim}$$
  每周淘汰给出的是一组**线性不等式约束**。这意味着：
  - **解不唯一**（可行域是一个多面体，而非一个点）——**这是本题的灵魂**。
  - 正确姿势不是"求出票数"，而是**刻画可行集 / 给出后验分布**。
- **方法一｜可行域刻画（线性规划边界法）**：把票数 $v_i \ge 0$、$\sum_i v_i = 1$ 作为变量，淘汰不等式作为约束，对每个 $v_i$ 分别求 $\min$ 和 $\max$（两次 LP）→ 得到每位选手票数的**区间估计**。简洁、严谨、可解释，性价比极高。
- **方法二｜贝叶斯潜变量模型（推荐主模型）**：
  - 先验：票份额 $\mathbf v \sim \mathrm{Dirichlet}(\boldsymbol\alpha)$，其中 $\alpha_i = \exp(\mathbf x_i^\top\boldsymbol\beta)$，$\mathbf x_i$ 为名人特征（粉丝基数、社交媒体关注度、职业类型、出场顺序等）。
  - 似然：观测淘汰事件的概率 $P(\text{elim}=k\mid \mathbf v) = \mathbb 1\{S_k = \min_j S_j\}$（硬约束）或用 softmax 软化：$P \propto \exp(-S_k/\tau)$（容忍噪声，数值更稳）。
  - 推断：**MCMC**（`pymc` / `emcee`）或 **ABC（近似贝叶斯计算）** → 得到 $\mathbf v$ 的**后验分布**，天然回答第 1 问的"评估准确性"（后验区间宽度即不确定性）。
  - 💡 这是本题最"对症"的模型：**逆问题多解性 = 后验分布的宽度**，一句话把难点转化为优势。
- **方法三｜Plackett–Luce / Bradley–Terry 排序模型**：把粉丝投票看作对选手的偏好排序，用 PL 模型的效用参数 $\theta_i$ 表示"人气强度"，由淘汰序列做**极大似然/贝叶斯**估计。适合第 3 问（把 $\theta_i$ 回归到名人特征上）。
- **第 2 问｜规则公平性的量化**：
  - 定义可比指标：**Kendall τ / Spearman ρ**（评委排序 vs 最终结果的一致性）、**逆序率**（评委第一被淘汰的频率）、**票数—名次弹性**（多一个百分点选票能提升几位）。
  - **反事实重放（counterfactual replay）是本题最有力的武器**：用推断出的票数，把 34 季历史**按另一套规则重跑**，统计"结果会改变的周数占比 / 冠军会变的季数"。给出"若采用比例制，第 X 季冠军会变成 Y"这类具体结论——**评审会被这种可验证的具体性击中**。
  - 机制性质分析：名次制丢失强度信息（差 1 票和差 100 万票同样是"差一名"）→ 放大评委权重；比例制保留强度但**易被超级粉丝团碾压**（长尾分布下少数明星吸走大部分票）。用 **基尼系数/HHI** 刻画票数集中度，论证两制度各自的失效条件。
- **第 4 问｜机制设计（拉分关键）**：
  - 候选机制：加权几何平均、**分位数归一化后再合成**（消除量纲差异）、Borda count、双轨保护（评委保留一次"救人"权）、**票数对数变换**（$\log v$ 压缩超级粉丝团优势）。
  - 用**公理化方法**论证：单调性（票多不该名次降）、匿名性、**无关选项独立性**、抗操纵性（strategyproofness）——挑 3 条公理，做成"机制 × 公理"满足性表格，是本题最具学术气质的呈现。
  - 观赏性维度可量化为"悬念度"：用**结果熵** $H = -\sum p_i\log p_i$ 或"淘汰前不确定性"衡量，做"公平性—观赏性"Pareto 前沿——**同时回答题目"更公平或更具观赏性"的双目标，格局最高**。

### 数据与获取
- 主数据：题目提供 34 季数据集（评委打分、名人/职业舞者信息、淘汰结果，**含 N/A 缺失**）。
- 补充特征（自行搜集，需规范引用）：Wikipedia 各季页面、IMDb 名人信息、Google Trends 搜索热度（代理"人气"）、社交媒体粉丝数、Nielsen 收视率。
- 💡 **Google Trends 做人气代理是本题性价比最高的外部数据**：可对推断出的票数做**外部验证**（相关性检验），直接回答"评估推断准确性"，比自说自话强得多。

### 求解与 Python 要点
- LP 区间：`scipy.optimize.linprog`（每个 $v_i$ 跑 min/max 两次）。
- 贝叶斯：`pymc`（Dirichlet + Potential 施加不等式约束）或 `emcee`；PL 模型可用 `choix` 库。
- 缺失值：题目明确有 N/A → 多重插补 `sklearn.impute.IterativeImputer`，并**报告插补敏感性**（换插补法结论是否变）。
- 反事实重放：纯 `pandas` 逐周重算，写成函数 `replay(season, rule)` 便于对比。
- 可视化：票数后验区间的森林图（forest plot）、规则对比的 Sankey/桑基图（谁在新规则下命运改变）、公平—观赏 Pareto 前沿。

### 检验套路
- **一致性**：推断票数必须满足 $v_i\ge0,\ \sum v_i=1$，且能**复现全部历史淘汰结果**（复现率应为 100%，否则模型或数据错）——这是本题最硬的自检，**必须在论文中报告**。
- **合成数据验证（强烈建议）**：自己造一批"已知真实票数"的模拟赛季，用你的方法反推，报**恢复误差**。这是唯一能真正证明"推断准确"的方式，而绝大多数队做不到。
- 后验预测检验（PPC）：从后验采样重跑淘汰，看模拟淘汰序列与真实的一致率。
- 稳健性：先验超参 $\boldsymbol\alpha$、软化温度 $\tau$、插补方法三者的敏感性。

### O 奖亮点建议
1. **合成数据反演验证**：先造真值再反推、报恢复误差 —— 直接把"如何评估准确性"这个所有队都心虚的问题彻底解决。**本题第一梯队与第二梯队的分水岭。**
2. **34 季反事实全量重放**：给出"改规则会改变 N% 的淘汰、M 季的冠军"，配桑基图。具体、可验证、有话题性。
3. **多解性正面处理**：不回避逆问题不唯一，而是用后验区间 / LP 上下界**量化不确定性**，并说明"哪些选手的票数可被确定、哪些本质不可辨识"——学术诚实本身就是高分项。
4. **机制设计公理化表格**：3 条公理 × 4 种机制的满足性矩阵 + 反例，把第 4 问从"拍脑袋建议"提升到社会选择理论。
5. **外部验证**：用 Google Trends 热度与推断票数做相关性检验，跳出"自证循环"。

### 高频失分点
1. ❌ **当成正问题做回归**：直接拿评委分预测淘汰，完全没意识到"粉丝票是潜变量、信息是不等式"——本题最普遍的错误，也是最致命的。
2. ❌ 给出票数的**唯一点估计**且不谈不确定性，等于假装逆问题有唯一解。
3. ❌ 推断结果**无法复现历史淘汰**却不检查、不报告。
4. ❌ 公平性只做定性议论，没有 τ/ρ/逆序率之类的可比指标。
5. ❌ 忽略 N/A 缺失或悄悄删行，导致样本选择偏差。
6. ❌ 第 4 问只写"建议加大评委权重"这类无模型支撑的空话，浪费本题最容易出彩的部分。
7. ❌ 涉及名人时加入主观评价/八卦口吻——**美赛要求中立可量化，只谈指标不谈价值判断**。

## ⬛ ICM D：Managing Sports for Success（体育管理的动态决策）

**题型定位**：**动态决策 / 多目标权衡 + 运营管理**。参赛仅 1,835 队、O 奖 3 个（≈0.16%），冷门但难度公认与 B 并列最高。适合有运筹/经管背景且**敢写决策者语言**的队伍。

### 交付目标
- **一句话**：为职业体育俱乐部建立一个动态决策模型，在**竞技成绩、财务利润、球队长期价值**三者之间权衡资源配置（签约、薪资、青训、交易），并以**备忘录（memo）形式给球队 owner 与 GM** 提出可执行策略。
- **典型分问结构**：① 定义并量化"成功"（成绩 vs 利润 vs 球队价值）；② 建立多期资源配置/阵容决策模型（含薪资帽约束）；③ 引入伤病、球员老化、市场波动等不确定性；④ 对不同类型球队（豪门 / 小市场球队 / 重建期球队）给出差异化策略；⑤ 写给 owner/GM 的备忘录。

### 模型链
- **核心框架｜多期随机动态规划 / MDP（推荐主模型）**：
  - **状态** $s_t$：阵容构成（各球员能力值与年龄）、薪资空间余量、财务储备、球队品牌价值。
  - **决策** $a_t$：签约/续约/交易/裁员、薪资分配、青训投入比例。
  - **转移**：球员能力随年龄演化（**老化曲线**，见下）、伤病随机冲击、比赛结果随机。
  - **报酬**：$R_t = w_1\cdot\text{Wins}_t + w_2\cdot\text{Profit}_t + w_3\cdot\Delta\text{Value}_t$。
  - 求解：状态空间大 → **近似动态规划（ADP）/ 强化学习**，或退化为**滚动时域优化（MPC）**——后者 4 天内更可控，**强烈推荐 MPC**。
- **子模型 1｜球员能力的老化曲线（aging curve）**：能力 $\theta(a)$ 关于年龄 $a$ 通常呈**倒 U 形**，峰值约 26–28 岁（因项目而异）。可用二次型 $\theta(a)=\theta_{\max}-k(a-a^*)^2$ 或非参数样条拟合历史数据。
  - 💡 **这是本题最容易做出定量洞察的地方**：由老化曲线可推出"签 30 岁球员的长约在第几年开始为负价值"，直接产出可写进备忘录的硬结论。
- **子模型 2｜薪资—战力生产函数**：$\text{Wins} = f(\sum_i \theta_i)$，常用 **Pythagorean expectation**（如棒球 $W\% = \frac{RS^2}{RS^2+RA^2}$，篮球/足球有对应形式），或 logistic 型边际递减 $f$。
  - 关键：**边际递减**——多花 1 元买战力的边际胜场随投入下降，这是"豪门也不该无限砸钱"的数学基础。
- **子模型 3｜财务模型**：收入 = 门票 + 转播 + 商业赞助 + 季后赛奖金，多数与**胜率非线性正相关**（季后赛资格是**阶跃点**）。
  - 💡 **阶跃是本题的戏剧性来源**：胜率跨过季后赛门槛时收入跳升 → 目标函数**非凸**，最优策略出现"要么全力冲击、要么彻底重建（tanking）"的**双模态**结构。能把这一点论证出来，直接触及职业体育最真实的战略逻辑，**是本题最强的亮点**。
- **子模型 4｜球队长期价值**：$V = \text{EBITDA}\times\text{multiple}$ 或用品牌资产模型；长期价值受"持续竞争力 + 球迷基础 + 场馆"驱动，与短期利润**存在冲突**（这正是题目要求权衡的核心张力）。
- **子模型 5｜伤病与不确定性**：伤病发生率（泊松/生存分析）× 缺阵时长（对数正态）→ 蒙特卡洛；用 **CVaR（条件风险价值）** 而非期望值做目标，回答"如何避免最坏情形"，比单纯期望优化高一档。
- **薪资帽约束（题目明确提到）**：硬帽/软帽 + 奢侈税（超出部分按累进税率罚款）→ MILP 中的**分段线性惩罚**。真实联盟规则（NBA 软帽 + 奢侈税、NFL 硬帽、MLB 无帽有税）差异很大，**建议明确锚定一个联盟并注明**，避免规则混搭导致逻辑不自洽。

### 数据与获取
- 公开数据库（都可免费获取，务必规范引用）：**Sports-Reference 系列**（Basketball/Baseball/Football/Hockey-Reference）、**Spotrac / Over the Cap**（薪资与合同）、**Lahman Baseball Database**（开源）、**FBref**（足球）。
- 球队估值：**Forbes 年度球队估值榜**（含收入、EBITDA 拆分）。
- 伤病：Pro Sports Transactions 伤病记录数据库。
- 💡 选**棒球（MLB）**数据最全、指标最成熟（WAR、Pythagorean 都是现成体系）；选**篮球（NBA）**薪资帽规则最有戏剧性。二者都比足球好做。

### 求解与 Python 要点
- MPC/滚动优化：每期解一个 MILP（`pulp` / `OR-Tools`），滚动推进 5–10 期。
- 老化曲线：`numpy.polyfit` 或 `scipy.interpolate.UnivariateSpline`；分位数回归（`statsmodels.QuantReg`）可给出能力区间。
- 生产函数拟合：`statsmodels` OLS/GLM，注意报告 $R^2$ 与残差诊断。
- 蒙特卡洛 + CVaR：`numpy` 采样，CVaR 取尾部均值 `np.mean(x[x<=np.quantile(x,0.05)])`。
- 强化学习（可选进阶）：`gymnasium` 自定义环境 + `stable-baselines3` PPO；**时间不够就别碰**，MPC 已足够。
- 可视化：三目标 Pareto 曲面、不同球队类型的策略热力图（年龄 × 薪资 → 签约建议）、蒙特卡洛胜场分布。

### 检验套路
- **历史回测（本题最强验证）**：用你的模型在某支真实球队的历史节点做决策，与该队**实际决策**对比，看模型是否能"事后正确"。例如模型建议不续某位后来暴跌的球员 → 强力证据。
- **量纲/口径**：薪资单位（百万美元）、赛季长度、胜率定义全篇统一；用 `check_results.py` 核对论文数字与 `results.json`。
- **边界**：薪资帽 → ∞ 时应退化为"买最强阵容"；折现率 → 1 时应极度重视长期价值。
- **敏感性**：权重 $w_1,w_2,w_3$ 扫描 → **报告"策略结构何时切换"**（冲击 ↔ 重建的临界权重），比报数值变化有价值得多。

### O 奖亮点建议
1. **季后赛阈值导致的非凸目标 → 双模态最优策略**：数学上论证"中庸阵容是最差选择"（既进不了季后赛又没有选秀权），这是职业体育界公认现象，你用模型推出来，说服力极强。
2. **老化曲线 → 合同年限的定量建议**：给出"某年龄段球员最优合同年限上限"的表格，是 GM 真正能用的东西。
3. **历史回测**：用真实球队真实年份验证，跳出纯理论。
4. **CVaR 稳健策略**：回答"如何在伤病最坏情形下不崩盘"，冷门题里的稀缺深度。
5. **三类球队差异化策略卡**：豪门/小市场/重建期各一张一页决策卡，**直接对应"给 owner 和 GM 的备忘录"这一角色要求**。ICM 极重视"是否真的写给了指定读者"。

### 高频失分点
1. ❌ **只做静态单期优化**，完全没有"动态"（题目核心是 dynamic decision），模型定位就错了。
2. ❌ 三目标只加权求和且权重凭空给定，不做权重敏感性 → "多目标"名存实亡。
3. ❌ 忽略薪资帽/奢侈税（题目明确提到），最优解变成"无限砸钱"，一眼假。
4. ❌ 混搭多个联盟的规则（拿 NBA 薪资帽配 MLB 数据），逻辑不自洽。
5. ❌ **忘了写备忘录**或备忘录写成论文摘要 —— ICM 的 memo 是独立文体，要求**面向非技术读者、给出可执行动作**，不是技术总结。
6. ❌ 数据只用一个赛季，样本太小无法支撑老化曲线等结论。

## ⬛ ICM E：Passive Solar Shading（被动式太阳遮阳设计）

**题型定位**：**物理机理建模（天文几何 + 传热）+ 工程优化**。参赛 1,649 队（全场最少）、O 奖 3 个（≈0.18%）——**六题中最冷门，性价比很高**。难度中等，且物理链条清晰、检验容易，适合工科队"稳稳做扎实"。

### 交付目标
- **一句话**：为两所处于不同纬度的大学（题面给出 **Sungrove**（低纬）与 **Borealis**（高纬）两所虚构大学）设计被动式遮阳方案，量化其对建筑得热/失热与能耗的影响，并说明设计如何随纬度与气候改变。
- **典型分问结构**：① 建立太阳位置与入射辐射模型；② 建立遮阳装置几何—遮蔽率模型；③ 耦合建筑热模型，计算全年供冷/供热能耗；④ 优化遮阳几何参数；⑤ 对比低纬 vs 高纬两校的最优设计差异；⑥ 给校方的设计建议。

> 🔑 **本题的核心张力（务必抓住）**：遮阳在夏天挡太阳省空调（好），但在冬天也挡了太阳、增加供暖（坏）。**最优设计不是"挡得越多越好"，而是"夏挡冬透"的季节选择性**。
> 由太阳几何可直接得出关键结论：**南向（北半球）适合水平遮阳板**（夏季太阳高度角高、易挡；冬季高度角低、阳光可从板下射入 → 天然实现季节选择性）；**东西向适合垂直遮阳/百叶**（早晚太阳方位偏、高度角低，水平板无效）。
> **纬度差异**：低纬（Sungrove）以**制冷为主导**，遮阳收益大、可做深挑檐；高纬（Borealis）以**采暖为主导**，冬季太阳能得热珍贵，**过度遮阳会净亏**，应改为可调节/季节性遮阳（活动百叶、落叶树）。能把这个"低纬固定、高纬可调"的结论定量论证出来，就已抓住了题目的命门。

### 模型链
- **第 1 层｜太阳位置（天文几何，必须精确）**：
  - 赤纬 $\delta = 23.45^\circ \sin\!\big[\frac{360}{365}(284+n)\big]$（$n$ 为一年中的第几天）。
  - 时角 $\omega = 15^\circ\,(t_{\text{solar}} - 12)$。
  - 太阳高度角：$\sin\alpha = \sin\phi\sin\delta + \cos\phi\cos\delta\cos\omega$（$\phi$ 为纬度）。
  - 方位角：$\sin\gamma_s = \dfrac{\cos\delta\sin\omega}{\cos\alpha}$。
  - ⚠️ 注意真太阳时修正（**时差方程 equation of time** + 经度修正），不修正会导致遮阳影子对称性错误——**做了这一步就是"细致"，没做就是"粗糙"**。
- **第 2 层｜表面入射辐射（三分量分解）**：
  $$I_{\text{surface}} = I_b\,\cos\theta_i + I_d\,F_{\text{sky}} + I_{\text{ground}}\,\rho\,F_{\text{gnd}}$$
  - 直射 $I_b$（受遮阳影响最大）、散射 $I_d$（可用 **Perez 或 Hay–Davies 各向异性天空模型**，比各向同性精细一档）、地面反射（反射率 $\rho$：草地 0.2、雪地 0.7 —— **高纬冬季雪地反射不可忽略，这是 Borealis 校区的加分细节**）。
  - 入射角 $\cos\theta_i = \sin\alpha\cos\beta + \cos\alpha\sin\beta\cos(\gamma_s-\gamma_{\text{surf}})$（$\beta$ 表面倾角）。
- **第 3 层｜遮阳几何 → 遮蔽率（本题的建模主体）**：
  - **解析法（推荐）**：水平挑檐深度 $d$、窗高 $h$、挑檐距窗顶距离 $e$ → 影子长度 $L = d\tan\!\big(\frac{\text{profile angle}}{}\big)$，其中 **profile angle（剖面角）** $\tan\psi = \dfrac{\tan\alpha}{\cos(\gamma_s-\gamma_{\text{surf}})}$。遮蔽面积占比 $f_{\text{shade}}(t) = \min\!\big(1, \max(0,\frac{L-e}{h})\big)$。
  - 💡 **剖面角 $\psi$ 是本题最关键的单一公式**：它把三维太阳位置压缩成一个角度，遮阳板的遮蔽完全由它决定。用它可直接画出**遮阳遮蔽率的年—日热力图**（横轴日期、纵轴时刻、颜色为遮蔽率），这张图是本题最有辨识度的可视化。
  - **数值法（备选）**：光线投射/蒙特卡洛采样窗面网格点，判断是否被遮阳板遮挡。可处理复杂几何（花格、遮阳翼、周边建筑），但慢。
- **第 4 层｜建筑热模型（RC 集中参数，够用且好检验）**：
  $$C\frac{dT_{\text{in}}}{dt} = \underbrace{\frac{T_{\text{out}}-T_{\text{in}}}{R_{\text{env}}}}_{\text{围护传热}} + \underbrace{\mathrm{SHGC}\cdot A_w\,I_{\text{surface}}(1-f_{\text{shade}})}_{\text{太阳得热}} + Q_{\text{internal}} + Q_{\text{HVAC}}$$
  - 能耗：$E_{\text{cool}} = \int \max(0, Q_{\text{HVAC}})dt / \mathrm{COP}$，$E_{\text{heat}} = \int \max(0,-Q_{\text{HVAC}})dt/\eta$。
  - 简化替代（若时间紧）：**度日法 + 太阳得热修正**（CDD/HDD），精度低但物理清晰、易解释。
  - 舒适度可加 **PMV/PPD** 或简单的"温度超限小时数"，回应"被动式设计不只省能，还提升舒适"。
- **第 5 层｜优化**：决策变量 = 挑檐深度 $d$、倾角、百叶间距/角度、朝向、玻璃 SHGC；目标 = $\min (E_{\text{cool}}+E_{\text{heat}})$ 或 $\min$ 全生命周期成本（含遮阳造价）；方法：网格搜索（变量少时最稳）或 `differential_evolution`。
  - 💡 **多目标**：能耗 vs 采光（遮阳过度会让室内变暗、增加照明电耗）→ **采光是本题被绝大多数队忽略的第三个维度**，加入"照明能耗补偿项"能让结论从"挡得越多越好"翻转，是极强的创新点。

### 数据与获取
- 气象数据（关键，均免费）：**EnergyPlus Weather (EPW) 文件**（energyplus.net/weather，含逐时太阳辐射/温度，全球数千站点）、**NREL NSRDB**、**PVGIS**（欧洲/全球辐射）、NASA POWER。
- 建筑参数：**ASHRAE 90.1** 标准（围护结构 U 值、SHGC 限值）、ASHRAE Handbook Fundamentals（第 14 章太阳几何）。
- 💡 **两校纬度需自行设定并说明理由**：建议 Sungrove 取低纬（如 $\phi\approx 25^\circ$N，类似迈阿密/广州）、Borealis 取高纬（如 $\phi\approx 60^\circ$N，类似奥斯陆/安克雷奇），并各自选一个真实 EPW 站点代表。**明确写出"我们用 X 城市数据代表 Sungrove，理由是……"**，比含糊处理专业得多。

### 求解与 Python 要点
- 太阳位置：可自己实现上述公式（**推荐，显示机理掌握**），或用 `pvlib`（`pvlib.solarposition.get_solarposition`，工业级精度）交叉验证——**两者对比一致即为强验证**。
- EPW 读取：`pvlib.iotools.read_epw()` 一行搞定。
- 辐射分解：`pvlib.irradiance.get_total_irradiance()`（含 Perez 模型）。
- 热模型 ODE：`solve_ivp`，或逐时显式差分（8760 步，`numpy` 向量化秒级完成）。
- 优化：`scipy.optimize.differential_evolution` 或直接对 $d$ 做细网格扫描 + 画曲线（**曲线比单个最优值更有说服力**）。
- 可视化：① 遮蔽率年—日热力图；② 太阳轨迹图（sun-path diagram）叠加遮阳遮蔽区；③ 两校最优挑檐深度对比 + 能耗分解堆叠柱状图（供冷/供热/照明）。

### 检验套路
- **天文验证（最容易做、最有效）**：夏至/冬至/春分正午的太阳高度角应满足 $\alpha_{\max}=90^\circ-|\phi-\delta|$；春分日全球昼长 ≈ 12 h；高纬夏季应出现极长白昼。**这些是有解析真值的硬校验，务必在论文里列表对照。**
- **能量守恒**：$\int I\,dt$ 得到的年总辐照量应与 EPW 站点公开的年辐照量（GHI 年累计，量级 1000–2000 kWh/m²）一致。
- **量级 sanity**：办公建筑单位面积年能耗量级 50–200 kWh/m²·yr；若算出 5 或 5000，参数必错。
- **边界退化**：挑檐深度 $d\to0$ 应退化为无遮阳基准；$d\to\infty$ 应全年全遮（此时高纬供暖能耗必须显著上升——**若没上升说明热模型或符号错了**）。
- **步长收敛**：逐时 vs 逐 15 分钟，年能耗差异应 < 几个百分点。
- **交叉验证**：自写太阳位置 vs `pvlib`，逐时对比最大偏差应 < 0.5°。

### O 奖亮点建议
1. **"夏挡冬透"的季节选择性定量化**：给出遮阳的**季节收益分解表**（夏季省下 X kWh、冬季多耗 Y kWh、净收益 X−Y），并指出净收益随纬度**变号的临界纬度** —— 这是本题最漂亮的结论，且直接解释了两校设计为何不同。
2. **纳入采光/照明能耗的三目标权衡**：论证"过度遮阳因照明电耗上升而净亏"，翻转直觉，绝大多数队想不到。
3. **可调节 vs 固定遮阳的对比**：对高纬 Borealis 论证"活动百叶/落叶树"优于固定挑檐，并量化可调节带来的额外收益（回答"设计如何随气候改变"）。
4. **遮蔽率年—日热力图 + 太阳轨迹叠加图**：ICM E 极吃可视化，这两张图能让评审一眼看懂你的遮阳在何时生效。
5. **天文解析校验表**：把夏至/冬至/春分的理论高度角与模型输出并列，展示严谨性——这是**低成本高回报**的严谨性展示。

### 高频失分点
1. ❌ **只考虑夏季制冷，忘记冬季采暖损失** —— 本题最本质的错误，直接导致"遮阳越深越好"的荒谬结论。
2. ❌ 太阳位置公式用错（纬度/赤纬/时角符号混乱、南北半球未区分、未做真太阳时修正），导致影子全错，后续全废。
3. ❌ 忽略散射与地面反射，只算直射 → 高纬阴天为主的气候下误差极大（散射常占总辐射 40–60%）。
4. ❌ 两校只改了个纬度数字，**没有真正讨论气候差异**（湿度、云量、雪地反射、供暖度日数），对比流于表面。
5. ❌ 不给气象数据来源或用不可复现的数据（题目要求可获取、规范引用）。
6. ❌ 只给最优解数值，不画"挑檐深度—能耗"曲线，无法展示权衡结构。
7. ❌ 忘记"给校方建议"的落地环节（造价、可施工性、改造 vs 新建）——ICM 重视现实可行性。

## ⬛ ICM F：To Gen-AI, or Not To Gen-AI（生成式 AI 对职业的影响）

**题型定位**：**社会科学建模 / 政策分析 + 综合评价**。参赛 1,776 队、O 奖 4 个（**≈0.23%，六题中单题 O 奖率最高**）。开放度全场第一、难度全场最低——**是"以写作与论证取胜"的题**，最适合把「质量三支柱」发挥到极致的队伍。

> ⚠️ **本题的评分几乎完全由"论证是否严密 + 论文是否好读"决定**，因为模型本身门槛低、人人都能建。所以：`logic-rigor.md` 与 `paper-quality-gate.md` 在本题的权重比其他任何一题都高，**务必逐条过闸**。

### 交付目标
- **一句话**：选择**三种职业**（题面指定覆盖 **STEM / 技工（trade）/ 艺术（art）** 三类），建立数据驱动模型评估生成式 AI 对其的影响，并对教育/课程改革提出建议。
- **典型分问结构**：① 定义 AI 影响的可测量指标；② 建立职业任务—AI 能力的匹配模型，量化替代/增强程度；③ 预测未来若干年的就业与技能需求变化；④ 对三种职业分别给出结论；⑤ 给教育机构的课程改革建议。

### 模型链（核心：任务级分解，别停在"职业级"）
- **关键洞察｜AI 影响的单位不是"职业"，而是"任务"**：一个职业由多个任务（task）构成，AI 对不同任务的可替代性差异巨大。这是劳动经济学的标准做法（Autor–Levy–Murnane 框架），也是本题**从"泛泛而谈"跃升到"专业分析"的唯一路径**。
  $$\text{Exposure}_j = \sum_{k\in \text{tasks}(j)} w_{jk}\cdot e_k$$
  其中 $w_{jk}$ 为任务 $k$ 在职业 $j$ 中的时间占比（**O*NET 数据库直接提供**），$e_k$ 为该任务的 AI 暴露度。
- **区分"替代"与"增强"（本题必须做的二分）**：
  - **替代（substitution）**：AI 直接完成该任务 → 岗位需求下降。
  - **增强（augmentation）**：AI 提升该任务效率 → 单位产出人力下降，但也可能因需求扩张而增加岗位（**Jevons 悖论 / 生产率悖论**）。
  - 建议构造**二维象限图**：横轴"技术可替代性"、纵轴"人际/体力/创造性不可替代成分"，把三种职业的各项任务打点 → **一张图讲完全篇核心结论**，是本题最强的可视化。
- **三类职业的预期结论（可作为论证锚点，但须用你的数据自行验证）**：
  - **STEM（如软件工程师）**：**高暴露 + 高增强**。代码生成能力强 → 初级任务大量替代，但系统设计、架构、调试仍需人；净效应可能是"技能要求上移、初级岗位收缩"。
  - **技工（如电工/管道工）**：**低暴露**。任务以**体力操作 + 现场判断 + 非结构化环境**为主，AI 难以替代（受 Moravec 悖论支配：对 AI 而言"感知与操作"比"推理"更难）；AI 主要在诊断辅助、排程、培训上做增强。
  - **艺术（如插画师）**：**高暴露且以替代为主**。生成式模型直接产出成品，商业化中低端需求受冲击最直接；但"作者身份/独创性/品牌"构成不可替代溢价 → 呈**两极分化**（头部溢价上升，中间层被挤压）。
  - 💡 **三者结论方向不同，正是题目选这三类的用意**。若你的模型给出三者同向的结论，几乎肯定是模型太粗——**这是最好的自检信号**。
- **量化方法（择一为主 + 一至二为辅）**：
  - **暴露度指数法（推荐主模型）**：基于 O*NET 任务清单，对每个任务用 rubric 评分（0–1）AI 可执行程度 → 加权得职业暴露度。**必须交代评分规则与评分者一致性**（如两人独立打分 + Cohen's κ），否则被质疑主观。
  - **回归/双重差分（DiD）**：以 ChatGPT 发布（2022-11）为冲击点，比较高暴露 vs 低暴露职业的岗位数/薪资变化。**这是本题最有"因果推断"含量的做法**，也是最能打动评审的一招。需注意平行趋势假设的检验。
  - **系统动力学 / 存量-流量**：劳动力在"传统岗位—AI 增强岗位—新兴岗位"间流动，含培训延迟（教育系统响应有 2–4 年滞后）→ 可预测"技能缺口窗口期"，直接支撑课程改革建议。
  - **情景分析（必做）**：AI 能力进展快/中/慢三情景 × 政策干预有/无 → 2×3 情景矩阵。**开放题必须用情景法替代点预测**，这既是严谨，也规避了"预测未来"的不可证伪陷阱。
- **第 5 问｜课程改革建议（本题真正的落脚点）**：
  - 从模型输出反推：哪些技能的相对价值上升（AI 协作、提示工程、系统性判断、跨域整合、伦理审查），哪些下降（重复性编码、基础绘制、标准化文案）。
  - 建议要**可执行且可评估**：给出"课程模块 + 学时占比调整 + 评估指标"三列表格，而不是"要重视 AI 素养"这类空话。
  - 加分：给出**改革的成本—收益估算**与**实施时间表**，并讨论**风险**（过度押注 AI 技能可能在技术转向时贬值）。

### 数据与获取（本题数据全部公开，无借口不做实证）
- **O*NET Database**（onetcenter.org，美国劳工部，**免费**）：职业—任务—技能三级结构，任务重要性与频率评分。**本题的地基数据。**
- **BLS（美国劳工统计局）**：OES 就业与薪资（分职业分年份）、Employment Projections（十年预测）。
- **学术基准**：Eloundou et al. (2023) *"GPTs are GPTs"*（OpenAI 团队，给出职业 AI 暴露度评分，**可直接引用并与你的评分对照——这是极强的外部验证**）；Frey & Osborne (2017) 自动化概率；Acemoglu & Restrepo 的任务框架；Autor 的技能偏向技术变革理论。
- 招聘市场：Lightcast / Indeed Hiring Lab 公开报告、GitHub/Stack Overflow 开发者调查（AI 工具使用率）。
- 艺术类：Upwork/Fiverr 自由职业市场价格趋势、ArtStation 相关行业报告。

### 求解与 Python 要点
- 数据处理：`pandas` 合并 O*NET 任务表与 BLS 就业表（按 SOC 职业编码 join，**注意 SOC 版本差异，2010 vs 2018 编码不同**，这是最容易出错的技术细节）。
- 暴露度评分：若人工评分，建立 rubric 表并计算 `sklearn.metrics.cohen_kappa_score`。
- DiD 回归：`statsmodels`（`smf.ols('y ~ treat*post + C(occ) + C(year)')`，**用聚类稳健标准误** `cov_type='cluster'`）。
- 系统动力学：差分迭代或 `solve_ivp`。
- 情景模拟：参数网格 + `numpy`，输出情景扇形图（fan chart）。
- 可视化：**替代—增强二维象限散点图**（三职业任务打点，气泡大小=就业人数）、暴露度分布小提琴图、情景扇形图、技能需求变化的斜坡图（slope chart）。

### 检验套路
- **外部效度（本题最重要的检验）**：你的职业暴露度评分与 **Eloundou et al. (2023)** 的公开评分做相关性检验（Spearman ρ）。ρ 高说明方法可信；ρ 低则须解释差异来源。**做了这一步，论文可信度立刻上一个台阶。**
- **评分者一致性**：Cohen's κ / Krippendorff's α，报告数值（κ > 0.6 可接受）。
- **稳健性**：换权重方案（任务重要性 vs 时间占比）、换职业分类粒度、剔除极端职业，看结论方向是否稳定 —— **报告"结论方向不变"比报告数值稳定更有力**。
- **平行趋势检验**（若做 DiD）：冲击前各期处理组与对照组趋势应无显著差异，画事件研究图（event study plot）。
- **反事实合理性**：模型预测的岗位变化率量级应与 BLS 官方十年预测同量级（年化个位数百分比）；若算出"5 年内减少 80%"，几乎必然错。

### O 奖亮点建议
1. **任务级分解 + 替代/增强二分 + 象限图**：一张图讲完三职业的结构性差异，是本题最高效的表达。
2. **DiD 因果识别**：以 2022-11 ChatGPT 发布为断点做准实验，绝大多数队只做描述统计，你做因果 → 直接进第一梯队。
3. **与 Eloundou et al. 公开评分做外部校验**：把"主观打分"变成"可验证的测量"，一举解决本题最大的方法论软肋。
4. **Moravec 悖论解释技工职业的低暴露**：用一句有理论支撑的洞察解释"为什么水管工比程序员安全"，比堆数据更让评审记住。
5. **课程改革做成可评估方案**：模块+学时+评估指标三列表，附成本收益与时间表，真正回应"给教育机构建议"。
6. **明确讨论不确定性与自身局限**：本题预测未来，**坦诚写出"哪些结论稳健、哪些高度依赖 AI 进展速度"**，学术诚实在开放题里是加分项而非减分项。

### 高频失分点
1. ❌ **停在"职业级"泛泛而谈**，不做任务级分解 → 沦为议论文，本题最普遍的死法。
2. ❌ 不区分"替代"与"增强"，把所有影响都说成"AI 会取代人类"，结论粗暴且与数据矛盾。
3. ❌ **暴露度评分完全主观且不交代规则**、无一致性检验、无外部对照 → 整篇建立在拍脑袋数字上。
4. ❌ 给出精确点预测（"2030 年插画师减少 47.3%"）却无置信区间与情景分析 —— 不可证伪，反而暴露不严谨。
5. ❌ 三职业结论同向（都"影响巨大"或都"影响有限"），说明模型没有分辨力。
6. ❌ **价值判断与立场化表达**：写"AI 剥夺艺术家生计"、"应当禁止 AI 绘画"之类 —— 美赛要求**中立、可量化，只谈指标与数据，不下价值判断、不站队**（涉及就业、技术伦理等社会议题时尤须克制）。参见 `mcm-icm-guide.md` 的敏感话题原则。
7. ❌ 数据只用二手报道/媒体文章，不用 O*NET、BLS 等权威一手数据源。
8. ❌ 课程建议写成"应加强 AI 教育"式空话，不可执行、不可评估。
9. ❌ **AI Use Report 忘写或写得敷衍**：本题主题就是 Gen-AI，若你用了 AI 却不规范申报，观感极差。见 `rules-and-deadlines.md`。

### 选题决策建议（结合 O 奖率）
- **求稳拿奖（M 以上）**：C 或 F —— 门槛低、O 名额相对多。
- **冲 O 且有工科硬实力**：**E 是被严重低估的选项**（全场人最少、物理链条清晰、检验容易做扎实、可视化容易出彩）。
