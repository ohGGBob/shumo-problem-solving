# 论文质量硬关卡（支柱三，交稿前必过）

> 定位：把 `bao-paper-writing.md`（写法）与 `innovation-playbook.md`（亮点）合成一道**交稿前必须逐节打勾的关卡**。这道关不是"建议润色"，而是"不过不许交"——它直接决定评审第一印象（摘要）与最终档位（逻辑与创新的可见度）。
> 用法：论文初稿成型后，按下面关卡逐节打勾；任一红项未过，回到对应环节补，不要带病提交。

## 两档用法（护住 72h 节奏，别每一问都跑全量关卡）

- **mini-gate（每问初稿，往下走之前过）**：只勾下面 4 条，全过即进入下一问（知道求什么→用什么模型→得到什么数 / 结果过了 sanity check / 假设与模型双向自洽 / 至少 1 个亮点有证据雏形），**此刻不跑全量表**。
- **full gate（定稿，交稿前过）**：关卡一至五全绿 + 关卡六百分制评分 ≥85 + 主 SKILL「交稿前自检收口」七道关，才允许提交。
- 判据口诀：**初稿"能讲清楚"，定稿"能扛住查"**。别在 D2 半夜为了勾满五张表而拖慢建模节奏。

## 关卡一 · 摘要四要素（评审第一关口，半页/一页）

| 检查项 | 通过？ |
|---|---|
| 每问都有「命名模型 + 核心公式/指标 + 具体数字（带单位/置信）」 | ☐ |
| 覆盖问题—方法—结果—结论四要素，无空缺 | ☐ |
| 含 ≥1 个量化灵敏度结论（如"±10% 扰动下结论稳健"） | ☐ |
| 敢写负结果 / 局限，不堆"首先/其次/最后"套娃 | ☐ |
| 美赛：200–250 词、bullet 式、显式误差/置信 | ☐ |

## 关卡二 · 表图三件套（每图每表必过）

每一张图表都要配齐三件套，缺一即不合格：

- **引出句**：正文明确"如表 5 / 如图 3 所示"引出，不凭空出现。
- **图表本身**：三线表 / 规范图，带完整标题、坐标轴标签、单位、图例、≥300 dpi（用 `figcheck.py` 查）。
- **解读句**：给出量化结论（占比、人数、排名、误差），图注能独立传达结论。

| 检查项 | 通过？ |
|---|---|
| 每张表/图都有引出句、图注独立可读、解读句带数字 | ☐ |
| 无"无标题/无单位/低分辨率"图 | ☐ |
| 解读句不重复图注文字，而是给出"所以…"的结论 | ☐ |

## 关卡三 · 模型命名与设计意图（国一 vs 国二的分界）

| 检查项 | 通过？ |
|---|---|
| 每个核心模型都有可引用名字（FMS / Model I/II/III / 自创指标） | ☐ |
| 阈值/评分体系写清"怎么定 + 为什么这么定"（如区间拉大的理由） | ☐ |
| 问题分析写成「数据→字段→方法→指标」操作链，非"本题属 XX 类"空判定 | ☐ |
| 假设写成一句可辩护的数值规则/独立判断 + 理由，非"忽略次要因素"空话 | ☐ |

## 关卡四 · 创新与落点（支柱二的可见化）

| 检查项 | 通过？ |
|---|---|
| 全文有 2–3 个扎实亮点，且每处都有数据/证明支撑 | ☐ |
| 至少有一个亮点是"多模型对照择优"或"一处理论改进/性质证明" | ☐ |
| 检验写成证据链（蒙特卡洛/最坏情形/基准对比），并解释"为什么" | ☐ |
| 优缺点：优点动作化、缺点机制化 + 诚实负结果 | ☐ |
| 落点写成"对谁、做什么、预期效果"的可执行建议，非"可推广"空话 | ☐ |

## 关卡五 · 降 AI 味 / 降重（交稿前最后一道）

配合 `writing-deai-dedup.md` 与 `dedup_scan.py`：

| 检查项 | 通过？ |
|---|---|
| 摘要/重述/评价/结论四块过 AI 味检测，无套娃词、零信息句 | ☐ |
| 问题重述转述不抄题面原句 | ☐ |
| 全文 ≥3 处"做事痕迹"（具体参数/踩过的坑/做过的选择） | ☐ |
| 查重率达标（国赛双重查重口径） | ☐ |

## 关卡六 · 百分制定稿评分（量化收口，对标社区"≥85 才定稿"实践）

五张表是"逐项打勾"，这一关是**给全文打一个总分**——把主观感受变成可比较的数字，防止"我觉得挺好就交了"。

| 维度 | 分值 | 评分依据 |
|---|---|---|
| 摘要 | 30 | 结构完整、数值具体、递进关系、与正文一致（对应关卡一；摘要占大头符合评委"先看摘要定档"的习惯） |
| 模型与求解正确性 | 20 | 推导无误、约束完备、结果合理可复现（铁律二） |
| 创新性 | 20 | 方法创新、跨学科融合、自定义指标构建（对应关卡四，支柱二） |
| 写作能力 | 15 | 逻辑连贯、学术语态、数据支撑、无 AI 痕迹（对应关卡三/五） |
| 排版规范 | 15 | 版式/图表/符号一致/匿名合规（对应 `typesetting-delivery.md` 自查清单） |
| **合计** | **100** | **≥85 分才允许定稿输出** |

**评分循环规则**：

1. full gate 五张表全绿后，按上表打一次分（诚实打分，宁低勿高）；
2. `<85` → 列出**具体扣分项**（如"摘要 24/30：缺灵敏度量化结论 -3"）→ 回对应关卡补 → 重评；
3. **最多循环 3 轮**——3 轮仍 <85 说明是建模层缺陷，回 `mid-contest-warning.md` 做取舍，别在文字层无限打磨；
4. 72h 只剩 2h 时：跳过循环，只修**扣分最多的单一项**（通常是摘要），然后直接交。

> 五张表（关卡一~五）全绿 + 评分 ≥85 = 论文质量达到可提交档位。任一红项 = 回到 `bao-paper-writing.md` / `innovation-playbook.md` 对应节补做，禁止"差不多就交"。
