# 国赛 C 题数据链深度（数据挖掘题的拿分手册）

> C 题是本科生组**最卷的赛道**：上手快、人人能做，但国一靠的是「数据素养 + 可解释闭环」。评委最烦"直接塞 sklearn 黑箱 + 报个准确率"。这份是 C 题从清洗到可解释的完整链路，配 `code-templates.md` 的 §10 和历年 `cases-<年>.md` 使用。

## 一、先懂 C 题阅卷心理（评委到底看什么）

1. 数据清洗**有没有讲道理**（缺失/异常怎么处理，不能一句"删除"带过）
2. 有没有**交叉验证 + 误差估计**（拒绝只报单点准确率）
3. 有没有**可解释性**（回扣业务机制，不是黑箱）
4. 有没有**基准对比**（证明你的模型比"用均值/上年同期"更准）
5. 结果**业务上说得通**（数字合理、结论可落地）

## 二、数据清洗：讲清楚「为什么这么处理」

> ⚠️ 清洗必须是**文件级流水线**（探查脚本 print 一堆统计 ≠ 清洗）：逐列缺失/异常/编码决策 + 审计表（missing_report/outlier_scan）+ 改完重跑全链核对论文数字。硬性清单与 2025 C 题事故复盘见 `preprocessing-pipeline.md`。

- **缺失值**：先判断缺失机制（随机缺失 MCAR 还是非随机）。少量删；中量填充（中位数/众数/KNN，**别拍脑袋填 0**）；大量缺失→设"缺失指示变量"。**成分/占比数据缺失尤其别乱填 0**（2022 C 玻璃题血泪）。
- **异常值**：IQR 法则（Q1−1.5·IQR, Q3+1.5·IQR）或 3σ 找；但**先业务判断**——销量激增可能只是促销，别当异常删了。
- **标准化**：z-score / min-max / log 按需选。
- ⚠️ **成分/百分比数据的闭合约束**：各成分占比总和≈100%，把它们当绝对含量做统计会系统性翻车（分母变小→表观"富集"伪象）。有这种数据先做 **log-ratio / 归一化**再建模。

## 三、特征工程（C 题拉开差距的地方）

- **时间特征**：趋势、季节、**滞后项**、滑动窗；销量预测必带"去年同期/上一期"做基准。
- **业务特征**：损耗率、需求价格弹性（lnQ = a + b·lnP，b 应为负）、毛利、库存比。
- **构造特征**：比值/组合/交叉项（如"单价×批发价"），但**先少后多**，堆太多特征会过拟合。

## 四、建模：从可解释到复杂（先上线性给基线）

1. 第 1 步：**线性回归 / 逻辑回归 / 岭回归**——先给一个可解释、可汇报的基线。
2. 第 2 步：再上 **RandomForest / XGBoost / LightGBM** 提精度。
3. 第 3 步：两者横向对比，说明"为什么复杂模型更优（且优得值）"。
4. 时间序列：ARIMA/SARIMA/Prophet，**必须和 naive 基准比**（§2 模板已含）。
- 别一上来就深度学习/大黑箱：数据量小、可解释性差，评委不买账。

## 五、检验（C 题的生死线）

- **交叉验证**：分类用**分层 K 折**；时序用**按时间顺序/滚动**验证（严禁随机打乱）。
- **报告口径**：分类报**混淆矩阵 + AUC/召回/F1**（类不平衡时准确率毫无意义）；预测报 MAPE/RMSE + **置信区间**。
- **闭环回测**：把「预测 → 决策 → 收益」整链在历史数据上回测，和"按实际销量进货"的基准比收益增量——证明决策模型确有提升（2023 C 的拿分点）。
- **多分类器集成 + 交叉验证**报稳健。
- ⚠️ **严禁标签泄露**：不许用全量数据选特征后再"验证"（看似很高，实则作弊）。

## 六、可解释性（国一加分项，把黑箱变白）

1. **特征重要性**（`rf.feature_importances_`）排序。
2. **SHAP 值**：全局看哪些特征主导 + 单个样本看"为什么这么判"。
3. **回扣业务机制**：数据结论 + 机制解释两头对——如"价格每涨 1%，销量降 0.8%，符合需求定律"（2023 C）；聚类亚类回扣考古先验"铅钡助熔剂、铜着色"（2022 C）。
4. **区间预测**替代点预测，体现不确定性量化（2025 C、2022 C 都是加分点）。

## 七、C 题红线（翻车点，一个都别踩）

1. 预测无回测、无基准；2. 只报准确率且类不平衡；3. 标签泄露；4. 百分比成分当绝对量（闭合约束）；5. 物理链建错——收率=转化率×选择性（2021 B Y=η·s）、进货=销量/(1−损耗率)（2023 C）；6. 纯黑箱不可解释。
