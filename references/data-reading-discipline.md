# 数据完整性纪律（铁律四 · 不读完不算懂，读全再判断）

> 定位：解决"没仔细读完全部数据甚至漏了数据就开始判断 / AI 幻觉严重"的实战翻车。
> 数据是题目的**事实库**——任何判断、任何数字、任何"数据表明…"的结论，都必须建立在
> **对全部数据文件的完整读取**之上。本文件把"读全数据"从口号变成三条可核查的纪律。

## 一句话原则

**不读完不算懂，读全再判断，数字必有出处。** 没进数据清单的数据 = 还没读的数据，
不许进建模；说不出来处的数字 = 幻觉，删除或补证据。

## 三条纪律

### 纪律一 · 数据清单先行（拿到数据第一件事）

拿到全部数据附件后，**先建数据清单，再谈建模**：

1. 把每个附件（xlsx/csv/PDF/txt）都登记进 `report/data_inventory.md`；
2. 每个表登记：文件、sheet 名、行数 × 列数、列清单、缺失情况（用 `data_profiler.py --inventory` 全量扫，别手敲）；
3. 清单覆盖不到的附件/表 = **还没读**，禁止进入建模环节。

> 判断标准：清单上的"表清单"必须与 `data/` 目录里的实际文件一一对上——**有一个文件没登记，就是没读完**。

### 纪律二 · 判断必有出处（反幻觉）

每个来自数据的数字 / 每个"数据表明…"的结论，必须能回答三问：

1. **哪个文件？**（data/supplier.xlsx）
2. **哪张表哪一列？**（Sheet1「周均供货(吨)」）
3. **什么口径？**（全量均值 / 某分类子集 / 去缺失后）

- 答不上来 = 幻觉 → **删除或补证据**，不许"大概 / 我记得 / 印象里"带过；
- 论文里出现的每个数据数字，先在 `data_inventory.md` / 原始文件里找到出处再写；
- 数据里**没有**的数：要么不写，要么明确标"估算（口径：…）"，绝不当事实报。

### 纪律三 · 漏读自查（建模前必过）

每问动手前 30 秒自查，三条不过不许建模：

- [ ] 附件**全读了**吗？——有没有 xlsx/csv 没打开、sheet 没看、PDF 某页没读？
- [ ] 该问依赖的数据**读全**了吗？——时间范围 / 分类 / 分组的每个子集都在清单里？
- [ ] 有没有"这个数据没用上"？——要么用上，要么写一句"为何不适用"，不许无声忽略。

## 幻觉高发场景（每条都是真实翻车实录）

| 场景 | 后果 | 正确做法 |
|---|---|---|
| 只读前几行 / 前几张表就总结全貌 | 把子集当全集，漏掉关键规律 | 先 `--inventory` 全量扫，确认行列数后再下结论 |
| 把表头 / 备注行当数据 | 脏数据进模型 | 概览输出里的"样例行"先核对，识别表头、单位行、汇总行 |
| 漏了某个 sheet / 某个附件 | 关键变量完全缺失 | 清单与目录逐文件对照，缺一即补读 |
| 凭训练记忆报数据（"这类题一般…"） | 编造本题没有的数 | 一律回文件确认；没有就标估算 |
| 读了一个文件就以为读完全部 | 多文件关联漏链 | 多文件必须跑 `--inventory` 看"候选关联键"再建模 |
| 数值列被识别成常量 / 全缺失没察觉 | 模型空转 | 概览输出里的"常量列 / 高缺失列"提示逐条处理 |

## 标准动作序列（读数据，照走）

```bash
# ① 全量扫 + 生成数据清单（机器可核对）
python scripts/data_profiler.py data/ --inventory --out report/data_inventory.md
# ② 读清单：确认文件/sheet/行列数一一对应，无遗漏
# ③ 逐表细读：对每个要用的表跑概览看分布/缺失/常量/关联键
python scripts/data_profiler.py data/supplier.xlsx
# ④ 逐问建模前，过"漏读自查"三条；每个数字回数据找出处
```

## 与铁律二的关系

铁律二管"**论文里的数字能回溯到代码**"（results.json 单一来源）；
铁律四管"**代码里的数字能回溯到数据**"（data_inventory 单一来源）。
一条链：**数据文件 → data_inventory → 代码 → results.json → 论文**，每一环都有出处，
任一环断了就是幻觉入口。
