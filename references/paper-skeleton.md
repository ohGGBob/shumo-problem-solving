# 国赛 / 美赛论文骨架 + 摘要模板 + 提交检查清单

## 国赛（CUMCM，中文）章节骨架

| 章 | 写什么 | 易扣分点 |
|---|---|---|
| 摘要 | 独立一页，四要素 | 缺数值、挂图、超一页 |
| 一、问题重述 | 用自己的话重述，不抄题 | 大段原文 |
| 二、问题分析 | 每问 → 类型 → 初步思路 | 与正文模型脱节 |
| 三、模型假设 | 分条 + 理由 + 失效影响 | 假设堆砌无理由 |
| 四、符号说明 | 三线表；全文一致 | 符号前后不一 |
| 五、模型建立与求解 | 每问一小节：模型 → 算法 → 代码要点 → 结果 | 只摆公式无过程 |
| 六、模型检验 | 灵敏度 + 误差 + 对比 | 缺失（硬伤） |
| 七、模型评价与推广 | 优点 / 局限 / 推广 | 只说好不说局限 |
| 参考文献 | 规范著录（GB/T 7714） | 乱列 |
| 附录 | 代码 + 数据说明 | 代码无法复现 |

## 摘要四要素填空模板（国赛）

> 本文针对____（问题一句话）。在第一问中，____（方法 / 模型）；第二问……（依次覆盖每问）。结果表明____（带具体数值），____（结论：有效性 + 灵敏度表现 + 可推广方向）。

要点：方法要和正文一致；结果必须量化；不要把摘要写成目录。

## 美赛 Summary Sheet（英文，单页）

- Para 1：问题 + 一句话总思路。
- Para 2..N：每题用 1–2 句写 Model + Key Results（数字）。
- 最后：sensitivity / strength / limitations 各一句。
- 术语规范、句式清晰；独立可读（不看正文也懂结论）。

## 国一论文得分点（评委视角，照着写）

国赛评审的给分点可归纳为「摘要—模型—求解—检验—规范—特色」六个维度（经验性归纳，非官方逐字细则），权重感大致如下：

| 维度 | 权重感 | 拿分关键 |
|---|---|---|
| 摘要 | 高（单独评审） | 四要素齐全、每问都有数值、逻辑自洽、一页内 |
| 模型合理性 | 高 | 假设有据、模型与问题匹配、说清范式选择理由 |
| 求解完整性 | 中高 | 算法实现 + 数值结果 + 代码可复现 |
| 检验可信度 | 中高 | 灵敏度 + 误差 + 稳定性 + 与基准对比 |
| 规范性 | 中 | 图表、符号表、引用、排版、公式编号 |
| 特色 / 创新 | 加分项 | 独到建模角度、更优算法、出色可视化 |

**模范论文（国一）的共性**：

- 摘要第一段即给出「问题—方法—结果」闭环，评委 30 秒读懂。
- 假设少而精，每条都"可辩护、有作用"，并讨论失效影响。
- 每问一条完整链：问题 → 模型 → 求解 → 结果 → 检验，公式与数值不脱节。
- 灵敏度分析必做且量化（图 + 表），指出敏感参数。
- 图表专业：建模总流程图 + 每问结果图 + 灵敏度图；三线表；≥300dpi。
- 诚实：主动写局限与可推广方向，不夸大、不编造。

## 必交图表清单

- 一张「建模总流程图」（开篇加分，一眼看懂思路）。
- 每题至少一张**结果图**（曲线 / 柱状 / 热图，≥300dpi，有标题、坐标轴标签、单位、图例）。
- 至少一张**灵敏度分析图**（参数 → 结果）。
- 表格一律三线表；数值保留适当有效数字。

## 提交前检查清单

- [ ] 摘要是否覆盖四要素且含数值？
- [ ] 每问：模型 + 算法 + 结果 闭环？
- [ ] 灵敏度 / 误差分析是否做了并写进正文？
- [ ] 符号表与正文公式一致？
- [ ] 图有标题 / 单位 / 图例，表为三线表？
- [ ] 代码可复现（种子固定、路径清晰），附录与正文数据一致？
- [ ] 无编造数据 / 文献；结论有依据？
- [ ] 页面大小 / 编号 / 引用符合赛题要求？
