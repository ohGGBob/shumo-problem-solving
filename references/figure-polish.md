# 科研图表美化手册（国一图与国二图的分界）

> 定位：`figures-and-abstract.md` 讲「图表该有哪些、图注三件套怎么写」——那是**规范层**（不过线扣分）；本文件讲「怎么把图画好看」——这是**美学层**（做对直接加分）。美观不是玄学，是一套可复制的参数 + 决策表。
> 配套：`scripts/plot_style.py`（一键风格/配色/中文字体探测/统一导出）、`code-templates.md` §14（matplotlib 画图示例）、`scripts/figcheck.py`（交稿硬检）。评委快速阅读，一张出彩的图抵得过两页正文叙述。

## 0. 国赛图的三档（先定位自己到哪一档）

| 档 | 特征 | 效果 |
|---|---|---|
| 能看 | matplotlib 默认风格、Excel 默认图 | 不扣分也不加分 |
| 规范 | 三线表、标题/单位/图例齐全、≥300dpi、图注可独立读 | 不扣分 |
| **出彩** | 配色统一克制、字号与版面匹配、一张图只讲一个结论、关键点被标注 | **肉眼可见地上档次，抢分** |

目标不是炫技，是让评委 **30 秒看懂 + 觉得你专业**。下面第 1–5 节是"出彩"的五个可复制抓手，第 6 节是死穴清单，第 7 节是完整流水线。

## 1. 一键风格（复制即用，国赛中文图）

不要每张图临时调参，文件头统一 `import plot_style as ps; ps.apply_style()`。其等价 rcParams 如下（或直接用脚本）：

```python
import matplotlib as mpl
mpl.rcParams.update({
    'font.sans-serif': ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC', 'WenQuanYi Zen Hei', 'PingFang SC', 'Arial Unicode MS'],  # 中文，按系统命中
    'axes.unicode_minus': False,      # 负号不乱码（豆腐块 □）
    'font.size': 9,                   # 正文 8–10pt；图以 1:1 嵌入，这就是评委看到的字号
    'axes.titlesize': 10, 'axes.labelsize': 9,
    'xtick.labelsize': 8, 'ytick.labelsize': 8, 'legend.fontsize': 8,
    'figure.dpi': 110, 'savefig.dpi': 300,   # 导出 300，过 figcheck
    'axes.linewidth': 0.7, 'lines.linewidth': 1.6,
    'axes.grid': True, 'grid.alpha': 0.28, 'grid.linestyle': '--', 'grid.linewidth': 0.5,
    'legend.frameon': False,          # 图例无边框
    'xtick.direction': 'out', 'ytick.direction': 'out',
    'axes.spines.top': False, 'axes.spines.right': False,   # 去右上 spine（若支持）
})
```

**中文字体跨平台是关键坑**：SimHei 只在 Windows；Linux 用 Noto CJK、mac 用 PingFang。别写死一个字体，让 `plot_style.find_cjk_font()` 探测本机可用的第一个，命中后 `mpl.rcParams['font.sans-serif'] = [命名字体]`。**出现豆腐块 □ 就是字体没命中**，先跑探测别硬画。

**美赛英文图**：跳过中文字体这步即可，其余风格参数照用（英文字体 DejaVu 默认就够）。

## 2. 配色（色盲友好 + 期刊风，别再彩虹默认色）

三条铁律：**同色系表达"程度"，不同色相表达"类别"，一个强调色表达"结论指向"**。

| 场景 | 用 | 代码 |
|---|---|---|
| 分类 / 不同模型对比（≤8 类） | Okabe-Ito 8 色（色盲安全）| `ps.COLORS` 或硬编码表 |
| 数值低→高（热图、等高线） | viridis / cividis（等亮度、色盲安全）| `cmap='viridis'` |
| 有正负/零点的发散（相关矩阵 ∈[−1,1]） | `RdBu_r`（配数值标注，别只靠颜色）| `cmap='RdBu_r', vmin=-1, vmax=1` |
| 单变量系列 + 一个突出项 | 灰阶 + 一个强调色（如 #D55E00）| 突出项 `color=ACCENT, lw=2.2` |

Okabe-Ito 8 色（直接抄）：
```
#E69F00 橙   #56B4E9 天蓝   #009E73 青绿   #F0E442 黄
#0072B2 蓝   #D55E00 朱红   #CC79A7 紫红   #000000 黑
```

- **禁用**：默认 tab10 彩虹、`jet`、高饱和霓虹色、Excel 蓝橙默认配对。
- **全论文颜色一致**：同一个变量/同一模型族，在所有图里用同一个颜色（这也是 `reproducibility.md` 输出治理的一部分）。
- 色弱警告：发散色（RdBu）对少数色盲不友好，**关键数值要直接标注在图上**，不要只靠颜色传达。

## 3. 图尺寸与字号（与版面 1:1，别缩放）

国赛 A4 单栏排版，正文宽约 **16 cm ≈ 6.3 in**，页边距约 2.5 cm。

- 图以 **1:1 嵌入**（不缩放），所以 rcParams 的字号就是评委看到的字号 → 正文统一 **8–10pt**（轴标签 9、刻度 8、图例 8），别设 14pt 的"屏幕字号"再缩进论文变成蚂蚁字。
- 常用 `figsize`（宽, 高，比例黄金比 ≈1.618 或 4:3）：
  - 通栏（占满一行）：`(6.0, 3.7)`
  - 半栏（一行两图并排）：`(3.1, 2.3)`
  - 全景大图（总流程/热图）：`(6.3, 4.5)`
- 一个子图讲一件事；确实要对比 → 用 `same x/y 范围` 的 `plt.subplots(1, n, sharex/sharey)`，别堆 6 条线 + 双 y 轴。
- 双 y 轴只在"两个量纲不同但高度相关、必须同框"时才用，且两条轴、两条曲线颜色一一对应，图例写清楚哪条对哪轴。

## 4. 图类型决策表（绑定国赛高频场景）

| 你要表达 | 首选用图 | 国赛典型场景 | 避坑 |
|---|---|---|---|
| 时间趋势 / 曲线 | 折线（关键线加粗 + 数据点） | 预测曲线、销量走势 | 点太密别每点都标 marker |
| 模型拟合 vs 实测 | 散点(实测) + 线(拟合) + 置信带 | 参数辨识、回归 | 补 `fill_between` 阴影做误差带 |
| 灵敏度 | 龙卷风图 / 单参数摄动折线 | 损耗率/权重 ±20% | 标出敏感参数 + 区间 |
| 模型/方法对比 | 分组柱状 + 误差棒 + 数值标签 | 各方法误差对比 | 柱高必须从 0 起，否则误导 |
| 收敛 / 迭代过程 | 折线 + 标记最优 | 遗传/粒子群收敛 | 报均值 + 方差 |
| 相关矩阵 | 热力图(发散色) + 数值 | 指标相关性 | 数值写进格子，不只靠颜色 |
| 分布 / 离散 | 箱线 / 小提琴 | 分组差异 | 样本少就别用箱线，用散点 |
| 综合评价结果 | 雷达图 / 平行坐标 | 熵权-TOPSIS 排序 | 指标 ≤8 个，否则糊 |
| 网络 / 结构关系 | 节点-边图 / 桑基 | 路网、物流、文本关联 | 强关系才用图论，别硬套 |
| 流程 / 框架 | 流程图（论文第一张加分图） | 建模总流程图 | 逻辑单向、方框分级 |
| 两个量的面函数 | 等高线 / 3D surface | 热传导温度场 | 等高线标数值层级 |

## 5. 出彩细节清单（把"画了"变"设计过"）

- [ ] 去右上 spine（`ax.spines['top'/'right'].set_visible(False)`），网格淡化（alpha 0.28、虚线）。
- [ ] 关键曲线 `lw=2.2` 实色；辅助线 `lw=1.2` 灰色；别全图一样粗细。
- [ ] 关键点用 `ax.annotate('19.43 元', xy=..., xytext=...)` 标出具体数值 + 箭头。
- [ ] 误差/置信用 `fill_between(..., alpha=0.2)` 而非一堆杂线。
- [ ] 图例放图内空白角落（`loc='best'`），无边框；遮挡数据时移到图外 `bbox_to_anchor=(1.02,1)`。
- [ ] 柱状图从 0 起；线图可从数据范围起（否则夸大波动）。
- [ ] 刻度格式统一：百分比 / 千分位 / 科学计数，`axis.set_major_formatter`。
- [ ] 有效数字统一 2–3 位（不要 19.431 vs 6.2% 混搭）。
- [ ] **图内不写「图 3 xxx」标题**——标题留给论文题注（三件套），图上标题会重复 + 占版面。
- [ ] 三线表进阶：列右对齐 + 表头单位 + 显著性星号 + 表注（n 与口径），见 `figures-and-abstract.md`「一·1 三线表」。
- [ ] 所有图统一风格（同一 rcParams、同一配色、同一字号），别一图一风格。

## 7. 一张"出彩图"的流水线（照做，别跳）

1. 读数据 → 想清楚**这一张图只回答哪一个结论**（没结论就别画）。
2. 选型：查 §4 决策表。
3. 配色：查 §2，定全论文用色。
4. 风格 + 尺寸：`plot_style.apply_style()` + §3 定 `figsize`。
5. 画 + 细节：过一遍 §5 checklist。
6. 导出：`plot_style.save_fig(fig, 'res_q1.png')`（自动 300dpi + `bbox_inches='tight'`）。
7. 硬检：`scripts/figcheck.py`。
8. 图注三件套：回 `paper-quality-gate.md` 关卡二 写「引出句→图→解读句」。

## 8. 复制即用模板（`plot_style.py` 内置，这里给骨架）

见 `scripts/plot_style.py` 的 `demo()`；核心三张"抢分图"的成品范式：

- **拟合 vs 实测**：散点 + 拟合线 + `fill_between` 置信带 + 标注 R²/MAPE。
- **灵敏度龙卷风**：横排 `barh`，正影响一种色、负影响另一种色，标注 ±20% 下的取值。
- **方法对比**：分组柱状 + 误差棒 + 柱顶数值，比较对象同口径。

> 三张图的完整可跑代码放在 `scripts/plot_style.py` 的 docstring/`demo()` 里，赛前照跑一遍，赛场上直接改数据。

## 9. Figure Contract（画图前的四行合同，对标社区最佳实践）

**多图翻车的根因是"先画再想"**。动手写绘图代码前，先给这张图立一份四行合同（写在草稿或注释里，30 秒）：

1. **核心结论**（一句话）：这张图只回答哪个问题？例：「α∈[0.4,0.6] 内冠军不翻转」——写不出这一行就别画这张图（对应 §7 第 1 步的合同化）。
2. **证据链**：每个面板/序列对应 `results.json` 里的哪个键？（铁律二：图上的每个数字都要能回溯到代码，画图脚本禁止手敲数据。）
3. **面板映射**：单面板图证据从左到右怎么排？双子图哪块放主结果、哪块放对比/残差？（不对称布局别硬对称，评审风险见下。）
4. **评审风险自查**：坐标轴截断会不会夸大差异？误差棒/置信带缺了会不会被挑"不报不确定性"？色盲友好吗（§2）？黑白打印还能区分吗？

**双格式导出约定**：正式图一律 **PNG 300dpi（投稿）+ SVG（矢量，`svg.fonttype='none'` 文本可编辑）**双份——SVG 留给"评委要放大看"和后期改字号，PNG 保证任何阅读器渲染一致。`plot_style.save_fig()` 存一份 PNG 后，加 `fig.savefig('同名.svg', bbox_inches='tight')` 即可。

> Contract 不是形式主义：它把「图与结论的显式映射」提前到画图之前，正是支柱三「每张图有解读句回指结论」的上游保障——合同立好了，§7 流水线和图注三件套只是照单执行。

## 10. 图表用途四分类与数量纪律（对标社区 figure-table-planner，v1.9.2）

画图前先给每张图**定用途身份**，四类各归其位——最常见的翻车是把 debug 图顺手贴进论文：

| 类型 | 用途 | 去向 |
|---|---|---|
| **诊断图** | 调参/排错用的中间产物（残差散点、损失曲线、收敛过程） | 只留在工作目录或备份目录，**绝不入正文**（有叙事价值时降级重画成附录图） |
| **对比图** | 方法/模型横向对比（本文模型 vs 基线 vs 备选） | 正文或附录，配合 `judge-view.md` 模型对比表 |
| **论文图** | 直接支撑某问结论的主结果图 | 正文，每张对应一个明确结论（§9 合同第 1 行） |
| **附录图** | 稳健性/补充材料（全参数灵敏度、大图拆分） | 附录，正文引用处标「详见附录图 X」 |

**数量纪律**（评委一天看几十篇，审美疲劳是真实扣分项）：

- **同类型图 ≤3 张**：三张灵敏度龙卷风图不如一张 + 一段文字；同质图合并成双子图（`sharex/sharey`，§3）。
- **每张图后必跟一段分析文字**：「图 X 显示…（现象），因为…（机理），因此…（回指结论）」——只放图不解读 = 白画，评委默认你没看懂自己的图。
- 全文正文图 6–10 张为宜：少于 6 张说明证据链偏薄，多于 10 张考虑往附录搬（排量紧张时见 `mcm-icm-guide.md` 排版省页技巧）。
