## 二、三大主线赛事详解

### 1. 国赛 CUMCM（高教社杯）—— 含金量最高的国内赛
- **主办**：中国工业与应用数学学会（CSIAM）；本科组 A/B/C，专科组 D/E。
- **打法**：**机理严谨 + 求解正确 + 检验到位**。评审最看重"模型对不对、检验做没做"，创新是加分而非门槛。
- **篇幅**：无硬上限，实际 15–25 页为常态（含附录代码）。
- **详见**：`rules-and-deadlines.md`（72h 倒排表）、`cases-2021.md`~`cases-2025.md`（真题）、`cumcm-years.md`。

### 2. 美赛 MCM/ICM —— 国际赛，另一套评分逻辑
- **打法**：**创意 + 合理 + 清晰 + 可视化**。不要求算法新颖，但要求"一张令人印象深刻的图 + 一个讲得通的故事"。
- **⚠️ 2027 新规**：**总页数 25 页硬上限**（含摘要页/目录/参考文献/附录/代码），AI Use Report 不计入。**旧的"附录随便塞代码"打法已作废。**
- **详见**：`mcm-icm-guide.md`（含 25 页页面预算表 + 交稿终检）、`cases-2026-mcm.md`（2026 六题深度解析 + O 奖率）。

### 3. 研赛（华为杯，中国研究生数学建模竞赛）—— 研究生专属，工程味最重
- **主办**：中国学位与研究生教育学会；秘书处在东南大学；2026 年第 23 届由**西安交通大学**承办。
- **报名平台**：**研创网** `cpipc.acge.org.cn`（报名/审核/缴费/提交论文全流程）。
- **对象**：在读硕博 + **将于当年秋季入学的新生**（3 名成员全为新生的队**可以跨校组队**，其余年级不可跨校）。
- **时长 100 小时**（9.23 08:00 – 9.27 12:00），比国赛长 28 小时。
- **特殊流程**：需**提前一天（9.22 08:00 起）下载试题 ZIP 包 + MD5 校验工具**，并按要求提交论文 MD5 码 —— ⚠️ **这是国赛没有的环节，漏做会出事**，务必赛前演练一遍。
- **打法**：题目来自工程技术与管理科学的实际问题，**数据量大、工程细节多**。100 小时够做扎实的数值实验，评审也期待更深的求解与检验。

## 三、按"打法"分类（决定你要调哪套方法论）

| 类型 | 代表赛事 | 核心打法 | 重点参考文档 |
|---|---|---|---|
| **中文·机理严谨型** | 国赛、研赛、电工杯 | 模型正确 + 检验充分 + 复现可靠 | `logic-rigor.md`、`validation-checklist.md`、`reproducibility.md` |
| **英文·叙事可视化型** | 美赛、小美赛、APMCM 英文、数维杯国际 | 创意 + 清晰 + 图表 + Summary Sheet | `mcm-icm-guide.md`、`figures-and-abstract.md` |
| **企业实际问题型** | MathorCup、大湾区杯、MathorCup 大数据 | 落地性 + 数据处理 + 业务解释 | `data-science-playbook.md`、`preprocessing-pipeline.md` |
| **超长周期·论文型** | 深圳杯、东北三省联赛、数据分析大赛 | 可做到准论文深度，重文献与创新 | `innovation-playbook.md`、`bao-paper-writing.md` |
| **短周期·练手型** | 五一杯、华中杯、中青杯、数维杯、认证杯 | 快速成稿、练流程与配合 | `paper-skeleton.md`、`code-templates.md` |

> **重要**：无论哪个赛，**质量三支柱都不变**——逻辑严密性（`logic-rigor.md`）、创新性（`innovation-playbook.md`）、论文质量（`paper-quality-gate.md`）。变的只是页数限制、语言和评审偏好。

## 四、各赛差异化注意事项（容易踩的坑）

| 赛事 | 特别注意 |
|---|---|
| **电工杯** | **查重 >40% 直接取消评奖资格**（明确写在官方通知里）——比多数赛事严格，务必跑 `dedup_scan.py` 并人工改写；72h 而非 4 天，节奏更紧 |
| **美赛** | 25 页含一切（除 AI 报告）；Summary Sheet 独立评审；数据须开放许可；敏感话题保持中立 |
| **研赛** | 提前一天下载试题 ZIP + **MD5 校验与提交**；仅研究生；100h |
| **APMCM** | 中文赛项（6月）与英文赛项（11月）**是两个独立赛事**，别搞混；**允许跨校组队**（少数允许的赛事）；须附**签字承诺书**扫描件 + 支撑材料压缩包 |
| **MathorCup** | 赛区奖 + 全国奖两级；前 20% 推荐至全国奖后**不再参评赛区奖**；允许 1–3 人，也允许**教师队** |
| **深圳杯 / 东北三省** | 共用赛题；周期超长（一个多月），**竞争者有充足时间**，敷衍交稿必然垫底 |
| **认证杯** | 两阶段制，一阶段通过才进二阶段，**别以为一次就结束** |
| 多数商业赛 | 需缴费（如 APMCM 100 元/队）；电工杯、国赛校内组织通常免费 |

## 五、备赛节奏建议（一年周期）

- **1–2 月｜美赛**：主攻。赛前 12 月用小美赛/华数杯国际赛练英文写作与 Summary Sheet。
- **3 月｜复盘期**：整理美赛复盘，补齐模型工具箱（`model-recipes.md`）。
- **4–6 月｜练兵密集期**：MathorCup（企业题）→ 五一杯 → 数维杯 → 电工杯 → APMCM 中文。**挑 2–3 个打，不要全打**，目标是练配合与流程，不是刷奖。
- **7–8 月｜国赛集训**：刷 `cases-2021.md`~`cases-2025.md` 真题，跑通 `init_project.py` 工程流程，定分工与模板；8 月华数杯做最后全流程演练。
- **9 月｜国赛（+研赛）**：主战场。研究生注意国赛与研赛间隔仅 10 天。
- **10–12 月｜转战国际赛 + 美赛备战**：APMCM 英文、数维杯国际、小美赛，同时开始美赛选题与英文写作训练。

> **一个诚实的建议**：赛事很多，但**奖项含金量差异极大**。国赛、美赛、研赛是主线，其余以练兵和积累素材为目的即可。**同一年打 8 个赛且都敷衍，不如打 3 个赛且每个都做扎实**——后者才能真正沉淀出可复用的模型库、代码库和写作能力。
