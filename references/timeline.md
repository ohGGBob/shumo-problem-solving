# 赛程时间轴（国赛 3 天 / 美赛 4 天）

> 用法：读题前先把这张表贴出来当「总进度表」，每完成一阶段更新勾选；硬截止到了没东西，先砍复杂度保可交付，别钻牛角尖。

## 一、国赛 72 小时

| 窗口 | 阶段 | 做什么 | 交付物（硬截止） |
|---|---|---|---|
| D1 18:00–24:00 | 读题·定题 | 逐问读题；选题决策卡打分（`topic-selection.md`） | 每题一句话 + **最迟 D1 24:00 定题** |
| D1 22:00–D2 12:00 | 数据 + 假设 | 清洗到 clean.csv + 缺失/异常审计；列假设（三件套） | clean.csv + 审计表 + 假设清单 |
| D2 12:00–24:00 | 建模跑通 | 每问先上朴素基线跑通全链（可复现 + 有数字 + 有图），再迭代改进 | 每问模型可复现跑通 |
| **D2 24:00** | **红警线** | 全部模型还没跑通 = 红警 | 砍复杂度、锁死当前可用版本 |
| D3 0:00–12:00 | 检验·灵敏度 | sanity check → 必做检验 → 灵敏度 → 结论稳健性 | 检验表 + 灵敏度图 |
| D3 12:00–20:00 | 论文 | 摘要四要素 + 全文 + 图表 + 降AI/降重 + 交稿自检 | 可提交 PDF |
| 最后 2h 前 | 对账收口 | 数值单一来源逐位对账 + 参考文献核验 + 干净环境复跑抽查 | 零残留 |

## 二、美赛 96 小时

| 时间 | 阶段 | 交付物 |
|---|---|---|
| 第 1 天 | 读题 + 定题 + 数据获取规划 | 选题决策卡；数据源清单 |
| 第 2 天 | 数据清洗 + 建模跑通（先基线） | 每问可复现结果 + 首版图 |
| 第 3 天 | 检验·灵敏度 + 打磨可视化 | 检验表 + 主打图 |
| 第 4 天 | 论文（Summary 独立一页）+ 降AI + 交稿自检 | 全文 ≤25 页（含 Summary Sheet） |

## 三、通用红线

1. **定题拖过第一天上限** = 后面全乱：选不到完美题就选"能做完"的题。
2. **第 2 天晚（国赛）/第 3 天（美赛）没跑通全部问** = 砍：换简单模型、放弃次要追问，保住"有完整结果"。
3. **最后 2 小时不做新计算**：只做对账、查重、格式、参考文献核验。
4. **每个阶段结束给一句话验收**（结果 + 关键数字），队友/助手都清楚进度。
5. 模型选型、数据处理方案、论文初稿大纲这三类决策，**随时可触发「强制确认门禁」的多方案选择**，不因赶时间而跳过。

## 四、团队分工与问题优先级（开赛即定，别到 D1 晚上才分）

### 1. 三人分工卡（默认，可微调）
| 角色 | 主责 | 交接物 |
|---|---|---|
| **建模手** | 读题拆解、列假设、选模型、推公式 | 每问「假设三件套 + 模型方程 + 符号表」 |
| **编程手** | 数据清洗、求解实现、检验/灵敏度跑批 | `results.json` + 图 + 可复现脚本 |
| **写作手** | 摘要、问题重述、图表三件套、降AI/降重 | 论文初稿 + 每日摘要草稿 |

- **交接规则**：建模手「模型定了」→ 编程手「跑出第一个数」→ 写作手「写进一句话 + 一张图」；**任一角色卡住 30 分钟未解，立即口头同步并换人互助**，别各自闷头。
- **每日站会**：D1/D2/D3 每天 22:00 与次日 8:00 各一次 10 分钟对表（进度 + 谁在等谁 + 今天砍什么）。

### 2. 问题优先级（读题后第一件事，进攻排序而非事后补救）
1. 把每题各小问按「**预估工作量 + 预估分值**」列成表（重点问通常题面可见）。
2. **先做分值高、队里最顺手的那问**，拿下第一份完整结果，稳住心态。
3. 标出「**可降级问**」：明显次要/费时的小问，先给一句话定性答案兜底，时间富余再展开（配合 `mid-contest-warning.md` 砍复杂度，但这里是**事前主动排序**）。
4. 每问交付前用「质量三支柱」mini-gate 打勾（见 `paper-quality-gate.md`）。
