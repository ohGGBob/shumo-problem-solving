# 赛程时间轴（72h 国赛 / 96h 美赛）

> 用法：读题前先把这张表贴出来当「总进度表」，每完成一阶段更新勾选；硬截止到了没东西，先砍复杂度保可交付，别钻牛角尖。

## 一、国赛 72 小时

| 时间 | 阶段 | 做什么 | 交付物（硬截止） |
|---|---|---|---|
| 第 1 天 0–4h | 读题·拆解 | 逐问读题：已知/待求/约束；附件清点；真题定位（查 `cumcm-years.md`） | 每题一句话"要交付什么" |
| 第 1 天 4–6h | 定题 | 选题决策卡打分（`topic-selection.md`）；A/B/C 三选一 | **定题**（最迟第 1 天中午前） |
| 第 1 天 下午 | 数据 + 假设 | 清洗到 clean.csv + 缺失/异常审计表；列假设（三件套） | clean.csv + missing/outlier 审计 + 假设清单 |
| 第 2 天 | 建模跑通 | 每问先上朴素基线跑通全链（可复现 + 有数字 + 有图），再迭代改进 | 每问模型可复现跑通 |
| **第 2 天 24:00** | **红警线** | 全部模型还没跑通 = 红警 | 砍复杂度、锁死当前可用版本 |
| 第 3 天 上午 | 检验·灵敏度 | sanity check → 必做检验 → 灵敏度 → 结论稳健性 | 检验表 + 灵敏度图 |
| 第 3 天 下午 | 论文 | 摘要四要素 + 全文 + 图表 + 降AI/降重 + 交稿自检 | 可提交 PDF |
| 最后 2h 前 | 对账收口 | 数值单一来源逐位对账 + 参考文献核验 + 干净环境复跑抽查 | 零残留 |

## 二、美赛 96 小时

| 时间 | 阶段 | 交付物 |
|---|---|---|
| 第 1 天 | 读题 + 定题 + 数据获取规划 | 选题决策卡；数据源清单 |
| 第 2 天 | 数据清洗 + 建模跑通（先基线） | 每问可复现结果 + 首版图 |
| 第 3 天 | 检验·灵敏度 + 打磨可视化 | 检验表 + 主打图 |
| 第 4 天 | 论文（Summary 独立一页）+ 降AI + 交稿自检 | ≤25 页正文 + Summary Sheet |

## 三、通用红线

1. **定题拖过第一天上限** = 后面全乱：选不到完美题就选"能做完"的题。
2. **第 2 天晚（国赛）/第 3 天（美赛）没跑通全部问** = 砍：换简单模型、放弃次要追问，保住"有完整结果"。
3. **最后 2 小时不做新计算**：只做对账、查重、格式、参考文献核验。
4. **每个阶段结束给一句话验收**（结果 + 关键数字），队友/助手都清楚进度。
5. 模型选型、数据处理方案、论文初稿大纲这三类决策，**随时可触发「强制确认门禁」的多方案选择**，不因赶时间而跳过。
