# 检验、灵敏度与结果合理性硬清单（国一和国二的分水岭）

> 国一和国二的差距，九成在「检验 + 结果合理性分析」。评委最反感两件事：算出一个反常识的数还振振有词；只给结果、不做检验不分析。**顺序不要乱：先做结果合理性 sanity check（5 分钟堵住量产级错），再做按模型类型的必做检验，最后补灵敏度。**

## 一、结果合理性 sanity check（算完数立刻做，最便宜最救命）

四道关，任何一道不过就回头查模型/单位/代码：

**① 量级对标** —— 和常识、文献、题面给的量级对照。常用参考量级：
| 对象 | 正常量级 |
|---|---|
| 塔式光热单位镜面面积年均功率 | ~0.1 kW/m² |
| 概率 / 比例 / 浓度 / 效率 | ∈ [0,1]（或 0–100%）|
| 人步速 / 车速 | ~1.4 m/s / 30–60 km/h |
| 增长率 / 损耗率 / 不良率 | 通常 1%–30% 量级 |
| 波长 / 频率换算、浓度单位 | 先统一 mol/L·mg/L 等再算 |

**② 单位一致性** —— 全流程统一（米 vs 海里×1852、kg vs 吨、s vs min vs h），尤其跨附件数据时先换算再进模型。

**③ 边界与守恒** —— 概率∈[0,1]、库存/数量/人数 ≥0、质量/能量/人数守恒（残差应≈0）。算出来负库存、概率 1.5、能量不守恒，就是硬伤。

**④ 单调性与极限退化** —— 参数趋于极端时结果应趋于合理；退化到简单情形（坡度 α=0、阻尼 c=0、无风）应等于已知解析解。

> 「明显错的数」示例：2023 A 单位面积功率算成 10 kW/m²（量级错 100 倍）、2022 C 把百分比当绝对量、2023 B 海里米没换算条数差 3 个数量级。这类错，sanity check 一秒钟就能拦住。

## 二、按模型类型的必做检验

| 模型类型 | 必做检验 | 别漏 |
|---|---|---|
| **预测/回归/时序** | 训练/验证切分报 MAPE/RMSE；**和 naive 基准比**（历史均值/去年同期/上一期）；残差近似白噪声；给**区间**不只单点 | 时序用"按时间顺序/滚动"验证，**别随机 K 折** |
| **优化 LP/MILP/非线性** | 解满足所有约束；与松弛解/解析下界比"离最优多远"；多起点/换初值看稳定 | 目标值量级合理；0-1 变量别偷懒当连续 |
| **机理/微分方程** | **守恒律校验**（残差≈0）；退化到解析解验算；步长/方法收敛（dt 减半结果不变、rk45↔BDF 互校） | 丢弃瞬态再取稳态均值 |
| **随机仿真/蒙特卡洛** | 样本量收敛（N 加倍结果稳定）；报**置信区间**不报单点；换种子多跑取均值±方差 | 固定 seed=0 保证可复现 |
| **综合评价/排序** | **权重敏感性**（熵权/AHP/等权换着来，排序是否稳定）；归一化方式稳健性 | 只给一个权重法=容易被质疑 |
| **统计/分类/聚类** | 分层 K 折交叉验证 + 混淆矩阵；类不平衡看 AUC/召回/F1**而非准确率**；聚类数用肘部+轮廓系数 | **严禁标签泄露**（用全量数据选特征再验证）；**重复测量/纵向数据必须按个体分组 K 折**（GroupKFold/StratifiedGroupKFold，行级切分把同一体的记录分进训练+测试=泄漏，AUC 会系统性虚高） |

> 预测类"和 naive 基准比"是国一国二的分水岭：证明你的复杂模型**确实比"用均值/上年同期"更准**，否则评委不认你这个模型的价值。

**筛查 / 不平衡分类的阈值姿势（医疗·风控·异常检测）**：

- 别用固定 0.5 阈值。按"**先满足最低灵敏度（如 90%），再最大化特异度**"（或最大化 Fβ，β>1 偏重召回）在验证集/OOF 概率上选阈值。
- 明确定位：这种高召回低特异的产出是"**初筛器**"，阳性一律走复核/确认；结论里写清"不等价于确诊/金标准"。
- 同时报 PR-AUC 与 ROC-AUC 的对照，并解释为什么类不平衡时以 PR-AUC 为主（ROC-AUC 好看但精确率极低会误导）。

## 三、灵敏度分析标准动作

1. 挑出**关键参数**（别全做，3–5 个最影响的即可），各摄动 ±10%/±20%（或按物理合理范围）。
2. 看**目标/结论**怎么变：画龙卷风图（tornado）或灵敏度曲线。
3. 落到一句结论："结论对参数 X 最敏感，X 在 [区间] 内结论仍成立/不成立"，并在正文给出 X 的不确定区间。

## 四、输出退化与决策保持性检查（对标社区 risk-probe，v1.9.2）

**① 输出退化 / 集中度**——模型输出全部相同 = 模型空转/塌缩，是「表面有结果、实际啥也没算出来」的典型信号，评阅最易扣分：

- **分类**：预测标签唯一值数 ≥2（全为同一类 = 分类器失效或数据泄露/特征无信息）；
- **优化**：解不随输入/初值变化（换 3 组初值答案一字不差 = 目标函数写错或约束把解锁死）；
- **仿真**：所有轨迹/样本完全相同（随机源没接对，seed 用成了常数）；
- **一键检查**：`python scripts/sanity_check.py results.json --distinct "*y_pred:2"`（匹配键的数组取值须 ≥2 种，详见 `sanity_check.py --help`）。
- **例外须解释**：若问题本身答案唯一（如某问就是常数解），在论文里写明「该问结果恒为 X，因为……」，别让评委自己猜。

**② 决策保持性**（简化/代理模型 vs 完整模型）——用简化模型（降阶、抽样、线性化、代理面）是为了省时间，但**最终决策必须和完整模型对得上**：

- 检查法：在**关键决策点**（最优方案排序、选中/淘汰、是否超阈值）用完整模型（或全量数据）复核一次，两者给出的决策一致才算数；
- 全域误差对不齐没关系，**决策翻车才是大事**：简化模型说选 A、完整模型说选 B，论文却交了 A → 直接被质疑全篇；
- 不一致时二选一：要么用完整模型重做最终决策（简化模型只用于过程探索，论文如实说明），要么显式给出两版差异与取舍依据。

## 五、交稿前检验总勾表

| 项 | 是否完成 |
|---|---|
| 每个关键结果都过了量级/单位/边界/守恒 sanity check | ☐ |
| 输出退化检查通过（预测/解/仿真非全同值，`sanity_check.py --distinct`；唯一解已解释） | ☐ |
| 简化/代理模型的最终决策与完整模型复核一致（决策保持性） | ☐ |
| 按模型类型跑完了上面的"必做检验" | ☐ |
| 预测有基准对比、有交叉验证、有区间 | ☐ |
| 优化解满足约束、与下界比对过 | ☐ |
| 灵敏度做了 ≥3 个参数并落到"结论是否稳健" | ☐ |
| 代码固定 seed、结果可复现 | ☐ |

## 六、反模式（评委一眼扣分）

1. 只给结果不检验；2. 检验走过场（"从图可看出差异明显"但无数字）；3. 灵敏度只做一件事拍脑袋；4. 预测无基准/无交叉验证；5. 把"对训练数据拟合得很好"当模型好（=过拟合）；6. 报告单点准确率且类别不平衡。
