# 真题演练示例：2026 MCM C — 星舞赛制分析（统计逆问题范式范本）

> 目的：与 `worked-example-2026-mcmA.md`（**机理范式**：列守恒方程→积分→事件触发）**互补**，本范例展示**统计逆问题范式**：给定"结果观测"（粉丝投票、评分），**反推背后机制**（选手真实实力、计分规则是否公平）。这是美赛 C 类最常见的题型。代码用**合成演示数据**跑通（标注替换真实数据处），串起 `cases-2026-mcm.md`（MCM C 段）、`bigdata-playbook.md`、`advanced-methods-templates.md` §4/§5/§10。**核心铁律：禁止纯 ML/离散拟合"黑箱"——必须有可解释的统计推断框架。**

## 1. 问题重述（转述，不抄题）

已知多季比赛数据（选手表现、粉丝投票、评委评分），要求：① 建立模型量化"选手真实实力"与"赛制对结果的影响"；② 评估赛制（粉丝投票权重、计分规则）的**公平性与可操纵性**；③ 给出改进建议。

## 2. 问题分析（数据→字段→方法→指标）

- 问① → **统计逆问题**：观测 = 真实实力 + 噪声/系统偏差 → 用潜在变量推断（贝叶斯/MCMC）估真实实力分布。
- 问② → **因果/机制分析**：改变赛制（投票权重、规则）后重放，看冠军是否稳定 → 反事实重放 + 稳健性。
- 问③ → **Policy Letter**：给"更公平赛制"的可执行建议（决策者视角）。

## 3. 模型假设（三件套）

| 假设 | 理由 / 后果 / 验证 |
|---|---|
| 观测评分 = 真实实力 + 独立噪声 | 理由：评分含随机误差；后果：忽略会导致实力估计方差大；验证：残差近似白噪声 |
| 粉丝投票与真实实力相关但含"人气偏置" | 理由：人气≠实力；后果：高人气低实力者被高估；验证：投票与评委分相关性但系统性偏移 |
| 各季难度可比（或引入赛季固定效应） | 理由：跨季比较需控制难度；后果：不控制会错判实力变化；验证：加赛季固定效应后结论不变 |
| 计分规则可参数化（投票权重 w） | 理由：规则即权重；后果：w 是机制设计核心变量；验证：扫 w 看冠军变化 |

## 4. 符号约定

| 符号 | 含义 |
|---|---|
| θ_i | 选手 i 的潜在真实实力（latent） |
| y_ij | 选手 i 在第 j 个观测（评分/投票）上的值 |
| ε_ij | 观测噪声 |
| w | 粉丝投票在总分中的权重（机制变量） |

## 5. 建模与求解（完整可运行）

```python
# 依赖 numpy, scipy；合成演示数据，比赛时替换为真实赛制数据
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
n = 12
# 潜在真实实力（升序便于对照）：实力最强者 idx=11，中等实力者 idx=5
true_skill = np.sort(rng.normal(0, 0.7, n))

# ---------- 观测生成 ----------
# 评委评分：≈ 真实实力 + 较小噪声（较客观）
judge_noise = rng.normal(0, 0.3, n)
y_judge = true_skill + judge_noise

# 粉丝投票：= 真实实力 + 人气偏置 + 噪声
# 人气偏置大多随机，但确定性构造一名"人气王"（idx=5，真实实力仅排第 6=中等）人气极高
pop = rng.normal(0, 0.8, n)
pop[5] = 4.0                          # 中等实力 + 爆棚人气 -> 典型"人气≠实力"案例
y_fan = true_skill + pop + rng.normal(0, 0.3, n)

# ---------- 逆推真实实力：贝叶斯后验（无重库版）----------
# 模型 y = θ + ε, ε~N(0,σ²)，θ 先验 N(0,1)；用两类观测融合估 θ
sigma = 0.5
alpha = 0.5                           # 粉丝投票权重（机制变量）
z = (y_judge + alpha*y_fan)/(1+alpha) # 组合观测
post_mean = z / (1 + sigma**2)        # 后验均值 = 似然精度·z/(先验精度+似然精度)
post_std  = np.sqrt(1/(1 + 1/sigma**2))

order_true = np.argsort(-true_skill)  # 真实降序
order_est  = np.argsort(-post_mean)    # 估计降序
print("真实冠军 idx:", order_true[0])
print("估计冠军 (α=0.5):", order_est[0])
print("Spearman(估计排名,真实排名):", round(stats.spearmanr(true_skill, post_mean).correlation, 3))
# 对照：纯评委 (α=0) 时是否恢复出真实冠军？
post_judge = y_judge/(1+sigma**2)
print("纯评委时估计冠军 (α=0):", int(np.argmax(post_judge)),
      "== 真实冠军?", int(np.argmax(post_judge))==order_true[0])
```
> 输出（本文件合成数据，已验证可复现）：**Spearman≈0.82**，整体排名恢复良好；但 α=0.5 时估计榜首已变成 idx 5（人气王），而纯评委 α=0 时恢复出真实冠军 idx 11——人气偏置的扭曲已初现。§6 量化这种"冠军翻转"。真实比赛用 **MCMC（`advanced-methods-templates.md` §5）** 给**可信区间**而非点估计，并显式建模"人气偏置"机制。

## 6. 模型检验（反事实 + 稳健性，美赛 C 的核心）

```python
# ---------- 反事实重放：改变投票权重 w，看冠军是否稳定 ----------
def champion_under(alpha):
    z = (y_judge + alpha*y_fan)/(1+alpha)
    return int(np.argmax(z/(1+sigma**2)))

champs = {}
for a in [0.0, 0.25, 0.5, 0.75, 1.0]:   # α=0 纯评委，α=1 纯粉丝
    champs[a] = champion_under(a)
print("不同投票权重下的冠军 idx:", champs)
# 若冠军随 α 变化大 -> 赛制可被"投票操纵"，公平性差
unique_champs = len(set(champs.values()))
print(f"不同权重下出现 {unique_champs} 个不同冠军 -> 赛制{'易被操纵' if unique_champs>1 else '稳健'}")
```
> 解读（本文件合成数据，已验证可复现）：冠军映射为 `{0.0:11, 0.25:11, 0.5:5, 0.75:5, 1.0:5}`，共 **2 个不同冠军**；α=0/0.25 时冠军是真正最强的 idx 11，α≥0.5 时翻转为 idx 5（人气王，真实实力仅第 6），**转折点约在 α≈0.5**。这就是"冠军随投票权重变化的剧烈程度 = 赛制可操纵性指标"。把"哪种权重下冠军最稳定"作为机制改进建议的依据——这就是美赛 C 的"证据链式检验"，也是支柱二的"结果背后的为什么"。

## 7. 摘要（四要素，带数值）

> 针对星舞赛制公平性问题，本文建立统计逆问题框架，将观测评分/投票分解为"选手潜在真实实力 + 噪声 + 人气偏置"三项。用贝叶斯后验反推真实实力，在合成演示数据下估计排名与真实排名 Spearman 相关达约 **0.82**。反事实重放显示：当粉丝投票权重 α 从 0 增至 1 时，冠军由真正实力最强者（idx 11）切换为一名仅列真实实力第 6 的"人气王"（idx 5），共出现 **2 个不同冠军**，转折点出现在 **α≈0.5** 附近，表明赛制在偏向粉丝投票时公平性明显下降、可被"人气操纵"。据此建议将粉丝投票权重控制在 α≈0.5 以下、并显式建模人气偏置，可显著缓解不公平。
