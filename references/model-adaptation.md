# 模型适配：DeepSeek 系模型通用（不区分型号）

> 一次会话绑定一个模型。本 skill 对 **DeepSeek 系模型（V3 / V3.1 / R1 / V4 系列等）通用适配**：全流程、23 个脚本、紧急模式与 AI 报告均与型号无关，选任何 DeepSeek 型号都能完整跑通。以下四条通用要点即可，不必按型号细分预设。

## 通用要点

1. **长上下文可用**：DeepSeek 系普遍支持长上下文（如 1M token 量级，以官方规格页为准）——长文档可全量塞入；但"贵型号省着用、便宜型号放开用"的成本意识仍成立（价格随版本变化，以 DeepSeek 官方定价页为准）。
2. **推理强度随型号浮动**：强推理型号（如 V4 Pro 级）在模型选型 / 创新设计 / 论文论证环节质量更高；轻量型号（如 V4 Flash 级）在这些环节可能略弱——**卡壳时换更强的 DeepSeek 型号开新会话补**（切换 = 开新会话，不能会话内热切换）。
3. **脚本与模型无关**：`scripts/` 下全部校验脚本是本地 Python 工具，不占用模型 token，任何型号会话下都直接调用。
4. **成本意识**：机械活（数据清洗、批量校验、降重改写、AI 报告）交给便宜型号/本地脚本；高价值推理（选型、创新、论证）留给强推理型号——不是质量妥协，是成本最优。

（规格与价格随版本更新，以官方文档为准。）
