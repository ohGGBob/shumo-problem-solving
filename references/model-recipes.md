## 三大高频题型「标准配方」（最高频，务必熟练）

### A. 综合评价题（给一组对象打分 / 排序）

1. 指标选取与解释（可结合主成分 PCA 降维去冗余）。
2. 标准化（正向 / 负向 / 区间型分别处理，消除量纲）。
3. 定权：
   - 主观：层次分析 AHP（构造判断矩阵，需一致性检验 CI/CR）；
   - 客观：熵权法（离散越大权重越大）；
   - 两者可组合成组合权重。
4. 集结评分：加权求和 / TOPSIS（贴近度）/ 灰色关联 / 模糊综合评价。
5. 灵敏度：权重 ±10% 看排序是否稳定。

Python 关键库：`numpy`、`pandas`、`scipy`；AHP / TOPSIS 常用 `numpy` 自实现（几十行）。

### B. 预测题（时间序列 / 回归 / 机器学习）

1. 画时序图判断趋势 / 周期 / 噪声。
2. 数据量小、样本点少 → 灰色预测 GM(1,1)（4 个以上数据点即可，需做级比检验）。
3. 有明显趋势 + 随机 → 指数平滑 / ARIMA（定阶看 ACF/PACF）。
4. 数据量大 / 多特征 → 多元回归、随机森林、LSTM。
5. 检验：留出后段做回测，报 MAPE / MAE / R²。

Python：`statsmodels`（ARIMA / 指数平滑）、`sklearn`、`torch`；GM(1,1) 用 `numpy` 自实现。

### C. 优化 / 规划题（求最优方案）

1. 写清三要素：决策变量、目标函数、约束条件。
2. 类型判断：线性 → `linprog` / `pulp`；整数或 0-1 → `milp` / `pulp` / `ortools`；非线性 → `scipy.optimize.minimize`；多阶段 → 动态规划。
3. 规模太大消不掉 NP-hard → 用启发式（遗传 / 模拟退火）并说明"近似解 + 稳定性"。
4. 必做：改变某约束 / 参数看最优解漂移（灵敏度）。

Python：`scipy.optimize`、`pulp`、`ortools`、`networkx`（图类优化）。

## 其他高频题型（配方速查）

### D. 机理 / 微分方程题（物理、工程、传染、生态）

1. 由守恒 / 定律列方程：力平衡、能量守恒、质量守恒、扩散 / 热传导、传染病 SIR、种群增长等。
2. 常微分方程 → `scipy.integrate.solve_ivp`；偏微分方程 → 差分离散（显式 / 隐式）或有限元，再数值求解。
3. 参数未知时做参数辨识 / 反演：用最小二乘或优化，让模型输出拟合观测数据。
4. 必做稳定性 / 收敛性检验：改变步长、网格加密看结果是否稳定；必要时做相图 / 相平面分析。

Python：`scipy.integrate`、`numpy`；PDE 离散常用 `numpy` 自实现。

### E. 图论 / 网络题（路径、选址、分配、社区）

1. 先做抽象：节点＝对象，边＝关系 / 成本 / 距离，说清边的含义。
2. 常用：最短路（Dijkstra / Floyd）、最小生成树、最大流、TSP / VRP 路径规划、覆盖与选址、社区发现（Louvain）。
3. 带约束的分配 / 选址 → 转 0-1 或混合整数规划再求解。
4. 只有"关系型"本质才用图论；否则强套图论会被认为建模失当。

Python：`networkx`、`scipy.sparse.csgraph`、`pulp` / `ortools`。

### F. 智能算法 / 启发式（大规模 NP-hard、多峰值优化）

1. 精确方法算不动（规模太大 / NP-hard）才用，并如实说明是"近似解 + 稳定性"。
2. 遗传 GA / 粒子群 PSO / 模拟退火 SA / 蚁群 ACO：写清编码、适应度函数、选择 / 交叉 / 变异（或速度更新）、终止条件。
3. 独立多跑取均值：报最优值 + 方差，画收敛曲线证明收敛。
4. 与小规模已知精确解对比，验证启发式的正确性。

Python：`scipy.optimize.differential_evolution`，或 `numpy` 自实现 GA / PSO / SA。

### G. 随机 / 仿真题（蒙特卡洛、排队、离散事件）

1. 明确随机变量的分布与参数：由数据拟合或给出可辩护的假设。
2. 蒙特卡洛：固定随机种子，大样本重复，报均值 + 置信区间。
3. 排队：M/M/1 等经典模型算关键指标；规则复杂时用 `simpy` 做离散事件仿真。
4. 敏感性：扰动分布参数，观察结果变化。

Python：`numpy`（蒙特卡洛）、`simpy`（离散事件）、`scipy.stats`（分布与统计）。

### H. 机器学习 / 大数据题（分类、聚类、预测）

1. 数据量大、特征多、非线性才上 ML；小样本优先统计 / 回归 / 灰色。
2. 预处理：缺失值、异常值、标准化、类别编码；特征工程优于堆模型。
3. 交叉验证选模型 / 调参；分类报准确率 / AUC / F1，回归报 MAE / RMSE / R²。
4. 可解释性：特征重要性、SHAP；避免纯黑盒。
5. 防过拟合：划分训练 / 验证 / 测试，正则化，报告泛化指标。

Python：`sklearn`、`xgboost` / `lightgbm`、`torch`。

## 选型三问（答辩 / 自检都靠它）

1. 这问的**本质**是"评价、预测、优化、机理、统计、图论、智能算法、仿真、机器学习"里的哪一类？
2. 数据**规模与质量**支撑得起多复杂的模型？（点少就灰色 / 回归，点多才上 ML）
3. 能不能**解释清楚**每一步？（评委要先看到逻辑链，再看到代码）
