# 数据预处理流水线（文件级清洗 + 审计 + 复核）

> 来源：2025 国赛 C 题（NIPT）模拟赛真实事故复盘。第一版"清洗"只做了探查 + 导出（`explore.py` 全程 print、不写数据），缺失值原样带出、异常值未检测、编码想当然，被用户当场指出后才补成正式流水线。本文把教训固化为规则，配 `data-science-playbook.md` §2 使用。

## 一、三条铁律

1. **探查脚本 ≠ 预处理脚本。** "清洗完成"的标志是**数据文件发生了实质性变化**（列删了、缺失填了、编码改了、审计表生成了），不是打印了一堆统计。凡是脚本结尾只有 `print` 没有 `to_csv/写入`，都不算清洗。
2. **预处理必须文件级、一次性、可审计**：`raw.xlsx → preprocess.py → clean.csv + missing_report.csv + outlier_scan.csv`。模型脚本只读 clean.csv，**禁止每个模型各自内联 dropna/fillna/编码**——那是口径漂移（同一个缺失值，有的脚本删、有的脚本填）的根源。
3. **改了数据必须重跑全部分析链**，把关键数字与上一版/论文逐项核对，变了要写清"为什么变"并同步论文。

## 二、文件级清洗清单（逐项打勾）

- [ ] 列名 `str.strip()`（防 `"孕妇BMI "` 取不到列）
- [ ] 单位/格式统一：**比例 vs 百分数**（0.026 vs 2.6% 差 100 倍，阈值直接可比才不出事）；字符串数字（`"1"/"2"/"≥3"`）
- [ ] 特殊格式解析：如孕周 `"11w+6"→11.857`，写解析函数 + 抽查样例（head 8 行 + 范围 + 缺失数）
- [ ] 删无信息列：100% 缺失或缺失多且建模不用（如 `末次月经`）——记录删了什么、为什么
- [ ] 缺失处理：先输出**全量缺失矩阵**（多 sheet 都要）→ 逐列定策略并记录：本人/组均值填补、中位数、删除、**保留为标签编码**（标签列空=阴性类，不是缺失！）
- [ ] **分类变量编码前枚举全部取值**（`unique()` 打出来）：如 IVF 真实有三类"自然受孕/IUI/IVF"，想当然二值化会把 IUI 归错；怀孕次数是字符串不是数字
- [ ] 标签列核查：唯一值、**是否随个体恒定**（纵向数据里标签跳变 = 噪声金标准！见 §三）、是否多标签（`T13T18` 组合值）
- [ ] 异常值：IQR + 3σ 双扫描 → 逐项业务判定 → 结论写入报告。**"越界 = 异常 = 删"是反模式**：NIPT 里极端 Z 值、高 BMI 就是信号，删了模型就瞎了
- [ ] 导出审计表：`missing_report.csv`、`outlier_scan.csv`，让"处理了什么"可查

## 三、纵向/重复测量数据的两个大坑

1. **行级 K 折 = 信息泄漏。** 样本单位（孕妇）≠ 观测单位（记录）：同一孕妇 4 条记录被行级 StratifiedKFold 分进训练/测试，测试折"见过"同孕妇的其他记录，AUC 虚高。本案实测：行级 0.823 vs 按孕妇分组 0.782（高估 0.04），PR-AUC 高估 0.07。**必须 GroupKFold / StratifiedGroupKFold（groups=个体 ID）**，判定依据是"每个个体是否完全同折"。
2. **"标签恒定"假设必须验证。** 本案女胎 AB 列在 43/147 名孕妇的不同孕周记录间"判异常/判正常"跳变——临床上胎儿核型不会变，说明标签其实是"单次采血的噪声判读"而非金标准。建模前必做 `groupby(个体)[标签].nunique()` 检查；标签跳变时，结论要按"噪声标签"重新表述（本案由此发现"判读可靠性随时点/信号强度变化"，成了全题统一命题的证据）。

## 四、数字进论文前必须独立复核（本会话血泪）

- "左删失 38.2%"写进论文，实际 **81.3%**——一次性计数错误。复核方式：换一个口径直接数一遍（如 `groupby(个体).first()` 直接数），两法对不上就停。
- "读段数 min=134" 是**输出格式误读**（1.34e6 被格式化显示成 134），差点把正常样本当垃圾剔除。读程序输出务必看单位/科学计数法。
- 规则：**关键数字至少用两种独立方式算一遍**；程序输出要带单位打印（`min=1.34e6` 而不是 `min=134`）。

## 五、同类问题多方法对照

删失类数据不要只给一种估计：保守 ECDF / Turnbull 非参数 NPMLE / 参数 log-hazard 三法对照。方法之间出现分歧要**解释分歧来源**（本案 81% 左删失使最优时点 12.5–14 周有 1–2 周敏感性），论文写"区间 + 保守口径"而不是拍一个单点。

## 六、事故复盘表（下次快速自查）

| 错误 | 后果 | 修正 |
|---|---|---|
| 探查脚本只 print 就声称清洗完成 | 用户质疑"到底清洗了什么" | preprocess.py 做文件级变换 + 审计表 |
| 缺失值原样带进 clean.csv | 各脚本口径漂移 | missing_report + 逐列决策 |
| 异常值从不检测 | 数据质量未知 | IQR+3σ 扫描 + 业务判定 + 证据表 |
| 分类变量想当然二值化（漏 IUI） | 编码错误 | 编码前枚举全部取值 |
| 行级 StratifiedKFold | AUC 虚高 0.04–0.05 | 按个体分组 K 折 |
| 左删失 38.2% 未复核 | 论文数字错误 | 双口径复核为 81.3% |
| 输出格式误读（1.34e6→134） | 差点误删正常样本 | 打印带单位、科学计数法 |

## 七、规则有效性验证（第二轮复盘：别人的方案也要用数据验证）

吸取队友方案时，**每一条规则先拿真实数据验证再采纳/否定**。本回合四个案例：

1. **固定阈值规则必须先对分布。** 队友提"GC 不在 40%–60% 标异常"——看着合理，但本数据 GC 实际 36.7%–44.4%，按该规则 **13 号 GC 100%、18 号 GC 99%** 的记录会被标异常，等于把整份数据标废。采纳前必须 `min/max/分位数` 对一遍。改成按列 IQR 栅栏后只标 54/61 条，合理。
2. **"复核规则"先验证是否有差异。** 队友提"用身高体重重算 BMI 覆盖孕妇BMI"——实测相关系数 1.0000、最大差 0.00，两者**完全相等**，该规则是恒等式、执行无任何变化。保留作 sanity check 无害，但别指望它改数据；缺失值用公式填反而是好用途。
3. **逻辑矛盾检查很有价值。** "唯一比对读段数 > 原始读段数"是不可能事件，实测男胎 71 条（6.6%）真存在。处理优先级：**先加标记列 → 量化影响 → 再决定删/封顶**（本案例删 6.6% 会损失数据且矛盾组 Y 浓度偏高，改用 `min()` 封顶 + 标记，不删行）。
4. **多标签列要交叉核对一致性。** 男胎"胎儿是否健康"38 条"否"与 AB 列矛盾（34 条 AB 空、126 条 AB 非空里 122 条标"是"）——该列是噪声，只能编码不能当标签，论文里注明不一致。
5. **混合类型列的双通道解析。** 日期列 int(20230429) 与 datetime 混存时，`format="%Y%m%d"` 对 datetime 型全失败（396 条变 NaT）。先 `%Y%m%d` 解析 + `fillna(默认解析)` 双通道。
6. **善用"可推导缺失"：** 末次月经 = 检测日期 − 孕周×7 天，12+8 条缺失全部可反推，比删列信息保全更好。

## 八、论文里"数据预处理"章节必须写什么

1. 数据规模（行数、个体数、重复测量结构）；
2. 单位与格式约定（比例/百分数、孕周解析）；
3. 缺失处理逐列决策（含"标签列缺失=阴性类"这种容易被评委追问的点）；
4. 异常检测方法与结论（检出多少、为何保留——**有结论才算做了**）；
5. 编码规则（分类变量取值枚举）；
6. 分析窗口/截断口径（如 [11,25] 周、>25 周视为已达标）。

## 九、多文件同步与口径一致性（第三轮复盘：改了 ≠ 改全）

数字修改的"最后一公里"最容易翻车，本回合事故全部属于此类：

1. **同值多副本，改一处=没改全。** 同一数字会同时存在于 `论文.tex / 论文.md / gen_docx.py / 分析脚本` 多处（0.781、38.2%、LRT 3.26 都踩过）。只改一处等于没改。**规则：任何数字改动后，必须用 grep 全目录扫旧值，确认零残留**（收口动作，不是可选项）。
2. **同错多位置。** 同一个错误值可能出现在多个语义位置（38.2% 在 .md 改了、.tex 正文还有一处）。修正时先 grep 该值的**所有**出现位置，逐一确认。
3. **表格口径必须全文一致。** Q4 表头写"按孕妇分组"，某行却用行级口径（0.528 vs 分组 0.459）——表内自相矛盾且无报错。**规则：同一表格所有行同一口径；引用任何数字带口径标签（行级/分组/全数据）**。
4. **"已修复"以文件现状为准，不信记忆。** 跨多轮对话，我的记忆 ≠ 磁盘现状。声称修复后必须 read/grep 验证，以工具结果为准。
5. **数据处理变更要重估"定性表述"。** 众数消歧把年龄 p 值从 0.063（不显著）变成 0.049（边缘显著）——**结论级别**的变化。改数据后除了重算数值，还要逐条重审"显著/不显著/稳健/敏感"这类定性结论。
6. **小样本组展示+标注，不隐藏。** BMI<28（n=5）被悄悄跳过是最差做法；正确做法是列出并标注"蒙特卡洛漂移 ±2–3 周、不稳定、不作为建议"——隐藏显得心虚，展示+标注是严谨。
7. **主动对账，别等用户发现。** 每次改完，用"canonical 验证脚本"（同一协议、同一 seed 重算论文全部数字）逐位核对输出 vs 论文，作为标准收口流程。
