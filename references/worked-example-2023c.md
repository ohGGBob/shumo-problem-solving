## 0. 读题与拆解（先想清楚每问交什么）

2023 C：商超生鲜蔬菜 **6 大品类、每类若干单品**，历史日度销售流水（售价 / 销量 / 批发价 / 损耗率），要建立定价与补货联合决策。

| 问 | 交付物 | 本质 |
|---|---|---|
| 1 | 销量分布规律 + 相互关系 | EDA（趋势/季节/相关性） |
| 2 | 6 品类未来 7 天补货量 + 定价 | 品类级联合决策（求总收益最大） |
| 3 | 7 月 1 日各单品补货量 + 售价 | 单品级决策（**全题技术内核**） |
| 4 | 候选新增单品选哪些 / 进多少 / 怎么定价 | 0-1 选品 + 组合优化 |

> 下文聚焦**问 3 单品级核心链路**做完整演示——问 2 是它的聚合版，问 4 是它的组合版，打通这一条，其余是套壳。

## 1. 假设（三件套示范，照这个格式写）

- **H₁ 需求价格弹性**：设 lnQ = a + b·lnP（对数线性）。
  理由：生鲜短期需求对价格近似等弹性，且对数线性便于估计与解释。
  后果：若结构错误（价格对销量存在强非线性），弹性估计有偏、最优价失真。
  验证：回测 MAPE 6.2%，远优于 naive 基准 40.6%，结构站得住。

- **H₂ 损耗率取历史均值**：设未来损耗率 ≈ 历史均值 10%。
  理由：损耗率短期平稳，用均值是数据有限下的稳健选择。
  后果：损耗率对收益影响直接（见灵敏度），故后续专门做 ±20% 摄动。
  验证：灵敏度显示最优价仅变 0.9 元，结论稳健。

- **H₃ 批发价短期平稳**：设未来批发价 ≈ 历史均值 6.5 元。
  理由：批发价由上游决定、波动小。后果与验证同上，纳入灵敏度。

## 2. 符号表

| 符号 | 含义 | 本例值 |
|---|---|---|
| P | 售价（元/kg） | 决策变量 |
| Q | 销量（kg/天） | 由弹性估算 |
| w | 批发价（元/kg） | 6.5（均值） |
| loss | 损耗率 | 0.10（均值） |
| b | 价格弹性 | −1.599（拟合） |

## 3. 建模（公式 + 为什么，这里藏着全题的关键链）

1. **需求**：Q = e^(a + b·lnP)，其中 b 为价格弹性（应 <0）。
2. **损耗校正链**（本题最容易错、最该写明白的一条）：
   `进货量 = 销量 / (1 − 损耗率)` —— 因为进货 100 kg、损耗 10 kg，实际只卖得出 90 kg。
3. **单日收益**：π = Q·P − 进货量·w。
4. **最优定价**：max π(P)。对 P 求导得**解析解**：
   `P* = b/(b+1) · w/(1 − loss)`（b<−1 时为正）。
   这一阶条件能当"理论亮点"写进论文——不是瞎调参，而是有闭式解。（符号表 6.5 / 0.10 为期望均值，代入闭式得 P*≈19.3；结果表 19.43 来自数据拟合均值，口径一致，别手混。）

## 4. 代码（完整可跑，见 `demo_2023c.py`）

```python
import numpy as np
from scipy.optimize import minimize_scalar
rng = np.random.default_rng(0)

# 0) 读数据（真实赛题换成 pandas.read_excel 读附件）
P = rng.uniform(8, 22, 60)
Q = 3000 * P ** (-1.6) * rng.normal(1, 0.08, 60)
loss = rng.uniform(0.05, 0.15, 60)
w = rng.uniform(4, 9, 60)

# 1) 拟合弹性 lnQ = a + b lnP
A = np.column_stack([np.ones_like(P), np.log(P)])
a, b = np.linalg.lstsq(A, np.log(Q), rcond=None)[0]   # 第1列截距a、第2列斜率b

# 2) 损耗校正 + 定价优化
loss_hat, w_hat = loss.mean(), w.mean()
neg = lambda P_: -(np.exp(a + b*np.log(P_)) * (P_ - w_hat/(1-loss_hat)))
res = minimize_scalar(neg, bounds=(5, 30), method='bounded')

# 3) 结果合理性检查（断言弹性为负，拦量产级错）
assert b < 0
print(f'b={b:.3f}  最优价={res.x:.2f}  收益={-res.fun:.1f}')
```

## 5. 运行结果（真实数字，seed=0 可复现）

| 量 | 值 |
|---|---|
| 拟合价格弹性 b | **−1.599** |
| 最优售价 P\* | **19.43 元/kg** |
| 预期销量 / 进货量 | 26 kg / 29 kg |
| 单日收益 | **317.6 元** |

## 6. 检验（三层，一个都别省）

**① 结果合理性 sanity check** —— b<0 ✓（涨价→销量降）；收益>0 ✓；最优价 19.43 落在历史售价区间内 ✓。

> ★ 真实教训：写脚本时把 `a, b = lstsq(...)` 误写成 `b, a`，解包颠倒后 b 变成 **+5.4**、销量冲到 **3978 万 kg**、收益 **9 亿元**——正是 `assert b < 0` 这一行在交稿前拦住了这个量产级错。这就是 `validation-checklist.md` 第一节存在的意义。

**② 回测**：留出后 20 天检验——模型 MAPE **6.2%**，naive 历史均值 **40.6%**，模型远优于基准（证明弹性模型真的有价值，不是白上）。

**③ 灵敏度**（损耗率 ±20%）：

| 损耗率 | 最优价 | 收益 |
|---|---|---|
| 80% | 18.99 元 | 322.0 元 |
| 100% | 19.43 元 | 317.6 元 |
| 120% | 19.90 元 | 313.1 元 |

结论：损耗率越高 → 最优价越高（要覆盖更多损耗）、收益越低，方向合理且单调，结论稳健。

## 7. 成文摘要（带数字的平铺式，照这个味道写）

> 针对商超生鲜蔬菜定价补货问题，本文用对数线性模型 lnQ=a+b·lnP 估计需求价格弹性，得 b=−1.60；建立"进货量=销量/(1−损耗率)"的损耗校正链，以单日收益最大为目标求解最优售价 19.43 元，对应销量 26 kg、补货 29 kg、收益 317.6 元。回测显示模型 MAPE 6.2%，显著优于历史均值基准的 40.6%；损耗率 ±20% 摄动下最优价仅变化 0.9 元，结论稳健。

## 9. 两个带走的启示

1. **先过 sanity check 再谈精度**——一个符号/顺序错误能差出 9 个数量级，检查器比人先发现。
2. **弹性接近 −1 是定价的"敏感区"**——|b| 越靠近 1，最优价对成本/损耗越敏感，这也是为什么损耗率值得单独做灵敏度。
