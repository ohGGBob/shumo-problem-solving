# 排版与双格式交付（Word / LaTeX，交稿前的最后一公里）

> 对标社区同类 skill（math-modeling-skill 系、MathModelAgent）后的补强项：**内容好 ≠ 卷面好**。评委第一眼看的是版面——摘要页观感、公式编号、三线表、图清晰度。本手册覆盖国赛 CUMCM 版式规范与 Word / LaTeX 两条落地路线；美赛差异见 §5。
>
> ⚠️ **不信任记值**：以下字号/页边距/字数为通行口径，动笔前以**当年官网通知与本校教务要求**为准（见 `rules-and-deadlines.md`「开题第一动作」）。

## 1. 环境预检（和 `check_env.py` 同一时刻跑）

```bash
xelatex --version    # LaTeX 路线需要；缺失 → 走 Word 路线或装 TeX Live/MiKTeX
pandoc --version     # Word 路线需要（md→docx，公式转 OMML）
```

- 两者都缺且来不及装：**降级为 Word 手排**（模板直接在 Word 里填，公式用 MathType/自带编辑器）——别为了工具链把 3 小时搭进去。
- LaTeX 强烈推荐在线兜底：Overleaf 传模板即写即编译，本机环境再烂也不影响。

## 2. 国赛版式规范（通行口径，以当年通知为准）

| 项 | 规范 |
|---|---|
| 纸张/边距 | A4；上下左右各 2.5cm |
| 摘要页 | 题目 + 摘要（**800–1000 字**）+ 关键词（3–5 个）**同页**，此页不编页码 |
| 正文 | 页码从 1 起；标题编号 1、1.1、1.1.1 |
| 字体 | 中文宋体（正文小四/五号，一级标题黑体），西文/数字 Times New Roman |
| 行距 | 1.5 倍或固定 20–22 磅 |
| 公式 | 核心公式独立成行、右侧编号 (1)(2)…，正文用「式(1)」回指；行内符号用 $...$ 风格统一斜体 |
| 表 | **三线表**（只留顶线/栏目线/底线），表题在表上方居中「表 1 …」 |
| 图 | 图题在图下方居中「图 1 …」，≥300dpi，正文先引出后见图（见 `figures-and-abstract.md` 三件套） |
| 参考文献 | GB/T 7714，**5–8 条为宜，≥2 条近 5 年，≥1 条英文**（英文文献用 `ref_search.py` 检索核验） |
| 承诺书/编号页 | 按官方模板单独放，**不得出现姓名/学校等身份信息**（匿名红线） |

## 3. Word 路线（最稳，评委端兼容性最好）

```bash
# Markdown 初稿一键转 docx（公式自动转 OMML 原生格式，可继续编辑）
pandoc paper.md -o paper.docx --reference-doc=cumcm_ref.docx
```

- `cumcm_ref.docx`：预置好的样式参考文档（宋体小四正文 + 黑体标题 + Times 西文），首次用 Word「样式」面板调一次，之后每次转换自动套。
- 转换后手工收尾 5 件事：① 插入分页符使摘要独立成页；② 表格套三线表样式（去掉竖线）；③ 图表题注用「插入题注」建交叉引用（改图不乱号）；④ 公式编号右对齐（表格三列法：公式居中列 + 编号右列）；⑤ 通栏检查 Times New Roman 是否漏套。
- **优点**：评审端 WPS/Office 打开零风险；**缺点**：长公式排版弱 → 复杂模型建议双路线。

## 4. LaTeX 路线（公式多、观感上限高）

- 模板：用**当年官方/赛区推荐模板**（以官网为准）；没有就用通用 `ctexart` 文档类起步。
- 编译链：**xelatex**（中文必需）×2 遍（第二遍生成目录与交叉引用）：

```bash
xelatex main.tex && xelatex main.tex
```

- 常见坑：① 中文必须 `ctex` 宏包/文档类，pdfLaTeX 会豆腐块；② 图片路径用相对路径 `figures/`，别写绝对路径；③ 参考文献 `thebibliography` 手排或 BibTeX + `gbt7714` 宏包；④ 编译报错先看第一处 error，别滚屏找最后。
- **交稿前**：把 PDF 逐页滚一遍——公式溢出页边、图压页眉、表格跨页断裂是三大高频事故。

## 5. 美赛差异（MCM/ICM）

- **整份 PDF ≤25 页硬上限**（含 Summary Sheet/目录/正文/参考文献/附录/代码），页数预算见 `mcm-icm-guide.md`；
- 通版 Times New Roman 12pt、单倍或 1.15 倍行距（以当年 instructions 为准）；
- Summary Sheet 独立首页，页眉带**控制号（Control Number）**；
- AI Use Report 单独成文件、不计入 25 页（`ai-usage-report.md`）；
- 全英文，句式库见 `english-writing-mcm.md`。

## 6. 交稿格式自查清单（10 条，5 分钟过完）

1. ☐ 摘要 800–1000 字、含 3 个以上具体数值、与关键词同页（美赛：Summary Sheet 含量化结果）
2. ☐ 页边距/字号/行距符合当年通知
3. ☐ 所有公式有编号且被正文回指；符号与符号表一致
4. ☐ 表全部三线表、表题在上；图题在下、先引出后见图
5. ☐ 图 ≥300dpi、缩放后文字不小于正文（见 `figure-polish.md`）
6. ☐ 参考文献条条真实（`verify_refs.py` + `ref_search.py`）、GB/T 7714 著录完整
7. ☐ 全文无姓名/学校/区队号等身份信息（匿名红线）
8. ☐ 页码正确：摘要页无页码、正文从 1 起；无空白页/半行孤页
9. ☐ 文件命名按官方要求（控制号/报名号），PDF 与 Word 内容版本一致
10. ☐ 双格式同开对比一遍：公式、图、表在两个格式里都没糊没错位

> 评分联动：本清单对应 `paper-quality-gate.md` 百分制评分中的「排版 15 分」——格式自查不过，排版分直接扣。
