# 摘要国一化打磨（摘要 30 分 · 评委第一印象的胜负手）

> 定位：让摘要从"合格"到"国一"。摘要占评分大头（30/100），评委先看摘要定档——**四要素齐只是及格线，
> 国一是"数字密度 + 节奏 + 与正文逐字一致"三者都赢**。本手册讲怎么写，`scripts/abstract_check.py` 负责量化检查。

## 国一摘要四段式（照这个节奏写）

**第一段 · 问题定性（1–2 句）**：一句话说清"针对什么、要解决什么"，带**背景数字**（数据规模/业务规模）。

**第二段 · 方法（每问一句）**：每问一个**命名模型**（FMS/RFMS/Model I）+ 关键动作 + 一句"为什么这么建模"。
不要罗列所有细节，只写最高杠杆的 2–3 个模型。

**第三段 · 结果（每问 1–2 个数字）**：每问给**具体数字**（带单位/误差/置信）——`22.4%` 而不是"显著提升"。

**第四段 · 收尾（1–2 句）**：灵敏度量化结论（"对权重 ±10% 摄动，结果稳健，ARI≥0.88"）+ 一句可推广/落点。

## 数字密度规则（abstract_check.py 自动查）

- **每句至少 1 个具体数字**，国赛摘要 800–1000 字至少 **6–10 个关键数字**；
- 数字必须**带单位/量纲**（% / 元 / 吨 / 家 / 倍），不带单位的孤数（如"结果提升了"）等于没写；
- **严禁无数字句**——"效果良好 / 性能优异 / 稳定性显著提升"全部是废句，删或补数字；
- 摘要里的每个数字**必须能在 `results.json` 找到**（铁律二）——写摘要时对着 `out/results.json` 抄，不凭记忆；
- 最后跑 `crosscheck.py` 查摘要与正文同一数字是否一致（摘要写 19.43、正文写 19.5 = 直接扣分）。

## 四要素自查（对应 paper-quality-gate 关卡一）

| 要素 | 及格（有就行） | 国一（赢在这） |
|---|---|---|
| 问题 | 提到了本题 | 带背景数字 + 一句"难点在哪" |
| 方法 | 说了用什么模型 | 模型**有名字** + 关键动作 + 一句设计意图 |
| 结果 | 有结论 | 每问 1–2 个**带单位的具体数字** |
| 结论 | 有总结 | 灵敏度量化 + 可落点（对谁/做什么/预期效果） |

## 修辞清单（降 AI 味 + 提质感）

- **禁**：首先/其次/最后套娃、"众所周知"、"显著提升/明显改善"（无量化）、"综上所述我们"；
- **换**："效果较好" → "RMSE 由 8.1 降至 5.9（降幅 27.2%）"；
- **敢写**：负结果/局限一句（"成本约束下方案牺牲 3% 覆盖率换取 22% 成本降幅"）——比报喜更显严密；
- **动词化**：用"构建/融合/提出/求解"，少用"进行了/做了"。

## 标准动作（交稿前）

```bash
# 1. 从论文提取摘要段跑检查（四要素/数字密度/灵敏度/套娃词）
python scripts/abstract_check.py report/main.md --section 摘要
# 2. 数字对账（摘要数字须全在 results.json）
python scripts/abstract_check.py report/main.md --section 摘要 --results out/results.json
# 3. 跨文件一致性（摘要 vs 正文 vs 图注）
python scripts/crosscheck.py report/main.md
# 4. 全文 AI 味复查
python scripts/dedup_scan.py report/main.md 题干.txt
```

> 与 `paper-quality-gate.md` 关卡一/关卡六联动：摘要四要素缺项按关卡一打回；摘要分（30 分）是定稿评分里最大单项，打磨优先级永远最高。
