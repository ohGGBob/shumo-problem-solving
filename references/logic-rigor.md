# 逻辑推理严密性硬检查（支柱一）

> 定位：论文不是零件拼盘，而是一条**论证链**。评委打分时最反感的不是"模型简单"，而是"论证跳步、结论无依据、假设和模型两张皮"。本文件把"逻辑严密"变成逐问可勾选的清单。**每一问交付前必须逐条打勾，缺一项视为该问推理未完成。**

## 一、论证链六环，环环要能回答"凭什么"

从「问题」→「假设」→「模型」→「求解」→「结果」→「结论」，每一环向下走都必须有依据，上一环是下一环的充分前提：

1. **问题 → 假设**：假设是在简化"题目真实约束"，不是凭空添加。每条假设都对应题目中某个"太复杂/未知"的点。
2. **假设 → 模型**：模型中确实用到了该假设；没有假设支撑的模型步骤，就是"无源之水"。
3. **模型 → 求解**：求解算法与模型形式匹配（连续方程用积分、离散用枚举/优化、随机用采样）；不出现"模型是 A、代码是 B"的脱节。
4. **求解 → 结果**：结果由代码可复现产出，不是手填（见 `reproducibility.md`）。
5. **结果 → 结论**：结论必须由结果**推出**，且写清中间推理。禁止"结果看起来不错，因此方案优越"这类缺环断言。
6. **结论 → 建议**：可行性建议须有结果支撑，不写"应对 X 加强重视"式空话。

## 二、假设—模型双向可追溯（最易丢分却最该做）

- **正向**：每条假设在模型推导/代码里被实际引用——在论文中标注"（假设 2 用于式 3 的线性化）"。
- **反向**：模型里每处简化、每个近似，都能在假设清单找到对应条目。模型用到的、假设里没写的，就是"未声明的假设"，属逻辑漏洞。
- 自查：把假设清单和模型章节并排，逐条连线，断线的那一条要么补假设、要么删模型步骤。

## 三、量纲 / 量级 / 边界（sanity check 三连）

每问结果先过这三关再进论文，堵住"量产级错"：

- **量纲一致**：等式两边单位相同；速率单位、时间单位、距离单位不混用。
- **量级合理**：结果数量级符合常识（人口增长不出现负值、概率落在 [0,1]、重合度 ≤1、误差不超物理量级）。
- **边界 / 退化正确**：极端参数下模型退化成可手算的解析解（如权重都为 1、样本数为 0/1、距离为 0）。退化不对 = 公式或实现有误。

## 四、敢写反例与负结果（显严密，不丢分）

- 主动报告模型**不适用的情形**与**失败尝试**（"我们尝试了 X，但在 Y 条件下表现差，原因是…"）。
- 负结果 + 机制解释，比只报正结果更可信、更显团队"懂"模型边界。
- 反例用于划清结论适用范围，是严谨性的证据而非短板。

## 五、常见逻辑漏洞清单（逐条排查）

- **因果倒置 / 相关当因果**：把"a 与 b 同时变化"说成"a 导致 b"，缺机制或对照。
- **循环论证**：用结论证明前提（"该模型好，因为效果好"而效果又来自该模型）。
- **选择性报告**：只报支持结论的数字，隐藏相反结果。
- **无对照的结论**：声称"方法 A 优于 B"却没在同一数据/口径下对比。
- **偷换问题**：求解的是简化后 A'，却声称回答了原题 A。
- **外推过度**：把有限样本/特定场景的结论推广到全品类/长周期。

## 六、逐问自检打勾表（交付前过）

| 检查项 | 本问通过？ |
|---|---|
| 假设与模型双向可追溯，无断线 | ☐ |
| 模型→求解→结果 三者形式一致、可复现 | ☐ |
| 量纲、量级、边界退化三关都过 | ☐ |
| 结论由结果推出，无跳步断言 | ☐ |
| 凡"优于/显著"均有同口径对照或检验 | ☐ |
| 已主动说明适用边界 / 负结果 / 失败尝试 | ☐ |
| 无因果倒置、循环论证、选择性报告 | ☐ |

> 七项全勾 = 本问逻辑链完整。任一未勾，回到对应环节补证据，不要带病进论文。
