# 大数据题型专项手册（美赛 C 类 / MathorCup 大数据 / 自找数据场景）

> 定位：与 `data-science-playbook.md`（国赛 C 题数据链）**差异化**。本文件聚焦三类「大数据味更重」的场景：**美赛 C 类（统计逆问题 + 潜在变量 + 机制设计）**、**MathorCup 大数据等数据竞赛**、以及**需要自找数据/字段杂/样本大**的题。共性问题：数据量大、要自找、要可解释、要业务闭环。配套 `cases-2026-mcm.md`（MCM C）、`advanced-methods-templates.md`（DiD/MCMC/Sobol）使用。

## 一、这三类题和国赛 C 题差在哪

| 维度 | 国赛 C（`data-science-playbook.md`） | 美赛 C / 大数据赛 |
|---|---|---|
| 数据 | 官方给好 Excel | **常要自找**（API/爬虫/公开库），格式杂 |
| 核心任务 | 分类/预测/评价闭环 | **统计逆问题 + 潜在变量推断 + 机制设计** |
| 重点 | 数据清洗讲道理 + 可解释 | **统计严谨性 + 因果关系 + 决策建议** |
| 交付 | 国一论文 | **Policy Letter / 机制解释** |
| 语言 | 中文 | 英文（美赛） |

**心态**：国赛 C 是"把给定数据挖透"；美赛 C/大数据赛是"设计一个统计推断框架 + 给出可落地的机制/决策"。

## 二、自找数据的 5 个原则

1. **先列"要什么指标"再找数据**：逆向从题目要求反推所需字段，别先抓一堆再凑。
2. **可核验的权威源优先**：官方统计、学术数据集、公开 API；记录来源 + 抓取时间（写进参考文献，铁律一）。
3. **数据规模决策**：样本点少（<100）→ 统计/回归/灰色；中等（百~万）→ 机器学习；超大（>百万）→ 降维 + 采样 + 可解释模型。
4. **标注获取方式**：爬来的要标注抓取时间/清洗口径；API 受限要说明。
5. **找不到理想数据就显式假设**：写清"因数据限制采用 X 替代/模拟，并讨论影响"——比编造数据强一万倍（铁律）。

## 三、美赛 C 类：统计逆问题 + 潜在变量（拿 O 的关键）

> 美赛 C 常给"结果观测"，要你**反推背后机制**（如 2026 C：从粉丝投票逆推选手真实实力与评分公平性）。这是**逆问题**，不是直接预测。

### 3.1 逆问题建模套路
- 把"观测 = 潜在真实 + 噪声/系统误差"写成结构方程或分层模型。
- **潜在变量**：用贝叶斯/MCMC 推断（`advanced-methods-templates.md` §5），给**可信区间**而非点估计。
- **机制设计**：用反事实重放检验"哪种计分规则最公平/最不容易被操纵"（§10）。

### 3.2 因果推断（判断"到底是不是 X 导致 Y"）
- 有"前/后 + 处理/对照"结构 → **DiD 双重差分**（`advanced-methods-templates.md` §3），并做平行趋势检验。
- 有随机/准随机 → 断点回归 / 工具变量；仅相关 → 明确说"是相关性不是因果"（严谨性，支柱一）。

### 3.3 反事实与稳健性
- 多做几个**对照模型 / 扰动**，看结论是否稳健（支柱二的"证据链"式检验）。
- 诚实写负结果：某机制没被数据支持就直说，别硬给一个"最优"。

## 四、MathorCup 大数据等数据竞赛：工程化 + 业务解释

### 4.1 海量/高维数据的工程动作
- **降维先行**：PCA/截断 SVD；特征数 > 样本数时用正则（岭/Lasso）或树模型。
- **采样策略**：超大样本用分层采样 / 分批训练，报同样的评估口径。
- **类型编码**：高基数类别用目标编码/嵌入（要防泄露）；时空字段提取特征。
- **性能 vs 可解释的取舍**：堆 XGBoost/LightGBM 提精度，但**必须给 SHAP + 特征重要性**解释"为什么"。

### 4.2 业务闭环（大数据赛的拿分点）
- 不止给预测/分类，要把结果翻译成**业务动作**：对谁、做什么、预期效果、量化收益。
- 例：销量预测 → "把促销预算挪到周末 + 热销 SKU，预期提升 GMV 约 X%"。
- 用**决策表 / 分层策略**呈现，让评委看到"能落地"。

## 五、可解释性进阶（把黑箱变白，美赛 C 加分）

1. **SHAP 全局 + 局部**：全局看主导特征；局部看单个样本"为什么这么判"（`shap` 库）。
2. **部分依赖图（PDP）**：看某特征对预测的非线性影响。
3. **回扣业务机制**：统计结论 + 领域机制两头对，别让结果"数学上对、道理上说不通"。
4. **区间/分布预测**：替代点预测，体现不确定性量化（美赛 C 常要求）。

## 六、通用红线（三类题都适用）

1. **严禁标签泄露**：不许用全量数据选特征后再"验证"。
2. **只报准确率且类不平衡** → 用混淆矩阵 + AUC/F1/召回。
3. **预测无回测、无基准对比**。
4. **编造数据 / 编造来源**（铁律一，一票否决）。
5. **纯黑箱无解释**。
6. **相关当因果**，不区分就下因果结论。

## 七、交付骨架（大数据题特有的部分）

- **数据获取与清洗**：来源、抓取时间、清洗口径、审计表（`preprocessing-pipeline.md`）。
- **EDA 洞察**：挖出 1–2 个别人没发现的规律，作为建模依据（支柱二的数据洞察）。
- **统计推断框架**：观测 → 潜在变量 → 噪声，公式化。
- **因果/机制分析**：DiD / 反事实 / 稳健性。
- **Policy Letter**：给决策者的英文信（`english-writing-mcm.md` 第二节）。
