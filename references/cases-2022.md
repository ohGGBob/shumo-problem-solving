## 2022 A 题：波浪能最大输出功率设计（浮子—振子垂荡运动）

- **交付目标**：给出浮子—振子垂荡系统的动力学模型与数值解，输出「最大输出功率 + 对应最优阻尼系数（PTO）」这组核心设计数值，并给出约束下的最优设计方案。
  - 问1：二自由度垂荡微分方程（含推导）+ 稳态位移/速度数值 + 最大输出功率 \(P_{\max}\) 与对应阻尼 \(c^{*}\)。
  - 问2：非线性阻尼（系数随相对速度变化）下的新模型 + 数值最优功率。
  - 问3/4（待核实表述）：推广模型（不规则波/非线性恢复力/附加约束）与全参数优化设计。

- **问题拆解与建模思路**（逐小问）：

  - **问1：二自由度线性受迫振动的稳态响应 + PTO 功率最大化**。设浮子垂荡位移 \(z_1\)、振子绝对位移 \(z_2\)，相对位移 \(z_r=z_2-z_1\)。
    - 浮子受力：波浪激励 \(F_w(t)=F_0\cos(\omega t)\)（弗劳德–克雷洛夫力＋绕射力简谐近似）、静水恢复力 \(-\rho g A_{wl}z_1\)、附加质量与辐射阻尼、PTO 力 \(k z_r + c \dot z_r\)。
    - 振子受力：PTO 反作用 \(-k z_r - c\dot z_r\)（**符号与浮子相反**）、内部粘性阻尼。
    - 运动方程（线性二自由度）：
      \[
      m_1\ddot z_1 = -\rho g A_{wl} z_1 - c_1 \dot z_1 + k z_r + c \dot z_r + F_0\cos(\omega t),\quad
      m_2\ddot z_2 = -k z_r - c \dot z_r - c_2 \dot z_2
      \]
    - **频域稳态解是关键**：设 \(z_i=Z_i e^{i\omega t}\) 得 2×2 复数线性方程 \(A(\omega,c)Z=B\)，解出复幅值 \(Z_1,Z_2\)，相对速度幅值 \(V_r=|i\omega(Z_2-Z_1)|\)。
    - **平均输出功率**：\(\bar P(c)=\tfrac12 c\, V_r^2\)（**\(\tfrac12\) 是幅值→有效值因子，极易漏写**）。扫 \(c\) 或求导得 \(c^{*}\) 与 \(P_{\max}\)。
    - 理论底线：最大功率对应 **PTO 阻尼 = 系统等效阻尼（阻抗匹配）** 的共振调谐条件，可作解析校验。

  - **问2：把恒定阻尼推广为「阻尼 = 速度相关函数」的非线性 PTO**（分段/幂律 \(c(|\dot z_r|)\)）。频域不适用，需**时域数值积分**到稳态后按 \(P=\langle c(\dot z_r)\dot z_r^2\rangle\) 取时间平均，再优化求最优参数。

  - **问3/4（待核实）**：通常为非线性恢复力/大振幅、振子行程约束（不碰撞内壁）、不规则波谱加权、几何/刚度/阻尼/质量综合优化。

- **求解算法与 Python 要点**：频域用 `numpy` 构造复数 2×2 矩阵 + `np.linalg.solve`；`scipy.optimize.minimize_scalar` 求 \(c^{*}\)。时域用 `scipy.integrate.solve_ivp`（`method='BDF'` 防刚性），丢弃瞬态后 `np.trapz` 平均。多参数用 `minimize`/`differential_evolution`。

- **模型检验与灵敏度**：频域 vs 时域稳态解互校；能量守恒校验（输入功率 ≈ PTO 吸收 + 阻尼耗散）；\(c^{*}\) 与阻抗匹配解析解比对；扫 \(c\) 看峰位、扫 \(k\)/质量比/周期 \(T\) 多工况；行程约束敏感性。

- **国一亮点建议**：① 引入频域传递函数/RAO 与阻抗匹配给 \(c^{*}\) 解析式再数值验证；② 画功率—阻尼曲线 + 幅频响应，点明「共振调谐点 = 最大功率点」；③ 不规则波用波谱 \(S(\omega)\)×RAO 卷积求谱平均功率，给「功率 vs 行程」帕累托前沿。

- **高频失分点**：① PTO 力作用对象符号搞反、\(z_r\) 与 \(z_2\) 混用；② 平均功率漏 \(\tfrac12\) 或含瞬态取平均；③ 忽略附加质量/辐射阻尼，只时域硬解不扫参。

## 2022 B 题：无人机遂行编队飞行的纯方位无源定位与调整

- **交付目标**：给出纯方位无源定位的可定位性判定与定位模型，及圆形/方形编队存在偏差时的定位解算与最小调整方案。
  - 问1：最少发射信号无人机数结论（含可观测性论证）+ 定位解算表达式/步骤。
  - 问2：圆形编队存在偏差时的坐标反算（最小二乘/非线性）+ 调整到位方案。
  - 问3：方形编队的定位与调整方案。

- **问题拆解与建模思路**（逐小问）：

  - **问1：纯方位（仅角度、无距离）无源定位的可观测性与最小信标数**。待定位机 \(u(x_u,y_u)\) 测信标 \(j(x_j,y_j)\) 方位角：
    \[
    \theta_{uj}=\operatorname{atan2}(y_j-y_u,\,x_j-x_u)
    \]
    未知坐标 2 个，需**≥2 条独立方位观测**；但存在**几何退化**（共线/对称/两圆双交点非唯一），故一般需 **3 条非退化方位线**（三站交会）。关键是无人机**位于已知半径圆周（或方形顶点）**，此约束可减少观测量，需严格讨论「最少几架 + 何种布局不退化」。（精确最少信标数以题面与官方评阅为准，待核实。）

  - **问2：「由方位观测反算坐标（参数估计）+ 有界协调调整」**。已知理想圆编队坐标与若干机微偏，残差最小化：
    \[
    \min_{x,y}\sum_{u,j}\big(\theta_{uj}^{\text{实测}}-\theta_{uj}(x,y)\big)^2
    \]
    非线性最小二乘得实际坐标，再以「总移动距离最小 + 到位精度」为目标给调整方案。

  - **问3：几何约束由「圆周」换「方形顶点/边」**，重写坐标约束与方位几何，其余同问2。

- **求解算法与 Python 要点**：非线性方程 `scipy.optimize.fsolve/root`；多观测最小二乘 `scipy.optimize.least_squares`；定位顺序传播可用 `networkx`；最小移动距离指派 `scipy.optimize.linear_sum_assignment`。

- **模型检验与灵敏度**：蒙特卡洛定位精度（方位加噪统计误差）+ GDOP/CRLB；退化几何专项检验（共线/对称奇异）；唯一性/多解（两圆两交点、镜像解）；调整总代价 vs 允许误差权衡。

- **国一亮点建议**：① 用 GDOP/CRLB 定量评价信标布局并择优发射组合；② 严格论证几何退化条件并给规避布局；③ 定位误差传播 + 匈牙利指派，做「先定位→再最优调整」两阶段闭环。

- **高频失分点**：① 方位角 `atan2` 象限/基准不清，一错全错；② 混淆「已知位置」与「待定位」，可观测性论证凭感觉写「3 架」；③ 忽略多解/退化构型导致奇异，调整方案不讨论航线冲突与饱和。

## 2022 C 题：古代玻璃制品（高钾/铅钡）成分分析与风化前后鉴别

- **交付目标**：给出高钾/铅钡玻璃的分类规律与亚类划分、风化前后成分变化规律与预测模型、未知类型鉴别结果，并做统计检验与关联分析。
  - 问1：风化 vs 类型/纹饰/颜色关系（列联表＋检验）＋分类规律＋成分统计＋风化前成分预测。
  - 问2：高钾、铅钡各自亚类划分（聚类结果、数量、成员、依据）＋合理性/敏感性。
  - 问3：附件3 未知玻璃类型鉴别 ＋风化前成分预测。
  - 问4：类型—成分关联分析（相关系数/重要性 + 考古解释）。

- **问题拆解与建模思路**（逐小问）：

  - **问1：分类变量关联检验 + 成分描述统计 + 风化前后对照建模**。风化 vs 类型/纹饰/颜色用**列联表 + 卡方检验**（`scipy.stats.chi2_contingency`）。分类规律看**特征成分**：铅钡玻璃 PbO/BaO 高、高钾玻璃 K₂O 高。风化前后：碱金属/碱土金属氧化物（K₂O、Na₂O、CaO、MgO）流失、SiO₂ 等表观富集（**占比数据，分母变小**）；建立流失/富集系数回归预测风化前成分。

  - **问2：无监督聚类亚类划分 + 聚类数选择 + 鲁棒性**。标准化（注意**成分闭和约束**，用 z-score 或 log-ratio），`KMeans`/层次聚类/DBSCAN；聚类数用**肘部 + 轮廓系数 silhouette_score + 树状图**；报告亚类特征差异 + 敏感性（换 k/标准化/方法）。

  - **问3：有监督分类 + 成分补全预测**。用规则/分类器（最近类中心、LDA、随机森林、KNN）鉴别附件3 类型；风化样品用流失/富集系数**回归预测风化前成分**；**分层 K 折交叉验证**报准确率防过拟合。

  - **问4：类型—成分关联 + 考古解释**。皮尔逊/斯皮尔曼相关、ANOVA/卡方、PCA 载荷、随机森林特征重要性；结合考古先验（助熔剂、着色剂 CuO 绿/Fe 系）。

- **求解算法与 Python 要点**：`pandas.read_excel/groupby/describe`；`scipy.stats` 全套；`sklearn.cluster.KMeans/AgglomerativeClustering`、`sklearn.decomposition.PCA`、`RandomForestClassifier/LDA/KNN`、`cross_val_score`。

- **模型检验与灵敏度**：分层 K 折交叉验证（报混淆矩阵）；聚类数 k 敏感性（轮廓系数曲线）；标准化方式敏感性（原始占比/z-score/log-ratio）；风化预测用留一验证/回归 R²/残差。

- **国一亮点建议**：① 显式处理**成分闭和约束**（log-ratio/Aitchison 几何），避免「绝对含量」误读；② 聚类/分类结果**回扣考古先验**（助熔剂、着色剂、产地工艺）；③ 多分类器集成 + 交叉验证，风化前成分给**区间预测**（不确定性量化）。

- **高频失分点**：① 百分比成分当绝对含量、忽略闭和约束与「相对富集」伪象；② 缺失值（未测）乱删或填 0；③ 聚类数拍脑袋、分类不交叉验证、问3 混用问2 标签造成标签泄露。

## 2022 年难度与选题提示

- **A（波浪能）**：物理+微分方程，推导门槛最高，适合力学/机电基础好、熟 ODE 与频域分析的队；上限取决于懂不懂共振/阻抗匹配。
- **B（无人机定位）**：几何+优化，上手快、高分难，区分点在可观测性、退化几何、GDOP 与最小调度。
- **C（玻璃成分）**：数据分析/统计，最稳、最容易出完整有结果的文章，适合掌握 pandas+sklearn 基础链、写作细致的队。
- 总体：A 硬核建模、B 几何算法、C 数据挖掘。求稳选 C、爱物理选 A、擅几何优化选 B。
