# 亮点预埋：A/B/C 三题型可移植亮点骨架（赛中直接套）

> 定位：`innovation-playbook.md` 讲"创新套路与原则"，本文件给**开赛前就能预写、赛中直接套**的三题型亮点骨架。国一的区分度在"创新有据"——亮点是**设计出来的**，不是赛后找的。每个骨架 = 模型组合 + 证据链 + 论文落点模板 + 预写清单，按「识别信号」命中即套。

## 用法三步（赛中 30 秒内完成定位）

1. **识别题型**：看题目信号判断 A（机理/物理）/ B（统计/优化/图论）/ C（大数据/机器学习）；
2. **选骨架**：对照"骨架选择速查表"挑 1–2 个最贴合的（每问 2–3 个扎实亮点 > 10 个浮于表面）；
3. **套数据补证据**：把骨架的模型组合落到本题，跑出数值，按"论文落点模板"填空成文——骨架不换，数据/证据全换。

## A 题 · 机理 / 物理类

**识别信号**：物理过程（光、声、流体、热、电磁、几何运动）、单位与物理量明显（光程差、功率、覆盖宽度…）、连续系统、微分/积分方程主导。

### 骨架 A1 · 机理主模型 + 残差驱动修正（机理定主值，数据学偏差）
- **卖点**：既展示第一性原理功底，又用数据把模型"校准到贴着实测"——耦合逻辑一句话讲清"谁修正谁"。
- **模型组合**：解析/数值主模型（微分方程、几何关系）算出主值 → 用实测/高精度解算残差 → 残差建模（多项式/小网络/插值）→ 主值+残差修正。
- **关键步骤**：① 机理建模得主值 y0；② 算残差 r = y_true − y0；③ 残差单独建模得 r̂；④ 输出 y = y0 + r̂；⑤ 报告各分量贡献占比。
- **证据链**：修正前后 vs 基准的相对误差表（L2/相对误差下降 X%）；灵敏度：对残差模型复杂度做 AIC/BIC 取舍。
- **论文落点模板**：`将___建模为___（机理方程），得到主值 y0；实测残差 r = y − y0 由___（方法）拟合，最终 y = y0 + r̂，使回测误差从___降至___。`
- **对应套路**：创新套路 2（机理+数据融合）。
- **预写清单**：机理方程模板（含无量纲化）、残差建模代码（多项式+小网络两版）、"分量贡献占比"柱状图模板。

### 骨架 A2 · 连续系统离散化 + 物理分量分解表（算得快 + 讲得清）
- **卖点**：把"积出来一个数"升级为"积出来 + 每一步物理意义可分解"，评委一眼看出你懂过程。
- **模型组合**：连续积分/微分 → 高效离散化（梯形/辛普森/解析分段近似）→ 把总指标按物理分量拆解成贡献表。
- **关键步骤**：① 写清连续模型与离散化误差界；② 选步长使离散误差 < 目标精度；③ 总指标 = Σ 物理分量，逐项算贡献；④ 用分量表回答"哪部分主导"。
- **证据链**：离散误差随步长收敛曲线（网格收敛）；与解析解/实测对比；分量分解表。
- **论文落点模板**：`对___沿___离散（___法，误差界___），总___ = Σ 各分量，其中___贡献最大（占__%），据此___。`
- **对应套路**：套路 4（针对性改进）+ 8（可视化：分量堆叠图/收敛曲线）。
- **预写清单**：三套离散化代码（梯形/辛普森/解析近似）、网格收敛图模板、分量堆叠柱状图模板。

### 骨架 A3 · 参数反演 / 标定 + 不确定性传播（不报裸数，报置信）
- **卖点**：把"假设参数 = 给定值"升级为"用数据反演关键参数 + 报告不确定度"，直接命中"稳健性"。
- **模型组合**：机理模型含未知参数 → 最小二乘/贝叶斯反演标定 → 蒙特卡洛扰动传播 → 输出参数估计 ± 不确定度。
- **关键步骤**：① 识别 1–2 个对结果最敏感的参数；② 用数据/文献先验反演；③ 蒙特卡洛对参数分布采样重算结果；④ 报告均值、95% 区间、主导敏感参数及物理解释。
- **证据链**：参数后验分布图；结果 ± 区间；灵敏度排序（哪个参数最影响结论）。
- **论文落点模板**：`对参数 θ 用___反演得 θ̂=___（95% CI [__,__]）；蒙特卡洛扰动下结果均值为___、区间[__,__]，敏感参数为___，物理含义为___。`
- **对应套路**：套路 5（检验证据链）+ 7（定义/量化新量）。
- **预写清单**：反演代码（scipy.least_squares + MCMC 两版）、蒙特卡洛扰动框架、参数分布/区间图模板。

## B 题 · 统计 / 优化 / 图论 / 运筹类

**识别信号**：资源分配、调度、路径、生产计划、预测、评价、决策、约束下求最优。

### 骨架 B1 · 预测→决策闭环（预测值直接喂进优化目标，回测验证）
- **卖点**：把"先预测、再决策"两步割裂，升级为"预测不确定性进优化目标"的一体化闭环，是 B 题最常用且评委认可度高的亮点。
- **模型组合**：预测模型（时间序列/回归/ML）→ 预测值（含分位数/区间）作为优化模型参数 → 求解最优决策 → 用历史回测验证闭环收益。
- **关键步骤**：① 预测得点估计+区间；② 把预测值/分位数代入优化目标与约束；③ 求解（LP/MILP/启发式）；④ 回测：滚动窗口下闭环 vs 分开做的收益差。
- **证据链**：回测收益对比（闭环 vs 分离）；预测区间覆盖率；对预测误差的鲁棒性。
- **论文落点模板**：`将___预测值（含 P95 区间）直接作为___优化模型的参数，形成"预测→决策"闭环；滚动回测下，闭环方案较分离式收益提升___%，且对预测误差不敏感。`
- **对应套路**：套路 2（机理+数据融合的"预测→优化"形态）+ 5（检验证据链）。
- **预写清单**：滚动回测框架代码、预测+优化衔接模板、回测收益对比图模板。

### 骨架 B2 · 多模型对照 + 组合权重 / 择优（最稳，人人能做但要讲清）
- **卖点**：异质模型解同一问，比较后择优或加权融合，并写清"为什么最终选它"——评审最爱看的理性取舍。
- **模型组合**：评价题用 AHP（主观权）+ 熵权（客观权）→ 组合权重；预测题用 GM(1,1) + ARIMA + 随机森林 → 回测误差择优或加权平均。
- **关键步骤**：① 选 2–3 个**异质**模型（不同原理，别换汤不换药）；② 各跑出结果与误差；③ 比较表（误差/复杂度/解释性）；④ 择优或加权（按误差倒数权重等）；⑤ 写清取舍理由。
- **证据链**：多模型误差对比表；组合权重 vs 单一权重的稳健性；权重敏感性。
- **论文落点模板**：`对___同时采用___、___、___三个异质模型，回测误差分别为___/___/___；最终选择___，理由为___；组合权重方案在___变化下结论稳定。`
- **对应套路**：套路 1（多模型对照）+ 4（一处改进）。
- **预写清单**：GM/ARIMA/RF 三模型代码、AHP+熵权组合代码、误差对比表与权重敏感性图模板。

### 骨架 B3 · 风险鲁棒优化（均值-方差 / CVaR + 蒙特卡洛扰动）
- **卖点**：把"求一个最优解"升级为"在不确定下求稳健解"，直接命中"稳健性"硬指标。
- **模型组合**：确定性优化 → 引入不确定性（参数区间/分布）→ 均值-方差或 CVaR 目标 → 蒙特卡洛扰动下比较确定性解 vs 鲁棒解。
- **关键步骤**：① 识别不确定参数；② 建风险目标（CVaR_α 或均值-方差）；③ 求解鲁棒解；④ 蒙特卡洛对不确定参数采样，比较两解的分布（期望/尾部风险）。
- **证据链**：确定性解 vs 鲁棒解在 1000 次扰动下的分布对比（期望收益、CVaR、最坏情形）；对风险厌恶系数 λ 的敏感性。
- **论文落点模板**：`引入___不确定性后，用 CVaR_{α=__} 建风险目标；蒙特卡洛扰动下，鲁棒解较确定性解期望损失降低___%、最坏情形改善___%，代价为收益下降___%，换取风险可控。`
- **对应套路**：套路 5（证据链）+ 3（等价转化）。
- **预写清单**：CVaR/均值-方差优化代码、蒙特卡洛扰动比较框架、两解分布对比图模板。

## C 题 · 大数据 / 机器学习 / 统计逆问题类

**识别信号**：数据量大、特征多、分类/回归/聚类、预测精度 + 可解释性 + 业务闭环、从观测反推机制。

### 骨架 C1 · 可解释管道（强模型 + SHAP + 阈值优化 + 业务闭环）
- **卖点**：不只报精度，还把"模型为什么这么判"讲给评委，并落到可执行的业务建议——C 题高分标配。
- **模型组合**：XGBoost/LightGBM/GAM 等强模型 → SHAP 全局/局部解释 → 最优阈值（Youden/成本权衡）→ 按特征影响给业务建议。
- **关键步骤**：① 训练强模型并交叉验证；② SHAP 得全局特征排序 + 关键样本解释；③ 阈值/决策边界按代价函数优化；④ 把"哪个特征驱动"翻译成业务建议。
- **证据链**：交叉验证精度/召回/AUC；SHAP 排序图；阈值-代价曲线；特征-结果可解释图。
- **论文落点模板**：`用___（模型）在___上取得 AUC=___；SHAP 显示主导特征为___（贡献__%）；按代价函数取最优阈值___，并据此给出___的可执行建议。`
- **对应套路**：套路 6（可解释挖掘）+ 7（定义指标）+ 9（数据洞察）。
- **预写清单**：XGB+SHAP 管道代码、阈值优化代码、SHAP 图与代价曲线图模板。

### 骨架 C2 · 统计逆问题 + 不确定性区间（概率建模 + 后验 / Pareto）
- **卖点**：把"给一个预测值"升级为"给分布 + 区间 + 时点-性能权衡"，直接命中统计深度。
- **模型组合**：概率模型（GAM 纵向/随机效应/贝叶斯）→ 预测分布 → 区间估计 → 多时点/多阈值 Pareto 权衡。
- **关键步骤**：① 建概率模型（含随机截距/效应）；② 得预测分布与区间；③ 多时点下性能（敏感度-特异度）画 Pareto 前沿；④ 选工作点并报告不确定度。
- **证据链**：预测区间覆盖率；后验/重采样分布图；Pareto 前沿 + 工作点选择依据。
- **论文落点模板**：`用___（概率模型）对___建模，预测区间在___% 水平覆盖率为___；多时点性能呈 Pareto 前沿，选定工作点___（Youden 指数___），区间宽度为___。`
- **对应套路**：套路 5（证据链）+ 7（新指标）+ 3（转化）。
- **预写清单**：GAM/贝叶斯模型代码、区间覆盖率校验、Pareto 前沿图模板。

### 骨架 C3 · EDA 数据洞察先行 + 特征工程（挖出别人没发现的规律再建模）
- **卖点**：先深挖数据（异常/周期/非线性/隐藏结构），用发现的规律反哺特征与建模——评委看到"你懂数据"。
- **模型组合**：EDA（分布/相关性/时间模式/异常）→ 洞察驱动特征工程 → 建模（可接 C1 或 C2）→ 用洞察解释结果。
- **关键步骤**：① 系统性 EDA（分布、缺失、相关性、周期、异常）；② 提炼 2–3 条可验证洞察（如"存在非线性阈值效应""距离是关键"）；③ 据此造特征/换模型结构；④ 回扣洞察解释结果。
- **证据链**：EDA 关键图（相关矩阵/周期谱/阈值散点）；"加洞察特征前后"精度对比；洞察的统计检验。
- **论文落点模板**：`EDA 发现___（规律，附图）；据此构造特征___后，模型精度从___升至___；该洞察同时解释了结果中___现象。`
- **对应套路**：套路 9（数据洞察）+ 8（可视化）。
- **预写清单**：EDA 一键脚本（分布/相关/谱/异常）、洞察驱动特征模板、前后精度对比图模板。

## 骨架选择速查表（命中即套）

| 题目信号 | 题型 | 首选骨架 |
|---|---|---|
| 物理过程/微分方程/几何运动 | A | A1（机理+残差）或 A2（离散化+分量表） |
| 需标定参数/报不确定度 | A | A3（反演+不确定度） |
| 先预测后决策/调度生产 | B | B1（预测→决策闭环） |
| 评价/权重/多个方法选优 | B | B2（多模型对照+组合权重） |
| 不确定下求最优/风险 | B | B3（风险鲁棒优化） |
| 大数据分类/预测+要解释 | C | C1（可解释管道） |
| 概率建模/逆问题/要区间 | C | C2（统计逆问题+不确定度） |
| 数据很脏但规律藏在里面 | C | C3（EDA 洞察先行） |

## 赛前预写清单（开赛前 8 天内的周末，一次备齐）

- [ ] A 题：机理方程模板（含无量纲化）、残差建模、离散化三套、反演+蒙特卡洛框架
- [ ] B 题：GM/ARIMA/RF 三模型、AHP+熵权、CVaR+蒙特卡洛、滚动回测框架
- [ ] C 题：XGB+SHAP、GAM/贝叶斯、EDA 一键脚本、阈值优化
- [ ] 每骨架配好：代码模板 + 2 张图模板（对比图/分布图）+ 一段"论文落点"填好变量的示例
- [ ] 全部模板过 `check_env.py` + 固定 seed 可复现

> 使用边界：骨架是"结构"，不是"结论"——每个亮点必须在本题数据上跑出真实数值、完成证据链，禁止把骨架当结论直接抄进论文（假创新反而扣分，见 `innovation-playbook.md` 反模式）。
