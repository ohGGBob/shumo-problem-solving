# 美赛 MCM / ICM 专册（与国赛共用骨架，两套打法）

> 定位：国赛练手、美赛变现。美赛看「创意 + 建模合理性 + 清晰沟通 + 可视化」，不要求算法绝对新颖；评审快速阅读，标题 / 图 / 结论句要能独立传达结论。

## 六题定位与选题

| 题 | 领域 | 常见题型 | 建议模型族 |
|---|---|---|---|

## 关键规则（别踩线）

> ⚠️ **2026/2027 赛季规则已变，旧经验会害你**：页数口径由「正文 ≤25 页」改为「**全文合计 ≤25 页**」。详见下节。

- **96 小时 / 4 天**。
- **总页数 ≤25 页（含 Summary Sheet、目录、正文、参考文献、附录、代码）**；**AI Use Report 不计入 25 页**。
- **Summary Sheet（摘要页）独立评审，是命门**：独立成页、四要素 + 数值。
- 数据常需**自己找**：用权威来源（政府 / 国际组织 / 期刊 / 官方统计），并规范引用；**须为开放许可、可获取、可复现**。
- 敏感话题（政策 / 政治 / 种族 / 性别等）保持**中立、可量化**：只谈指标与数据，不下价值判断、不站队。

### 25 页页面预算（建议模板，开赛即定）

| 部分 | 建议页数 | 说明 |
|---|---|---|
| Summary Sheet | 1 | 硬性独立一页，**不可压缩** |
| Table of Contents | 0.5–1 | 官方要求项 |
| Introduction / 问题重述与分析 | 1.5–2 | 别抄题面，直接给分析框架 |
| Assumptions & Notation | 1–1.5 | 表格化，省空间 |
| 模型建立（各问） | 7–9 | **核心，优先保这里** |
| 求解结果与分析 | 5–6 | 图表为主，正文少铺陈 |
| 检验 / 灵敏度 / 稳健性 | 2–3 | 不能砍，这是严谨性得分点 |
| 优缺点与推广 | 0.5–1 | 简洁 |
| 备忘录 / 建议信（ICM 常要） | 1–2 | 独立文体，面向非技术读者 |
| References | 0.5–1 | **计入 25 页**，控制条目数 |
| Appendix / 代码 | 0–1 | **计入 25 页 → 代码只放核心片段** |
| AI Use Report | 不计入 | 单独附在最后 |

> 🔑 **新规下最大的打法变化：附录与代码不再免费。**
> - 旧习惯是把大段代码塞附录充实感 → **现在会挤掉正文**。
> - 正确做法：代码只放**最关键的 10–30 行**（或干脆不放，改为在正文写清算法步骤 + 伪代码），完整代码用**外部可复现说明**（如"代码结构见 §4.2 描述，参数见表 5"）替代。
> - 参考文献也计入 → **宁精不滥**，15–25 条高质量文献足够，别为凑数堆引用（且每条都要在正文被引用，见 `scripts/verify_refs.py`）。
> - 排版省页技巧：图表用双栏并排、表格代替长段落、图注紧凑、避免大段空白；**但不要把字号缩到难读**——可读性是评分项。

## 英文写作要点

- 术语规范、简洁；用**过去时**描述"做了什么"，**现在时**描述"成立的结论"。
- 避免中式英语长句堆叠；每段首句点结论，评审扫读也能抓住重点。
- 图注自足：不看正文，光看标题 + 图也能懂。

### 英文 QA 自查（交稿前过一遍）

- **术语一致**：同一概念全篇同一个词（先定一份术语表）；图表单位、变量符号与正文一致。
- **句式**：短句优先，一段一句结论；避免一句 30+ 词的中式长句。
- **语态/时态**：过去时写"做了什么"，现在时写"成立结论"；能主动语态就别被动语态堆叠。
- **形式**：主谓一致、冠词、单复数、单位符号（%）前后一致；数字与国赛用同一份 `results.json`，避免手抄造成中英数字不一致。

## 与国赛的风格差异（同骨架，两打法）

| 维度 | 国赛 CUMCM | 美赛 MCM/ICM |
|---|---|---|
| 评审重点 | 模型严谨、求解正确、检验到位 | 创意 + 合理 + 清晰 + 可视化 |
| 篇幅 | 无硬上限（通常十几页） | ≤25 页 |
| 语言 | 中文 | 英文（Summary 独立） |
| 数据 | 常给定 | 常需自找 |
| 重点打法 | 机理 / 检验深度 | 叙事、图表、迁移性 |

> 共性详见 `paper-skeleton.md`（Summary Sheet 模板）、`model-recipes.md`（模型配方）、`innovation-playbook.md`（亮点）。美赛尤其吃「一张令人印象深刻的图 + 一个可以讲通的故事」。
