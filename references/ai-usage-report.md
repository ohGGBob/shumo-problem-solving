# AI 使用报告（2026 国赛合规辅助材料）

> 依据《全国大学生数学建模竞赛人工智能工具使用规定（2026年试行）》（全国组委会 2026-08-03 发布，2026-09-01 起试行；官方源：mcm.edu.cn）。**先核规则再动笔**（铁律三）——本页内容基于官方原文，如规则更新以官网为准。

## 一、核心规则（必须全部满足）

1. **不强制用 AI，但公开透明**：核心建模与分析由参赛队主导；AI 参与的内容逐项人工审查与核实。
2. **所有参赛队（用没用 AI 都要）在论文参考文献之前设置「AI工具使用声明」**，二者择一：
   - 未使用：`本参赛队在竞赛过程中未使用任何AI工具。`
   - 使用：`本参赛队在竞赛过程中使用了AI工具，主要用于【简要用途，如语言润色、代码调试等】，详细使用情况见支撑材料。`
3. **使用 AI 的参赛作品，须在支撑材料中提交「AI工具使用详情.pdf」**（PDF 格式，文件名必须严格一致），内容四要素：
   - (1) 所用 AI 工具名称、版本或型号；
   - (2) 具体使用目的和环节；
   - (3) 主要提示方式与使用过程说明（可附典型交互示例）；
   - (4) 对 AI 输出的采纳、人工修改和核验的主要情况（**语言润色除外**）。
4. **匿名**：详情文件与整个支撑材料不得出现学校、参赛队编号、队员姓名、指导教师、联系方式、账号、签名（含文件名与文档属性）。

## 二、取消评奖资格的红线（一票否决）

- 故意隐瞒 AI 使用情况；
- 作出虚假声明；
- 将未经必要人工审查与核实的 AI 生成内容**直接作为核心建模与分析成果**提交。

> 红线含义：用 AI 本身不违规，**隐瞒 + 不核验**才是违规。诚实披露 + 每项 AI 输出人工核验，是最安全的姿势。

## 三、本 skill 的合规用法（一键三连）

```bash
# 1) 每次拍板留痕（AI 参与情况如实写进 --ai）
python scripts/decision_log.py <项目目录> add --phase 模型选型 --decision "..." --why "..." --ai "AI提供3种候选思路，本队独立推导验证后选定"

# 2) 生成声明 + 使用详情（自动汇总决策日志）
python scripts/gen_ai_report.py <项目目录> --tools "豆包;ChatGPT 4o"

# 3) 若系统有 pandoc 会转出 out/AI工具使用详情.pdf；否则用 Word/浏览器把 ai_usage_report.md 另存为 PDF
```

- **声明**：粘贴到论文参考文献之前（gen_ai_report 输出到 `report/ai_declaration.txt`）。
- **详情**：`log/ai_usage_report.md` 已按官方四要素排好，重点补全「三、提示方式与过程」和「四、采纳/修改/核验」——**核验必须写动作**（如"对 AI 公式逐行推导"、"用真实数据重算比对"），禁止只写"已核验"。
- 转 PDF 后放进支撑材料压缩包，文件名保持 `AI工具使用详情.pdf`。

## 四、AI 能做什么 / 不能做什么（2026 边界）

| ✅ 允许（辅助） | ❌ 禁止（直接生成核心） |
|---|---|
| 语言润色、错别字修改 | 研究选题、研究假设、研究框架 |
| 代码调试、绘图 | 核心建模方案（须本队主导设计） |
| 文献检索、关键词推荐、参考文献格式整理 | 代写部分或全部论文 |
| 对思路的启发与讨论（经本队独立验证后采纳） | 直接复制 AI 输出作为最终报告 |

> 判断标准：**"核心建模与分析由参赛队主导"**。AI 当"讨论对象/校对/代码工"，不当"大脑"。

## 五、边界声明

本 skill 只做**如实记录与格式化**：不教隐瞒、不编造使用情况、不替参赛队"洗"AI 痕迹。若决策日志无 AI 记录而声明"使用了 AI"，gen_ai_report 会显式提示人工补全——合规责任始终在参赛队。
