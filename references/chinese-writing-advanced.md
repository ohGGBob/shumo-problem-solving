# 中文写作进阶（句式库 / 语病对照 / 精打磨）

> 定位：`bao-paper-writing.md` 讲「对标国一/O 奖的写作动作」，本文件从**语言层**把中文稿再抠细——给可用句式、常见语病与 AI 味措辞对照、以及"改一句顶三句"的精打磨动作。配套 `writing-deai-dedup.md`（降 AI 味/降重）一起用。目标是让每一段都像**有经验的学长手写**，而不是模板拼装。

## 一、可用中文句式库（按用途挑，别硬套）

### 1. 摘要 / 结论（信息密度拉满）
- `针对<问题>，本文构建了<模型名>，用<数据/方法>拟合出<关键量>=<数值>，据此给出<结论/建议>。`
- `<模型名>的核心思想是把<对象>建模为<抽象>，用<求解法>得到<结果>；在<条件>下与实测误差<误差>。`
- `灵敏度显示<参数>最敏感：±<X>% 摄动下<结果>变化 <Δ>，说明<结论>稳健。`
- `与<基准>相比，本文方法误差降低 <X>%（<A>→<B>），且<额外优势>。`

### 2. 假设（写成"一句可辩护的判断"）
- `假设<对象>服从<规则>，因其量级约 <X>% 可忽略 / 由<文献/数据>支撑。`
- `为简化<环节>，假设<X>，该假设的失效边界是<条件>，届时<影响>。`

### 3. 模型建立（讲"为什么这么建"）
- `本题属于<类型>问题，故选用<模型>；与<替代方案>相比，其优势在于<本质匹配点>。`
- `<模型>在标准做法上做了<一处>改进：<改进>，理由是<原理>。`
- `把<对象>的<量>作为决策变量，目标为<目标>，约束包括<约束>，构成<问题类型>。`

### 4. 检验（写成实证）
- `对<参数>做 ±<X>% 摄动，<结果>变化 <Δ>，<结论>在<范围>内成立。`
- `蒙特卡洛 <N> 次重采样，<量>的 95% 区间为 [<a>, <b>]，未出现<异常>。`
- `与<真实值/基准>对比，误差 <误差>，主要误差源是<来源>。`

### 5. 缺点 / 局限（机制化，不空喊）
- `模型的局限在于<具体机制>，导致<后果>；在<条件>下尤为明显，可<改进方向>。`
- `由于<假设/数据>，本模型对<情形>适用性有限，推广需<条件>。`

### 6. 落点 / 建议（给谁、做什么、预期效果）
- `建议<对象>采取<动作>，预期<量化效果>（依据<模型/数据>）。`
- `据此，管理者应<动作>，可<预期结果>，并对<敏感参数>保持关注。`

## 二、高频语病 / AI 味措辞对照（动手写时就避开）

| ❌ 空泛 / AI 味 | ✅ 具体写法 | 说明 |
|---|---|---|
| 采用了科学合理的方法 | 用最小二乘拟合 lnQ 与 lnP，得弹性 b=−0.83 | 给模型名+数字 |
| 数据经过充分预处理 | 剔除 37 家近半年断供供应商，缺失值用中位数填补 | 给具体操作 |
| 模型具有良好的性能 | 测试集 R²=0.91，MAPE 6.2%，优于历史均值基准的 40.6% | 给指标+对比 |
| 具有重要的理论意义和实践价值 | （删掉或换成具体贡献） | 零信息，删 |
| 本文首先…其次…最后… | 按"问题→方法→结果→结论"平铺 | 反套娃 |
| 结果表明模型是有效的 | 回测误差 6.2%，±10% 摄动下结论稳定 | 给证据 |
| 与现有方法相比有优势 | 误差从 40.6% 降到 6.2%，且可解释性更好 | 给对比数字 |
| 各因素相互影响、错综复杂 | 屏幕亮度与处理器负载存在显著交互（交互项 p<0.05） | 给统计依据 |
| 综上所述，本文方案切实可行 | （删掉或给出可执行落点） | 套话收尾 |
| 大约 / 可能 / 基本 | 直接给数字或范围 | 模糊词 |

## 三、精打磨动作（改一句顶三句）

1. **删连接词**：把"然而、此外、值得注意的是、与此同时"删一半，保留真正表转折的。
2. **主谓宾优先**：被动句改主动，长句拆短。`数据被模型用来估计参数` → `模型用数据估计参数`。
3. **动词具体化**：`处理` → `清洗/编码/归一化`；`分析` → `回归/聚类/敏感性`；`得到` → `拟合出/求解出/估计出`。
4. **数字带单位与置信**：`约 6%` → `6.2%（±0.4）`；`明显提高` → `从 40.6% 降到 6.2%`。
5. **每段一个中心句**：段首一句结论，后面全部支撑它；删与中心句无关的句子。
6. **公式与文字呼应**：公式后必须跟一句"它算什么、参数含义、怎么解"，别只摆公式。
7. **图表三件套**：引出句→图表→解读句，解读句给量化结论（见 `figures-and-abstract.md`）。

## 四、政论腔 / 模板腔自查（评委一眼识破的"八股"）

数模论文里常见的"政论腔/八股"是扣分重灾区，**见到就删**：
- ❌ 空表态："我们坚信该方案具有广阔的应用前景"——删。
- ❌ 堆砌形容词："先进、科学、合理、严谨、有效"连用——留一个具体的。
- ❌ 无依据的拔高："本研究填补了XX空白"——除非真有依据，否则删。
- ❌ 伪创新："提出了一种创新性方法"却不说是啥——改成"我们在X处做了Y改进"。
- ❌ 过度承诺："本模型适用于一切场景"——改成"在<条件>下适用"。

**判断标准**：一句话删掉后，论文是否损失信息？若否，删。

## 五、中文稿逐节精检清单

- [ ] 摘要：无套娃连接词、每句带数字、无"重要意义/切实可行"
- [ ] 问题重述：转述、不抄题、压缩到要点
- [ ] 假设：每条可辩护、带量级依据或文献，非空话
- [ ] 建模段：模型起名 + "为什么这么建" + 公式有解释
- [ ] 检验：实证化、带数字、有对比
- [ ] 优缺点：优点动作化、缺点机制化，不空喊
- [ ] 全文：动词具体、主谓宾清晰、连接词删一半、无政论腔
- [ ] 落点：给谁、做什么、预期效果

> 写完把稿子朗读一遍——**读不顺的地方就是要改的地方**。这是最便宜也最有效的精打磨手段。
