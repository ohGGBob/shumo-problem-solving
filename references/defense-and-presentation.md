# 答辩与展示指南（国赛晋级答辩 / 美赛可选的展示）

> 定位：数模**不是交完论文就结束**。国赛获省一/国一往往要现场答辩，团队还要把成果讲清楚。本文件讲答辩策略、PPT 结构、问答应对与临场讲解，帮你把「论文里的内容」转化成「台上的说服力」。答辩考验的是**你对自己论文的理解深度**，而不是背稿。

## 一、答辩的本质：证明"这是你做的、你懂它"

评委 10 分钟里要确认三件事：
1. **模型你真的理解**（为什么这么建模、假设的依据、模型怎么解出来的）。
2. **结果可复现**（关键数字怎么来的、代码在不在、跑不跑得出）。
3. **你诚实**（局限是什么、哪些地方可能不准，别被问倒了才承认）。

**心态**：答辩不是演讲比赛，是"把你论文里最重要的事讲清楚 + 扛住提问"。讲得清楚比讲得华丽重要。

## 二、答辩陈述的时间结构（8–12 分钟通用）

| 阶段 | 时间 | 讲什么 | 要避免 |
|---|---|---|---|
| 开场 | 0:00–0:30 | 题目一句话 + 你们做了什么（模型名） | 念题目原文 |
| 问题与思路 | 0:30–1:30 | 每问类型 + 总思路（一页图最好） | 堆细节 |
| 模型主线 | 1:30–6:00 | 每问：模型名 + 为什么选它 + 关键假设 + 怎么求解 | 只念公式 |
| 关键结果 | 6:00–8:00 | 每问一个**数字**结果 + 一张图 | 无数字、图看不清 |
| 检验与亮点 | 8:00–9:30 | 灵敏度 / 误差 / 创新点（有证据） | 空喊创新 |
| 局限与展望 | 9:30–10:00 | 诚实写 1–2 个局限 + 改进方向 | 只说优点 |
| 收尾 | 10:00–10:30 | 一句话总结 + 谢谢 | 拖沓 |

> 建议**每问固定讲 1.5 分钟**，别在一问上恋战。留 2 分钟缓冲给提问。

## 三、答辩 PPT 结构（8–12 页为佳）

1. **封面**：题目 + 队伍名 + 模型总名。
2. **问题重述与分析**：一页图（建模总流程图），每问一句"要交付什么"。
3. **假设**：只列**最关键的 3–4 条**（不是全部），每条带一句理由。
4. **模型一**：公式（关键一条）+ 设计意图 + 求解方法。
5. **模型二/三**：同上，每模型一页。
6. **结果**：每问一张结果图 + 一个关键数字。
7. **灵敏度/检验**：一张灵敏度图 + 结论"对哪些参数稳健"。
8. **创新与特色**：2–3 个亮点，每个一句"解决了什么 + 证据"。
9. **局限与展望**：诚实 1–2 条。
10. **致谢/备份页**：备份页放所有公式推导、额外表格，供提问时调出。

**PPT 制作铁律**：字少（每页 ≤5 行要点）、图多（≥300dpi）、数字大、公式只放关键一条。**别把论文段落粘进 PPT。**

## 四、问答应对（最可能被问的 10 类 + 应对）

| 提问 | 应对 |
|---|---|
| "为什么选这个模型？" | 说**本质匹配**（这问是评价/优化/机理…）+ 与基准对比的理由，别说"网上都这么用" |
| "你这个假设合理吗？" | 背出**量级依据**（"忽略 X 因其量级 <1%"），承认它的失效边界 |
| "这个参数怎么定的？" | 给**来源**（数据拟合/文献/经验），说明做过灵敏度 |
| "和 XX 方法比优势在哪？" | 给**对比数字**（误差、耗时、稳健性），别空喊 |
| "结果可信吗？" | 给**检验**：交叉验证/回测/与真实值误差 |
| "这个数是哪来的？" | **当场可复现**：报出代码里那一步、或现场重跑 |
| "模型有什么局限？" | 主动讲 1–2 条具体局限 + 改进方向（比被戳穿强） |
| "数据怎么处理的？" | 讲清洗/缺失/异常流程 + 为什么这么处理 |
| "创新点是什么？" | 讲"解决了什么 + 怎么检验"，**不是**"用了很高级的模型" |
| "能推广到其他场景吗？" | 讲方法论抽象 + 换数据/参数即可复现 |

**应答三原则**：
- **会答**：先给结论，再给理由（结论先行）。
- **不会答**：诚实说"这一点我们没深究，但我们的处理是…"，别硬编。
- **被挑错**：先承认（"您指出的对"），再解释为什么当时这么取舍，不狡辩。

## 五、临场讲解要点

1. **讲人话**：每讲到一个模型/概念，先给一句"通俗说法"再给术语。评委未必是数模方向。
2. **指图讲**：讲到哪个模型就指向对应的图/公式，别对着空气。
3. **控制节奏**：语速中等，关键数字放慢 + 重读。
4. **眼神交流**：看评委，不盯 PPT。
5. **团队分工**：主讲 1 人，其余 2 人分别负责「翻页/指图」和「补答/记问题」；被问到不熟的问题，可由擅长的队友补。
6. **预演**：至少**全流程彩排 2 遍**（计时 + 问答模拟），找队友扮演评委刁难你。

## 六、答辩前 1 小时清单

- [ ] PPT 在本机 + U 盘 + 云端各一份
- [ ] 关键数字能脱口而出（不翻 PPT 也能报）
- [ ] 复现脚本能在现场 3 分钟内跑出关键图/数
- [ ] 每问的"为什么选这个模型"想好了
- [ ] 3 个局限 + 改进方向背熟
- [ ] 备份页已放好所有公式/表格，随时可调
- [ ] 团队分工明确、彩排过 2 遍

## 七、答辩后：立即沉淀

答辩被问到的、答得不好的问题，**第一时间记进赛后复盘**（见 `post-contest-review.md`）——下次参赛直接避开。这是最快的成长闭环。
