## 2021 A 题：FAST 主动反射面的形状调节

### 交付目标
一句话：**建立"由基准球面调节为旋转抛物面（工作抛物面）"的几何模型，给出理想抛物面方程、各主索节点/促动器的调节量，并用光线追迹量化调节后的馈源接收效果。**

- **问 1**：交「理想抛物面方程」（顶点、焦点、焦参数 $p$），工况为天体在正上方（$\alpha=0^\circ$，$\beta=90^\circ$）。
- **问 2**：交「斜照工况（$\alpha=36.795^\circ$，$\beta=78.169^\circ$，角值待核实）的理想抛物面方程」+ 300 m 口径内**主索节点编号、位置坐标、各促动器伸缩量**列表。
- **问 3**：交「接收比」数值 + 与基准球面的对比评价（调节效果量化）。

> 关键常数（高置信，具体坐标约定以附件为准）：基准球面半径 $R=300\ \text{m}$、口径 $D=500\ \text{m}$、照明/工作口径 $300\ \text{m}$、促动器行程 $\delta\in[-0.6,\ +0.6]\ \text{m}$；主索节点约 **2226** 个、促动器同数量级、反射面板为三角形（FAST 实际 4450 块，题目附件块数「待核实」）。附件含：主索节点坐标、反射面板（三角形三顶点=节点编号）、促动器坐标。

### 问题拆解与建模思路

**问 1：本质是解析几何 —— 确定天顶方向的旋转抛物面。**
- 基准球面半径 $R=300$，球心 $C$。照明区域为顶点处的 300 m 口径球冠。
- 工作抛物面需满足两点：(1) 顶点贴在球冠顶点（天顶）；(2) **焦点落在馈源舱**（馈源舱位于基准球面对应焦平面，即球心上方 $R/2$ 处）。
- 以球心为原点、竖直向上为 $z$ 轴，抛物面（开口向下）：
$$x^2+y^2=2p\,(R-z),\qquad p=\frac{R}{2}=150\ \text{m}$$
  顶点 $(0,0,R)$，焦点 $(0,0,R-p)=(0,0,150)$。$p=R/2$ 是"抛物面与球面在顶点二阶贴合"的经典结果（球面曲率半径 $R$，抛物面顶点曲率半径 $=p$）。
> 顶点/焦点的具体坐标值随题目坐标原点可能整体平移（若原点不在球心），「待核实」以附件 Z 坐标反推。

**问 2：本质是坐标旋转变换 + 带界最小二乘（约束优化）。**
1. **旋转**：把天顶抛物面刚体旋转，使其对称轴指向天体方向单位向量 $\mathbf{u}(\alpha,\beta)$。用罗德里格斯（Rodrigues）旋转或 `scipy` 的欧拉角旋转（先方位角 $\alpha$ 绕 $z$，再按仰角 $\beta$ 倾斜轴，注意符号/顺序——高频错误点）。旋转后焦点仍位于馈源舱（反射面调焦的目标）。
2. **调节变量**：每个主索节点只能沿**球面法向（径向）**移动，促动器伸缩量 $\delta_i\in[-0.6,0.6]$ m，节点新坐标 $P_i' = P_i + \delta_i\,\mathbf{n}_i$（$\mathbf{n}_i$ 为单位外法向）。
3. **目标函数**（三选一，越往后越严谨）：
   - 节点法向距离残差：$f_i(\delta) = \text{dist}(P_i',\,\text{理想抛物面})$；
   - 面板质心残差：把每块三角形面板质心沿面板法向到抛物面的带符号距离作为残差（**推荐**，因反光的是面板，不是节点）；
   - 光程差/波前残差：节点到馈源路径的光程一致性（国一加分项）。
4. **求解**：$ \min_\delta \sum_i w_i f_i^2 $，s.t. $-0.6\le\delta_i\le0.6$。这是带界非线性最小二乘，直接用 `scipy.optimize.least_squares`。输出 $\delta_i$ 与节点新坐标。

**问 3：本质是光线追迹（ray tracing）+ 面积/能量积分。**
- 入射为平行光（方向 $-\mathbf{u}$）。对每块三角形面板：求面法向 $\mathbf{n}$（顶点叉积）→ 按镜面反射定律 $\mathbf{r}=\mathbf{d}-2(\mathbf{d}\cdot\mathbf{n})\mathbf{n}$ 求反射方向 → 判断反射光线是否进入馈源舱口径（或其张开的立体角）。
- **接收比** = 落入馈源舱的有效接收光通量 / 入射总光通量（可按面板面积加权，或以"有效接收面板面积占比"近似）。
- 与**基准球面（未调节）**对比：平行光经球面反射不汇聚到一点而是形成焦线/焦面，点状馈源接收极少；调节成抛物面后基本汇聚到焦点=馈源舱，接收比显著提升——这是本题核心物理结论。

### 求解算法与 Python 要点
- **读数据**：`pandas.read_excel()`（节点坐标/面板顶点/促动器坐标）。
- **问 1**：直接套解析式，无需数值优化。
- **问 2 旋转**：`scipy.spatial.transform.Rotation.from_euler('z', alpha, degrees=True)` 结合仰角倾斜，或 `Rotation.from_rotvec`；再用矩阵点乘 `@` 批量变换节点坐标。
- **问 2 优化**：`scipy.optimize.least_squares(func, x0, bounds=(-0.6, 0.6))`；残差 `func` 内部用 `numpy` 向量化算所有节点/面板到抛物面的距离。抛物面距离不闭合时可对每个节点做**一维数值求根**（沿法向求交点）。
- **问 3 光线追迹**：纯 `numpy` 向量化（一次算 4000+ 面板），$\mathbf{n} = \mathrm{cross}(v2-v1,\ v3-v1)$ 归一化；直线与圆盘（馈源口径）相交判据。量大可用 `numba` 加速。
- **代码模板关系**：这题"模板化"弱于 B/C，核心是自定义几何函数；建议把"读文件→面板法向→抛物面残差→优化→导出 CSV"封装成可复用模块。

### 模型检验与灵敏度
- **多工况自洽**：天顶（问 1）与斜照（问 2）用同一套代码，检验旋转退化到天顶时是否还原问 1。
- **行程边界统计**：统计 $\delta_i$ 触及 $\pm0.6$ m 的节点比例；大量贴边说明目标抛物面顶点/焦距需二次优化（顶点与焦距可微调，别硬贴 $p=150$）。
- **目标函数敏感性**：比较"节点贴合 / 面板质心贴合 / 光程差"三种残差下的调节方案与 RMS 偏差。
- **基准对比**：问 3 必做调节前 vs 调节后接收比对比，量化提升倍数。
- **口径/采样收敛**：光线追迹的面板离散假设、馈源口径张角取值做收敛性说明。

### 国一亮点建议
1. **引入光程差/波前 RMS**（镜面口径效率的物理量），论证"几何贴合≠光学调焦"，让结论上升到射电望远镜口径效率层面。
2. **接收比精确到"面板面积加权 + 馈源舱张角积分"**，并与理想上限对比；不要用粗糙的"面板个数占比"。
3. **对顶点/焦距做二级优化**：不固定 $p=150$，把焦距作为附加决策变量，给出"最佳拟合抛物面"，并讨论 0.6 m 行程是否构成瓶颈。

### 高频失分点
1. **忽略面板是平面三角形、节点只能径向移动**的约束，直接把节点硬贴抛物面 → 得到非法或调不动的解。
2. **旋转角度符号/顺序写错**（$\alpha$、$\beta$ 定义与绕轴顺序），导致抛物面指向错误天体，全题崩盘。
3. **接收比定义含糊**（能量/面积/个数占比混用），或不与基准球面对比，结论无说服力。

## 2021 B 题：乙醇偶合制备 C4 烯烃

### 交付目标
一句话：**以实验数据回归/机器学习建模"催化剂组合 + 温度 → 乙醇转化率、C4 烯烃选择性"，完成 350 ℃ 预测、因素分析、收率寻优，并设计补充实验。**

- **问 1**：每种催化剂组合下「转化率 $\eta(T)$、选择性 $s(T)$ 随温度的关系」+ 对附件 2（350 ℃ 给定组合）的**预测值（含误差区间）**。
- **问 2**：不同催化剂组合与温度对 $\eta$、$s$ 的**影响方向与交互作用**（重要性排序）。
- **问 3**：使 **C4 烯烃收率最大**的最优「组合 + 温度」；以及**温度 < 350 ℃** 约束下的最优。
- **问 4**：允许增加 5 次实验时的**序贯实验设计**（具体组合 + 温度 + 理由）。

> 关键量：**C4 烯烃收率 = 乙醇转化率 × C4 烯烃选择性**（$Y=\eta\cdot s$），这是问 3 的**唯一目标**，切勿用单一指标。变量：Co/SiO2 的 **Co 负载量**、「Co/SiO2 : HAP 装料比」、**乙醇浓度**、（连续）**温度**。附件 1 = 性能数据表（组合 + 温度 + $\eta$ + $s$）；附件 2 = 350 ℃ 待预测数据（仅自变量）。具体实验温度档、催化剂组数、重复次数「待核实」（常见为 250/275/300/325/350 ℃ 多档、约 21 种组合）。

### 问题拆解与建模思路
**问 1：本质是回归 / 插值 + 预测（有误差估计）。**
- 每组共用一个低阶模型：$\eta=f_\eta(T)$、$s=f_s(T)$。候选：线性、二次、三次多项式，或经验 Arrhenius 型（$\eta$ 单调增；$s$ 常先增后减、有峰值，需允许非单调）。
- 数据点相对少（每组约 5 个温度档，若含 5 次重复则用重复方差评估噪声）：「待核实」。用**交叉验证**选阶次，避免过拟合。
- 350 ℃ 预测：350 ℃ 是给定温度，用模型在该点求预测值 + 置信区间。若附件 2 是"已知组合、给定 350 ℃"，本质是**插值/可迁移预测**，而非外推（好做很多）。
- 更稳做法：建**全局模型** $\eta = g(T, \text{负载量}, \text{装料比}, \text{浓度})$，用全部数据拟合，再对附件 2 预测——信息利用更充分、预测更稳。

**问 2：本质是方差分析 / 变量重要性（可解释）。**
- 方法：标准化回归系数、`statsmodels` OLS + `anova_lm`（主效应 + 交互效应）、随机森林 `feature_importances_`、SHAP 值。
- 输出：各因素（Co 负载量、装料比、乙醇浓度、温度）对 $\eta$ 与 $s$ 的**影响方向与强度排序**，以及最重要的交互项（如"温度 × Co 负载量"）。

**问 3：本质是约束优化。**
$$\max\ Y=\eta\cdot s,\quad \text{决策变量}=(\text{组合}_{\text{离散}},\ T_{\text{连续}})$$
- 先拟合响应面 $Y(\text{组合},T)$（可用班门/径向基/GLM，或直接用问 1 模型 $Y=\eta(T)\cdot s(T)$），再离散枚举组合 + 对 $T$ 用 `scipy.optimize.minimize` 或网格搜索求最优。
- **加约束**：$T<350$ ℃ 时重新寻优（注意选择性峰值可能恰在 350 ℃ 附近，降温后最优组合可能变化）。
- 必须给出"在同一实验条件下收率最大"的组合 + 温度具体值，并说明 $\eta$、$s$ 的权衡。

**问 4：本质是实验设计（DoE / 序贯）。**
- 思路 A：**验证 + 加密**——用若干点在问 3 最优组合上重复/邻域（温度 ± 若干 ℃、组合 ± 一档）。
- 思路 B：**信息增益最大化**——在响应面最不确定/期望改进（EI）最大的区域加点（贝叶斯优化思想），5 点围绕候选最优区做二次多项式加密拟合，进一步收敛最优。

### 求解算法与 Python 要点
- **回归**：`sklearn.linear_model.LinearRegression` + `sklearn.preprocessing.PolynomialFeatures`；`statsmodels.api.OLS` 或 `statsmodels.formula.api.ols` 获得置信区间与 ANOVA（`anova_lm`）。
- **非参数/树**：`sklearn.ensemble.RandomForestRegressor`（`feature_importances_`）；更进阶用 `shap`。
- **拟合**：`numpy.polyfit` / `scipy.optimize.curve_fit`（自定义 Arrhenius 型）；误差用 `sklearn.model_selection.KFold` 交叉验证的 RMSE，bootstrap 给区间。
- **寻优**：`scipy.optimize.minimize`（连续温度）+ 枚举离散组合；或 `scipy.optimize.differential_evolution`；网格 `numpy`/`itertools`。
- **可视化**：`matplotlib` 的 `plot_surface`/`contour`。

### 模型检验与灵敏度
- **交叉验证误差**（RMSE/MAE/$R^2$），并给出预测**置信区间**而非单点值。
- **外推/边界风险**：350 ℃ 是上边界档，注意多项式在此处的鲁棒性；模型外推要声明。
- **重复实验方差**（若附件含 350 ℃ 多次重复）→ 用它标定噪声、检验拟合是否过拟合。
- **最优稳健性**：在最优组合邻域网格展示收率变化面，说明最优是"平台"还是"尖峰"。

### 国一亮点建议
1. **全局统一回归模型**（含"组合 × 温度"交互项与重复方差/随机效应），取代每组分头拟合——预测更稳、可给预测区间。
2. **SHAP / ANOVA 定量解释**给出"温度 > 装料比 > Co 负载量 > 浓度"这类可解释排序，并解释化学机理（如 $\eta$ 随 $T$ 单调、$s$ 在 350 ℃ 附近有峰值）。
3. **收率与 $\eta,s$ 的 Pareto 权衡** + 问 4 用"期望改进/贝叶斯"式序贯设计（而非拍脑袋加 5 点），体现工程性。

### 高频失分点
1. **把"收率"错当转化率或选择性**优化，忽略 $Y=\eta\cdot s$ → 目标函数根本错误。
2. 附件 2 预测**只给单点数值、无区间与交叉验证误差**，或每组机械套同一模型、不做阶次选择。
3. 问 4 补点**无信息增益依据**；问 3 忘记加"温度 < 350 ℃"约束分支。

## 2021 C 题：生产企业原材料的订购与运输

### 交付目标
一句话：**建立供应商多指标评价体系，并用线性/整数规划制定未来 24 周的订购与转运方案，权衡供货能力、转运损耗与产能/库存约束，并支持扩产情景。**

- **问 1**：402 家供应商**评价模型 + "最重要的 50 家"名单及理由**。
- **问 2**：未来 24 周**订购方案**（每周、每类、每家供应商订购量），满足生产需求与供货上限。
- **问 3**：未来 24 周**转运方案**（每批原料由 8 家转运商中的哪家承运），最小化转运损耗且满足运力。
- **问 4**：**产能提高 1%（及可能新增一家供应商）** 下的订购 + 转运改进方案。

> 关键结构：**402 家供应商**、**8 家转运商（各有转运损耗率 $r_k$ 与运力上限）**、近 5 年（240 周）供货数据、原材料分 **A/B/C 三类**、生产每周有固定需求。物理链：**到货量 = 订购量 × (1 − 损耗率)**，且实际供货量受每家供应商"周供货能力上限"约束（从历史数据估计）。具体每周需求方数、各供应商类别、损耗率区间「待核实」（以附件为准）。

### 问题拆解与建模思路
**问 1：本质是多指标综合评价 + 排序。**
- **候选指标**（每供应商，用 240 周序列计算）：供货规模（周均值）、波动（标准差/变异系数 CV）、供货稳定率（非零供货周数占比）、连续性（缺货周/中断）、供货能力（历史最大值或 95% 分位数）、趋势（线性拟合斜率）。
- **处理坑**：供货量为 0 或缺失的周要显式处理（缺货 vs 0 供货），否则均值方差失真。
- **综合评价**：熵权法（客观权重）→ TOPSIS 排序，或 AHP + 熵权组合，或 PCA 降维 + 聚类。最终取前 50，并解释"为什么是这 50 家"（规模大、稳定、能力强）。

**问 2：本质是线性/整数规划（带库存与提前期的动态决策）。**
- 决策变量 $x_{s,t}$：第 $t$ 周向供应商 $s$ 的订购量（$s$ 属于对应原材料类）。
- 约束：
  - 供货能力：$0\le x_{s,t}\le \hat Q_s$（$\hat Q_s$ 为历史估计的周供货上限）；
  - 需求满足：$\sum_s x_{s,t}(1-r)\ge D_c(t)$（$c\in\{A,B,C\}$ 各类每周需求，$r$ 为转运损耗率）；
  - 库存/提前期：下单 → 到货有时滞，写库存平衡 $I_t = I_{t-1} + \text{到货} - \text{消耗}$，$I_t\ge0$。
- 目标：总订购量/成本最小、供应商数量精简、或损耗最小等（题面指定「待核实」）。用 **LP/MILP** 求解（可整期联合，也可 24 周滚动）。

**问 3：本质是运输指派（assignment / 最小费用流）。**
- 决策变量 $y_{k,t}$：第 $t$ 周由转运商 $k$ 承担的量。
- 目标 $\min \sum_{k,t} r_k\, y_{k,t}$（总损耗最小）；约束：每家每周运力上限、每周总运量分配完整（$\sum_k y_{k,t}=$ 该周到货/发运总量）。
- 可直接 LP；若限制"每批只由一家转运商承运"则加 0-1 变量变 MILP。

**问 4：本质是情景扩展。**
- 产能 +1% → $D_c(t)$ 提升 1%，重解问 2 + 问 3；新增供应商（已知其每周供货上限）加入决策再优化；若涉及缺陷率则放大安全库存。
- **推荐**：把问 2 + 问 3 合并为**联合 MILP**（同时决策订购量与转运商），与先问 2 后问 3 的"分层"解法对比损耗/成本差距。

### 求解算法与 Python 要点
- **问 1 数据处理**：`pandas` 聚合（`mean/std`、`quantile`、`count`、自写 CV/稳定率）；`sklearn.decomposition.PCA`、`sklearn.cluster.KMeans`；TOPSIS/熵权手写（矩阵化 numpy，几十行）。
- **问 2/3/4 优化**：`pulp`（CBC，免费）或 `ortools.linear_solver` / `pywraplp`；规模大用 Gurobi（有 Gurobi 开源参考实现）。连续 LP 也可 `scipy.optimize.linprog` / `milp`（含 0-1 时）。
- **拆分技巧**：三类原材料 A/B/C 需求独立 → 可分类建模型或联合建一个大模型；24 周时间维用 `pulp` 的 `LpVariable.dicts` 批量建变量。
- **代码模板关系**：C 题是"评价 + 优化"经典组合，模板复用度最高（TOPSIS/熵权 + LP 两套即可覆盖）。

### 模型检验与灵敏度
- **问 1 稳健性**：熵权 vs 层次分析 vs 等权三种权重下前 50 名单的**交叠率**；聚类稳定性。
- **供货上限假设**：用"历史最大 / 95 分位 / 均值+2σ"三种 $\hat Q_s$ 估计，检验方案可行性差异。
- **损耗率摄动**：$r_k$ 上浮、运力上限扣紧后的总损耗与可交付性变化。
- **压力测试**：需求 +1%（问 4 基础）、某头部供应商断供情景下的方案鲁棒性。

### 国一亮点建议
1. **供货能力用分位数/稳健估计**（而非简单取历史最大），并显式建模"实际供货量 = min(订购量, 供货能力)"。
2. **订购 × 转运联合整数规划**（损耗、运力、库存、提前期一体），并与分层解法对比，证明联合更优。
3. **对供应商做聚类画像**（A/B/C 类、刚需 vs 弹性、规模 vs 稳定），输出"断供/波动"压力测试与安全库存建议，提升管理决策价值。

### 高频失分点
1. **缺失/零供货周处理不当**，把缺货当 0 直接纳入均值方差 → 指标失真、前 50 名单不可信。
2. **忽略"到货量 = 订购量 × (1 − 损耗率)"物理链**，直接让订购量=需求，导致实际到货不足、生产中断。
3. **订购与转运割裂求解**、不考虑运力上限与提前期；或问 1 堆几十个指标但权重无依据、无解释。

| 题号 | 类型 | 数据/计算量 | 上手难度 | 竞争烈度 | 适合队伍 |

| **C** | 综合评价 + 线性/整数规划 | 大（402×240 + 8 转运商） | 中 | 中 | 运筹/供应链/优化建模强、会 PuLP/Gurobi |
