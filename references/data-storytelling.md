# C 题数据叙事挖掘（数据深度 · 数据题国一的真正分水岭）

> 定位：C 题（数据题）国一 vs 国二的差距，常在**数据挖掘深度**——不是模型多高级，而是
> 从数据里挖出了几个"反直觉且可解释"的发现，并用图和文字把故事讲清楚。
> `scripts/insight_miner.py` 负责"半自动挖候选"，本手册负责"怎么把候选变成论文里的硬发现"。

## 三类高价值发现（挖的时候优先找这三类）

### A. 反直觉发现（最值钱）
常识/直觉预期与数据实际**相反**——"以为 A 区成本高，实际最低；以为大供应商稳，实际波动最大"。
评委看到会停留，这就是印象分。

### B. 隐藏结构（次值钱）
强相关对（`r≥0.7`）、聚类形态、异常点、时间拐点、分组差异——数据里不是一眼看得到的规律。

### C. 业务可解释规律（必有一两条）
分组差异（区域/类别间均值差）能落到**业务原因**："华东价高 2.9 元，可能因运输半径小/竞争密度低"。

## 每个发现的标准四要素（写进论文前必须凑齐）

1. **发现陈述**：一句话，可量化（"华东区采购均价高出华北 42%"）；
2. **证据**：哪个文件/哪张表/哪一列/什么统计（铁律四：数字必有出处）——来自 `insight_miner.py` 或 `data_profiler.py` 输出；
3. **可视化**：选什么图（见下表），图要能独立传达这个发现；
4. **论文落点**：放在哪一节、怎么引出（"如图 3 所示…值得注意的是…"）。

## 挖掘流程（照走）

```bash
# 1. 先摸结构（铁律四：数据清单）
python scripts/data_profiler.py data/ --inventory --out report/data_inventory.md
# 2. 挖候选发现（自动出清单，带来源）
python scripts/insight_miner.py data/ --target <目标列> --top 15
# 3. 人/AI 一起筛：哪 3–5 条"反直觉 且 可解释 且 有业务含义"？
#    留下的一人一条，按四要素补证据、画图、定位论文落点
# 4. 深化被选中的发现：换角度再挖一层（分组→时间→相关→异常逐层看）
```

## 图的选择（发现 → 图，对应论文三件套）

| 发现类型 | 推荐图 | 要点 |
|---|---|---|
| 强相关对 | 散点+拟合线 / 热力图 | 标 r 值，点出"协同/共变"关系 |
| 分组差异 | 箱线图 / 柱状+误差棒 | 组间差异肉眼可见，标注均值差 |
| 时间趋势 | 折线 + 拐点标注 | 把"时间拐点"画出来，写一句"拐点后增速…" |
| 异常点 | 标注散点 / 箱线离群点 | 单独讨论异常的业务含义 |
| 分布形态 | 直方图+密度曲线 | 右偏 → 写"故取对数/用中位数" |

> 图规范照 `figure-polish.md`（≥300dpi、标题/单位/图例、三件套），配色照 `plot_style.py`。

## 常见翻车（每条都是真实教训）

| 场景 | 后果 | 正确做法 |
|---|---|---|
| 把 data_profiler 的结构概览当"发现" | 论文里全是"数据有 402 行 8 列" | 发现必须是有业务含义的规律，不是元信息 |
| 挖了 20 条全写进论文 | 堆砌，评委看不到重点 | 只留 3–5 条，每问 1–2 条写深 |
| 发现没有证据出处 | 铁律四：数字必有出处 | 每条四要素齐全才准写 |
| 发现无法解释"为什么" | "有差异"不等于"有洞察" | 想不出业务原因的，降级为辅助证据或删 |
| 只挖不画图 | 发现埋没在文字里 | 每个写入论文的发现配一张图 |
