# 降 AI 味 + 降重写作规范（国赛 / 美赛论文）

> 现在数模论文普遍会过 AIGC 检测和查重。AI 味重或重复率高，轻则印象分大跌，重则判违规。本文件教你在**动笔时就规避**，并在交稿前自检改写。
> 边界说明：本技能没有接知网/维普 AIGC 检测引擎，无法替代官方检测。这里是「让产出更像人写、更原创」的规范 + 自查清单；**交稿前务必用学校/组委会指定的检测工具最终复核**。

> 配套：`deai-rewrite-bank.md`（改写对照库，`dedup_scan.py` 命中哪句就照它逐条改）；`dedup_scan.py`（自动扫描，支持 `dedup_scan.py 论文.md 题干.txt` 查疑似抄题）。

## 一、AI 味从哪来（先知道要避开什么）

AI 生成文本的 8 个典型特征，对着稿子找：

1. 过度工整的排比/对仗，几句字数都差不多
2. 滥用连接词：首先 / 其次 / 最后 / 综上所述 / 值得注意的是 / 与此同时 / 更进一步
3. 空洞的总分总：每段都是"主题句 + 展开 + 总结"一板一眼
4. 华丽但零信息："具有重要的理论意义和实践价值"
5. 段落长度惊人均匀（每段都 3–4 行长）
6. 缺「做事痕迹」：没有具体数字、参数、踩过的坑、做过的选择
7. 固定句式："本文通过……建立了……模型，采用了……方法"
8. 长句 + 定语堆叠（美赛英文尤其）

**AI 味最重的区域**：摘要、问题重述、模型评价与推广、结论——这些"套话区"最容易被检测器点出来，也是最先要改的地方。

## 二、降 AI 率的实操（5 个动作）

1. **用具体替换抽象**：删"采用了科学合理的方法"，写"用最小二乘拟合 lnQ 与 lnP，弹性 b=−0.83"。
2. **打破句式节奏**：长短句交错；删掉一半模板连接词；三条排比删成一条具体的。
3. **删废话句**：删"具有重要的理论意义和实践价值"这类零信息句——一句话说不清贡献就直接删。
4. **加「做事痕迹」**：写真实操作，例如"402 家供应商取 95% 分位估供货上限""Differential Evolution 跑 10 次取均值、固定 seed=0""因交互项不显著，退回主效应模型"。这些片段是机器写不出、检测器判不准的人类痕迹。
5. **摘要拒绝套娃**：别用"本文首先……其次……最后……"，改按"问题→方法→结果→结论"平铺，每句带数字。

**改前 / 改后对照**：

> ❌ 改前（AI 味重）：本文首先对数据进行了充分的预处理，其次建立了多元回归模型，最后通过综合分析得出相关结论。该研究具有重要的理论意义和实践价值。

> ✅ 改后（人味）：附件 402 家供应商里 37 家近半年有断供，剔除后按 95% 分位估计供货上限。销量对价格弹性 b=−0.83（R²=0.91），据此把 7 月 1 日补货量定在 1.2 吨、售价 12.8 元。

## 三、降重实操（重复从哪来 + 怎么避）

1. **题目原文**：问题重述用自己的话**转述**，只保留关键数据与约束，别整段抄题面（题目文字最容易被查到）。
2. **定义 / 公式 / 标准算法**：GM(1,1)、熵权法、AHP 步骤属公共知识（检测系统一般会排除公式区），但**步骤表述用自己的话**，不要整段复制某篇范文的原文。
3. **模板句换措辞**：网上范文的"本文通过建立……采用……得出……"这类通用句，改语序、拆句、换动词。
4. **范文段落不照抄**：学思路、不抄文字；别人的结论用自己的数据重新表述。
5. 交稿前用指定工具跑一遍，重点看**摘要 / 问题重述 / 模型评价 / 结论**四块，超标就按本节重写。

## 四、给 skill 的硬规范（写时就照做，别事后补）

- **摘要**：禁套娃连接词、禁"重要意义"句、每句带数字。
- **问题重述**：转述、压缩到要点、不照抄题面原句。
- **模型建立**：写"具体算什么、用什么参数、得到什么数"，别只摆公式。
- **模型评价**：别写"本文模型具有以下优点"，写"在 X 条件下误差 <5%、比基准少 Y%"。
- **全文**：长短句交错、删模板连接词、删废话句、加做事细节。

## 五、交稿前自检清单（两项，逐条勾）

**降 AI 味**：
- [ ] 摘要无"首先/其次/最后"套娃、无"重要意义"句
- [ ] 已删所有零信息废话句
- [ ] 全文有 ≥3 处具体数字/参数/踩坑的"做事痕迹"
- [ ] 段落长短有起伏，无空泛排比

**降重**：
- [ ] 题目原文已转述、不照抄
- [ ] 模板句已改措辞
- [ ] 范文段落未照抄
- [ ] 已用检测工具跑过；摘要/重述/评价/结论四块达标

## 六、诚实写负结果（短板也是"做人味"的加分项）

AI 味论文习惯把结果吹满；敢写"不好看"结论的稿子，既降重又更可信。三条：

1. **负指标照写 + 给原因**：CV-R² 为负、AUC 只有 0.58、某亚类样本太少判别差——写出来，并解释"总体趋势显著但个体差异大（ICC≈0.71）""AUC 低只能说明群体分层能力有限，不能当个体诊断"。
2. **不可达 / 失败如实标**：某组在检测窗口内达不到目标概率，就写"此组 25 周内不可达、建议复检/质控"，不要硬给一个时点。
3. **复杂模型输给简单模型也写**：多因素模型边界窄、时点非单调、留出验证不稳，就写"作为个体风险修正工具，不作为普遍群体标准"。

> 正例句式："样条模型 CV-RMSE 0.034，但 CV-R² 仍为负，说明它刻画的是总体规律，不能精确预测个体浓度，因此问题二、三改用达标概率与风险决策，而非直接预测单点浓度。"
