# 纵向 / 重复测量 + 阈值达标时间题（一类易错高分题型）

> 定位：响应变量是一条"随个体、随时间重复测量"的曲线，题目真正要的不是预测那条曲线本身，而是"**首次达到阈值的时间 / 何时检测 / 该怎么分组定策略 / 要不要复检**"这类**决策**。2025 国赛 C（NIPT 时点选择与胎儿异常判定）是这类题的典型正例。

## 一、识别特征（三个都中，基本就是这类题）

1. 同一**个体**有**多条时间点记录**（纵向 / 重复测量），记录之间不独立；
2. 存在一个**阈值达标事件**：浓度≥q%、指标进入治疗窗、越过安全线；
3. 问的是**分组 + 最佳时点 / 最早时间 / 复检策略**，使某种"潜在风险"最小。

## 二、标准三段式（照此拆，别一头扎进单纯回归或单纯生存分析）

1. **连续响应层**：对响应做合适变换（比例→logit、正数→log、计数→log1p），建**个体随机截距混合效应模型**（LMM / GAMM），把个体差异 σ_b² 与记录误差 σ_e² 分开估计。
2. **阈值概率层**：达标概率
   \[
   p(t,\mathbf x)=1-\Phi\!\Big(\frac{\mathrm{logit}(q)-\mu(t,\mathbf x)}{\sigma_{\text{total}}}\Big),
   \qquad \sigma_{\text{total}}=\sqrt{\sigma_b^2+\sigma_e^2}.
   \]
   注意用 **σ_total 而不是 σ_e**——要的是"该孕妇在 t 当天单次检测达标"的概率，必须含个体差异。
3. **决策层**：把题面"风险分级"翻译成目标函数（未达标/需复检损失 + 延迟发现损失），在"分组边界 × 组内时点"之间**联合优化**（连续边界用动态规划/枚举排序后切点），最终落到"每组区间 + 最佳周数 + 达标率 + 风险 + 误差敏感性"。

## 三、四个必踩对的关键坑

1. **个体分组 K 折**：`GroupKFold / StratifiedGroupKFold`（groups=个体 ID），行级切分把同一个人分进训练+测试就是泄漏（2025 C 实测 AUC 虚高约 0.04）。
2. **测量误差单独估**：用"近同期重复"配对差值（|Δweek|≤0.5 或同个体同次采血）的 MAD 估 σ_m，和生物变异分开；别拿普通回归残差冒充测量误差。
3. **达标概率做非降投影**：成熟/积累过程不可逆，观测值可能短期下降，群体层面 p(t) 应单调不减——对预测曲线做累积最大（`np.maximum.accumulate`）。
4. **阈值邻域摄动**：q±σ_m 重算一遍，报告"哪些组时点稳健、哪些组 25 周内不可达"，比只给一个单点时点有说服力。

## 四、这道题的"诚实"怎么写（评委加分项）

- 组内达标概率可能永远到不了目标（如高 BMI 组在窗口内不可达）→ 如实标"**不可达 + 建议复检/质控**"，别硬编时点。
- 复杂 vs 简洁：报告"组数从 3 增到 4，风险只降 0.18%，故选更少组"，体现 Occam。
- 负 R² / 低 AUC 照写 + 解释："总体趋势显著但个体差异大（ICC≈0.71），故模型适合描述群体规律，不能精确预测个体"。

## 五、正例速记（2025 国赛 C）

男胎 Y 浓度 logit → 孕妇随机截距 LMM / 样条混合效应 → p(t,BMI)=1−Φ(·) → 目标函数（未达标损失 C_u=4 + 延迟损失 D(t)）→ 动态规划切 BMI 得三组［[20.70,33.03) 17.7 周 / [33.03,35.22) 19.3 周 / [35.22,46.87] 24.1 周］，σ_m=0.515 个百分点由 81 对近同期差值 MAD 估得。
