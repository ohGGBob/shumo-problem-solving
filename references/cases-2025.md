## ⬛ 2025 A 题：烟幕干扰弹（多弹协同）的投放策略与遮蔽/干扰效能

**已核实要点**：题目确为「烟幕干扰弹的投放（策略）」，核心是多烟幕干扰弹协同投放、以烟幕遮蔽（干扰）无人机的探测；公开题解普遍采用「三维弹道运动学 + 引信延迟 → 起爆点 → 烟幕扩散 → 视线遮挡 → 遮蔽区间/多目标优化」的建模链。某公开题解给出单弹有效遮蔽区间示例约 `8.0–9.4 s`（仅示例，且与后文「最优遮蔽时长」区间属不同口径、不可直接对比；具体参数/附件数值见下「✅ 确证题面参数」，其余仍待核实）。

### 交付目标
- **一句话**：建立「弹道运动学 → 烟幕扩散 → 视线透射判定 → 投放时序优化」闭环，给出使烟幕在规定时段内有效遮蔽无人机探测的最优投放与起爆方案。
- **各问交付**（按公开题解归纳的 4 问结构，确切问数与表述**待核实**）：
  - **问 1（单弹定解）**：给定某弹速度、投放时刻、引信延迟 → 求投放点、起爆点坐标 + 有效遮蔽时间区间（数值）。
  - **问 2（多弹协同）**：给定多弹/连续投放 → 求投放序列与时间间隔，最大化连续遮蔽时长或覆盖面积（方案）。
  - **问 3（含环境/多目标）**：计入风场扩散、多目标(无人机/被保护目标)、资源约束 → 动态投放决策方案（方案+优化）。
  - **问 4（权衡评价）**：弹数、成本、遮蔽效能的多目标权衡与综合评价（建议/报告）。

### 问题拆解与建模思路（逐小问）
- **问 1｜本质＝单弹弹道 + 引信定时的逆问题/正算**：
  - 弹道：质点受重力 + 空气阻力（二次阻力模型 $m\dot{\mathbf v}=-\frac12 \rho C_d A\,|\mathbf v|\mathbf v - m g \mathbf{e}_z$，或题面直接给速度/弹道参数）。投放时刻 $t_d$ + 引信延迟 $\tau$ → 起爆时刻 $t_b=t_d+\tau$，起爆点为弹道在 $t_b$ 处的位置 $P_b$。
  - 烟幕形成：起爆后烟幕以 $P_b$ 为中心膨胀 + 平流扩散，几何可用时变球/椭球/分段烟团描述：$R(t)=R_0+v_s t + f(\text{风、浮力})$（$v_s$ 为膨胀/扩散速率，**参数待核实**）。
  - 遮蔽判定：无人机传感器—被保护目标连线（视线 LOS）与烟幕区域相交，且透过率低于阈值即「被遮蔽」。透过率用 **Beer–Lambert（朗伯–比尔）定律**：$\tau=\exp(-\alpha_{ext}\, c\, L)$，$L$ 为视线在烟幕内的路径长度，$c$ 为浓度，$\alpha_{ext}$ 为消光系数（**参数待核实**）。
  - 遮蔽区间＝$\{t\,|\, \tau(t) \le \tau_{th}\}$ 的闭区间；据此反演引信延迟 $\tau$ 使遮蔽区间覆盖指定时段。
- **问 2｜本质＝时序资源调度/覆盖优化**：把每发弹的遮蔽时间窗（起止时刻）作为「可调资源」，多弹的起爆时刻 $t_{b,i}$ 作为决策变量。目标 max 连续遮蔽时长（或指定时段覆盖率）；约束：弹数上限、单弹遮蔽时长、扩散重叠。模型为 **混合整数规划（MILP）/时序调度**，求解用贪心+局部搜索或元启发式。
- **问 3｜本质＝含烟羽扩散的时空覆盖**：
  - 扩散用 **高斯烟团/烟羽模型（Gaussian puff/plume）**：浓度 $c(\mathbf x,t)\propto \frac{Q}{(2\pi)^{3/2}\sigma_x\sigma_y\sigma_z}\,\exp\!\big(-\frac{(x-\bar x)^2}{2\sigma_x^2}-\cdots\big)$，扩散系数 $\sigma_x,\sigma_y,\sigma_z$ 随时间/稳定度增长；中心随风场平流 $\bar{\mathbf x}=\mathbf x_0+\mathbf u t$。
  - 将浓度场代入透过率沿 LOS 积分，得到时变「遮蔽覆盖率」；多目标优化（覆盖率、持续时长、弹数）。
- **问 4｜本质＝多目标决策与稳健性**：以弹数/成本为对边、以遮蔽效能为收益，画 **Pareto 前沿**；结合灵敏度/风场不确定性给出稳健投放建议（可用鲁棒优化或蒙特卡洛情景法）。

### 求解算法与 Python 要点
- **弹道 ODE**：`scipy.integrate.solve_ivp`（`method='RK45'` 或 `'DOP853'`）；引信延迟用 `brentq` 反解时间（对遮蔽起止时刻求根）。
- **视线/几何相交**：`numpy` 向量化；2D 投影可用 `shapely`（`LineString.intersection`）；3D 直接解析求「线段—球/椭球」交。
- **扩散场**：高斯烟团直接写 `numpy` 表达式；风场平流逐帧更新中心。
- **覆盖统计**：**蒙特卡洛**对视线端点/投放参数采样，估计遮蔽概率与覆盖率。
- **优化**：时序调度 → `scipy.optimize.milp`（MILP）或 `pulp`；连续/组合决策 → `scipy.optimize.differential_evolution`（全局，推荐）、`geatpy`/`DEAP`（遗传算法）、模拟退火。
- **可视化**：`matplotlib` 3D（弹道+烟幕+视线）、`shapely` 覆盖热力图、Pareto 前沿图。
- **代码模板关系**：与「弹道/扩散+遮挡+蒙特卡洛」类模板高度复用；关键自定义部分是「透过率沿 LOS 积分」与「遮蔽时窗提取」。

### 模型检验与灵敏度
- **必要动作**：① 蒙特卡洛样本量/时间步长收敛性检查（结果随 $N,\Delta t$ 稳定）；② 简化情形对照（无风、单弹时遮蔽区间应有解析/半解析解）。
- **灵敏度**：引信延迟 $\pm \Delta\tau$ 与风速风向对遮蔽区间的扰动（龙卷风图/单因素扫描）；消光系数 $\alpha_{ext}$ 与透过率阈值 $\tau_{th}$ 的鲁棒性。

### 国一亮点建议（可落地）
1. **透过率非二值遮蔽**：用 Beer–Lambert 沿视线积分得到「连续遮蔽度」，输出 $(\text{时间},\text{覆盖率})$ 热力图，明显优于「球心到视线距离 < R 即算遮挡」的粗判。
2. **把风场不确定性做成鲁棒/情景优化**：风场蒙特卡洛生成多条扩散情景，给出「在 X% 情景下满足遮蔽」的稳健起爆方案。
3. **Pareto 前沿 + 成本量化**：弹数—遮蔽效能—成本三维权衡，配上可交互的投放时序甘特图（覆盖时窗叠加图）作结论佐证。

### 高频失分点
1. 把烟幕当「瞬时/静止」或只画一个固定球，**忽略烟幕随时间的膨胀与平流演化**，导致遮蔽区间整体错位。
2. 遮挡判定用「视线到烟幕球心距离 < 半径」的**二值几何判据**，漏掉透过率沿程积分与边缘半透明遮蔽。
3. 坐标/单位混乱：弹道投影、$t=0$ 基准、引信延迟与起爆时刻不一致，多弹时窗无法对齐。

## ⬛ 2025 B 题：碳化硅（SiC）外延层厚度的确定（光学干涉测量）

**已核实要点**：题目确为「碳化硅外延层厚度的确定」，方法核心为**红外反射干涉光谱测厚**；公开题解与后续期刊论文（《数学建模及其应用》等）指向「**色散修正 + 全谱拟合**」是高精度方案；题目含附件光谱（反射率随波数/波长的干涉条纹数据）。SiC 中红外折射率约 2.5–2.6（4H-SiC，具体 Sellmeier 参数与附件数值**待核实**）。

### 交付目标
- **一句话**：由红外反射干涉光谱反演 SiC 外延层厚度，核心是把「色散折射率 + 全谱干涉拟合」做实。
- **各问交付**（按公开题解归纳的 4 问结构，确切表述**待核实**）：
  - **问 1**：单层外延层干涉模型 + 极值/条纹间距法粗测厚度（数值）。
  - **问 2**：计入 SiC **色散 n(λ)**，修正条纹间距/干涉级次，提高反演精度（模型改进+数值）。
  - **问 3**：**全谱拟合**（含噪声、多层/非均匀、相位模糊）反演厚度并给出不确定度（数值+误差）。
  - **问 4**：测厚方法综合评价/精度来源/最优测量条件（报告）。

### 问题拆解与建模思路（逐小问）
- **物理机制**：外延层上下界面反射形成 **Fabry–Pérot 干涉**，反射谱 $R(\nu)$ 呈周期条纹（在波数 $\nu$ 域近似等周期）。
- **问 1｜本质＝条纹间距测厚**：相邻峰(谷)间距 $\Delta\nu$ 与厚度关系
  $$d=\frac{1}{2\,n\,\Delta\nu}$$
  在波数域对 $R(\nu)$ 找极值（`find_peaks`），取 $\Delta\nu=|\nu_{k+1}-\nu_k|$；可用某折射率标称值先粗估。
- **问 2｜本质＝色散修正（用群折射率）**：介质色散时峰间距对应**群折射率** $n_g=n+\nu\frac{dn}{d\nu}$（而非相折射率 $n$），否则产生系统偏差。折射率用 **Sellmeier 模型** $n^2(\lambda)=A+\frac{B\lambda^2}{\lambda^2-C}+\frac{D\lambda^2}{\lambda^2-E}$（系数以文献/附件为准，**待核实**）。由此 $d=\frac{1}{2\,n_g\,\Delta\nu}$。
- **问 3｜本质＝多层薄膜反射 + 全谱拟合**：用**传输矩阵法（TMM，特征矩阵）**逐层算复反射率 $R_{model}(\nu;\,d,n(\nu),k(\nu))$，对全谱做非线性最小二乘 $\min_{d,\theta}\sum_k \big(R_{model}(\nu_k)-R_{meas}(\nu_k)\big)^2$ 反演厚度；并可对反射谱振荡项做 **FFT** 直接测光程差 $2n d$（峰位对应厚度）。相位/级次模糊用「给定厚度范围」约束消除。
- **问 4｜本质＝测量不确定度与条件优化**：误差来源＝折射率误差、光谱分辨率、噪声、级次判读；用误差传播/蒙特卡洛给出 $\pm u$（±2σ 或扩展不确定度）。

### 求解算法与 Python 要点
- **极值/条纹间距**：`scipy.signal.find_peaks`（或 `argrelextrema`）在波数域取 $R(\nu)$ 峰谷 → 求 $\Delta\nu$。
- **FFT 测厚**：`numpy.fft` 对 $R$（或其振荡项 $R-mean$、$1/R$）作 FFT，主峰对应光程差 $2nd$ → 反推 $d$。
- **色散折射率**：Sellmeier 公式手写函数即可；$n_g$ 用数值微分或用解析导数。
- **传输矩阵法 TMM**：手写 ~30 行特征矩阵函数（每层 $M_j=\begin{bmatrix}\cos\delta_j & \frac{i}{q_j}\sin\delta_j\\ iq_j\sin\delta_j & \cos\delta_j\end{bmatrix}$，$\delta_j=2\pi n_j d_j\hat\nu\cos\theta_j$），叠乘求反射率。
- **全谱拟合**：`scipy.optimize.curve_fit` / `least_squares`（给参数上下界），多峰/易多解时用 `differential_evolution` 先全局再精修；`lmfit` 便于设界与报不确定度。
- **不确定度**：拟合协方差（`curve_fit` 的 `pcov`）、`scipy.stats` bootstrap、蒙特卡洛噪声重采样。

### 模型检验与灵敏度
- **必要动作**：① 拟合残差/RMSE/$R^2$（模型谱 vs 实测谱，残差应无系统结构）；② **方法互证**：极值法 vs FFT 法 vs 全谱拟合法三者厚度一致；③ 若附件给标称值则对齐误差。
- **灵敏度**：折射率 $\pm 1\%$、光谱分辨率、噪声水平对厚度的扰动；波长窗口选取（两端舍弃影响）；级次判读的稳健性。

### 国一亮点建议（可落地）
1. **明确「群折射率 vs 相折射率」+ Sellmeier 色散修正**——这是本题区分度所在，期刊论文级结论就是这个路线；把「不用色散的粗结果」与「色散修正后结果」对比列表。
2. **传输矩阵法做多层（外延层/缓冲层/衬底）与吸收**，而非单层简化干涉，反演结果更高一档；并可同时拟合层厚与折射率参数。
3. **给出带不确定度区间的报告值**（$d\pm u$，k=2）+ 波长窗口/分辨率影响分析 + 三种方法交叉验证表。

### 高频失分点
1. 直接套 $d=\frac1{2n\Delta\nu}$ 却用**相折射率**、忽略色散 → 系统性偏差（正确应换群折射率 $n_g$）。
2. 在**波长 $\lambda$ 域**等间隔处理条纹间距（真实条纹在波数 $\nu$ 域近似等间距），极值间距算错；应在波数域计算或重采样。
3. 干涉级次/相位模糊未处理，不同峰间距不一致时简单取平均；拟合不收敛/陷局部最优而未设参数边界、未做全局搜索。

## ⬛ 2025 C 题：无创产前检测（NIPT）的采样时点选择与胎儿异常判定

**已核实要点**：题目确为「NIPT 的时点选择与胎儿的异常判定」；省一等奖题解明确采用「**GAMM（广义相加混合模型）+ 随机森林**」路线（时点优化 + 异常预警模型），并普遍用到逻辑回归、ROC/AUC、阈值选择；数据面向胎儿分数（fetal fraction, FF）随孕周演化及协变量（BMI/孕产年龄等）。检测通量下限经验值约 3%–4% FF（临床经验值，以题面为准，**待核实**）。

### 交付目标
- **一句话**：刻画胎儿分数随孕周的演化并构建异常分类器，联合给出「最优采样时点窗口 + 判定阈值 + 临床建议」。
- **各问交付**（按公开题解归纳的 4 问结构，确切表述**待核实**）：
  - **问 1**：FF 随孕周/协变量的变化规律拟合（曲线 + 显著性）。
  - **问 2**：胎儿异常判定模型（分类器 + 性能：AUC/灵敏/特异度 + 阈值得分点）。
  - **问 3**：最优采样时点选择（时点—性能权衡 + 敏感性）。
  - **问 4**：检测方案/临床建议 + 不确定性（报告）。

### 问题拆解与建模思路（逐小问）
- **问 1｜本质＝纵向轨迹建模（重复测量）**：个体 FF 随时间(孕周)多次测量、非独立 → 用 **GAMM**：
  $$FF_{it} = \beta_0 + s(\text{孕周}_{it}) + \mathbf X_{it}\beta + u_i + \varepsilon_{it},\quad u_i\sim N(0,\sigma_u^2)$$
  平滑项 $s(\cdot)$ 用样条捕捉非线性趋势，随机截距/斜率 $u_i$ 刻画个体差异；协变量如 BMI 分层、孕产年龄。（若 Python 无法精确等价 mgcv，可用 `pyGAM`，或退化为 `statsmodels` 混合模型 `MixedLM` + 样条基。）
- **问 2｜本质＝二分类 + 阈值决策**：以 FF、Z-score（染色体标准化读数比）等为特征，构建 **逻辑回归 / 随机森林 / GBM(XGBoost)** 二分类器（正常 vs 异常）；用 **ROC 曲线**选阈值，取 **Youden 指数最大** $J=Se+Sp-1$ 处为最优切点。
- **问 3｜本质＝时点—性能双目标**：越早采样越有利于临床（早发现），但孕周越早 FF 越低、分类越不稳 → 建立「采样时点 → AUC/灵敏/特异度」曲线，在满足最低性能约束下取最早/最稳时点窗口（多目标/Pareto 或带约束优化）。
- **问 4｜本质＝稳健方案与建议**：个体差异、FF 阈值边界、类别不平衡影响下的稳健检测策略 + 敏感性分析。

### 求解算法与 Python 要点
- **GAMM**：优先 `pyGAM`（`gam.LinearGAM`/`LogisticGAM`）；纵向随机效应用 `statsmodels.formula.api.mixedlm`（+ `patsy` 样条 `bs()`）；R 的 `mgcv::gamm` 为黄金参照（若环境有 R，可用 `rpy2` 调用）。
- **分类器**：`sklearn.ensemble.RandomForestClassifier`、`GradientBoostingClassifier`、`sklearn.linear_model.LogisticRegression`、`xgboost`。
- **评估/阈值**：`sklearn.metrics` 的 `roc_curve`、`roc_auc_score`、`confusion_matrix`、`precision_recall_curve`；Youden 最大切点代码 ~3 行。
- **验证/调参**：`StratifiedKFold`（类别不平衡必须分层）、`GridSearchCV`/`RandomizedSearchCV`/`BayesSearchCV`。
- **类不平衡**：`imblearn` 的 `SMOTE` 或 `class_weight='balanced'`。
- **特征重要性/解释**：`feature_importances_`、`sklearn.inspection.permutation_importance`、`shap`（TreeExplainer）。

### 模型检验与灵敏度
- **必要动作**：① 分层 K 折交叉验证 + 留出测试集（报告 AUC 而非仅准确率）；② GAMM 残差诊断（正态性、自相关、随机效应方差）。
- **灵敏度**：判定阈值 ± 对灵敏/特异度的影响（阈值扫描曲线）；采样时点 ± 孕周对性能的影响；不同随机森林种子/交差验证的稳定性；类不平衡处理前后对比。

### 国一亮点建议（可落地）
1. **把「纵向重复测量」真正当纵向处理**：用混合效应（随机截距/斜率）而非把每条记录当独立样本，直接体现统计严谨性，是区分「看起来对」与「国一」的关键。
2. **SHAP 解释 + Youden 最优阈值 + 时点—性能 Pareto**：三者组合输出「可解释、可决策」的结论，而非只报一个 0/1 准确率。
3. **类别不平衡 + 分层交叉验证 + bootstrap 置信区间**：对 AUC/阈值得分点给出可信区间，结论有统计分量。

### 高频失分点
1. **把纵向重复测量当独立样本**、忽略个体相关性——必须上随机效应/重复测量模型。
2. **只报准确率**：类别不平衡时准确率极具误导性，必须报 AUC/灵敏/特异度/PPV/NPV。
3. **过拟合**：不做交叉验证、特征全塞进随机森林；不处理类别不平衡导致「全判为正常」。
4. 忽视**临床时间约束**（孕周可行范围、检测窗口），给出生物学上不可行的采样时点。

| 题 | 类型 | 相对难度 | 适合队伍 | 拿奖与拿国一的关系 |
|---|---|---|---|---|
| A | 物理/力学 + 时序优化 | 中等偏上 | 工科、机械/物理/航空背景，能写几何与 ODE | 思路顺、完成度易中上；国一靠「透过率连续遮蔽 + 不确定性/鲁棒」拉开差距 |
| B | 物理光学 + 数据处理/拟合 | 中（门槛偏专） | 光电/物理/信号处理，能写 TMM 与拟合 | 对专业队伍「技术流」高分题；国一靠「色散修正 + 全谱拟合 + 不确定度」 |
| C | 统计/机器学习 | 最低（工具现成、上手快） | 统计/计算机、能说清纵向模型与验证 | 竞争最激烈，人人都能做；国一靠「GAMM 纵向建模 + 交叉验证 + SHAP/ROC 严谨性」 |

- 有**力学/物理/几何建模**强项、不惧 ODE 与扩散 → 选 **A**。
- 有**光电/信号/拟合**功底、想做「解析 + 数据」结合 → 选 **B**（产出稳、专业壁垒高）。
- 时间紧、想要**快速可交付 + 统计可解释** → 选 **C**，但务必把纵向结构与交叉验证做严，否则易陷同质化。
