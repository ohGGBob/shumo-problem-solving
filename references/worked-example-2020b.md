## 0. 读题与拆解（先想清每问交什么）

2020 B：玩家从起点穿越沙漠到终点，途中可到村庄补给、可绕道矿山挣收益，受负重上限与天气消耗约束，目标：到终点**剩余资金最大**。

简化场景（示意）：
- 路线 S → B（村庄）→ E；B 处可岔去矿山 M。
- 时间：S→B 2 天，B→E 3 天；矿山支线 B→M 1 天 + 采 1 天 + 返 1 天。
- 消耗 4 kg 物资/天（水+食合并）；负重上限 100 kg；初始资金 800；S 单价 12，B 单价 10；矿山收益 300。

| 问 | 交付物 | 本质 |
|---|---|---|
| 1 | 最优补给 + 最大剩余资金 | 沿路比价 + 背包上界 |
| 2 | 去不去矿山 + 完整策略 | 分叉决策 DP |

> 下文用两个策略分支把问 1/问 2 一起打通——B 题核心永远是"把规则形式化 + 把权衡算清"。

## 1. 假设（三件套示范）

- **H₁ 水/食可合并为单一复合资源**：按固定比例消耗，合并成"物资 kg"。
  理由：两资源消耗速率成比例时，等价于单一资源，简化状态。
  后果：比例随天气变时须拆开；第 2 问有随机天气时用二维资源 DP。
  验证：本题消耗恒定，成立。
- **H₂ 单价沿途已知、恒定，决策前已知天气**。理由：第 1 问晴天恒定。后果/验证：有随机天气时改为期望决策（见 `mid-contest-warning.md` 砍复杂度）。
- **H₃ 负重只约束一次性携带量，不约束累计**。理由：沿途可补给。验证：每次采购量 ≤100kg 成立。

## 2. 符号表

| 符号 | 含义 | 本例值 |
|---|---|---|
|c | 每日物资消耗 | 4 kg/天 |
| p_S / p_B | 起点 / 村庄单价 | 12 / 10 元/kg |
| M0 | 初始资金 | 800 元 |
| G | 矿山收益 | 300 元 |
| W | 负重上限 | 100 kg |

## 3. 建模（两个原则 = B 题"把话讲清"的关键）

1. **沿路比价原则**：补给"越靠便宜站越该买够"。某段从便宜站 B 之后的全部需求，都应在 B 一次性买够；前段 S 只带够走到 B 的量。
2. **分叉决策**：每条策略剩余资金 = M0 − 补给总支出 + (绕行收益)。枚举分支取最大即得最优。

- 策略 1（直行）：需求 = (2+3)×4 = 20kg。S 买 2×4=8kg 花 96，B 买 3×4=12kg 花 120，总支出 216，剩余 **584**。
- 策略 2（去矿）：B 之后还需 (1+1+1+3)=6 天 ×4=24kg。S 买 8kg 花 96，B 买 24kg 花 240，支出 336，加矿收益 300，剩余 **764**。

## 4. 代码（完整可跑）

```python
# 简化穿越沙漠：比价 + 分叉 DP（示意场景，真题以题面为准）
c = 4            # kg/天
pS, pB = 12, 10  # 元/kg
M0, G, W = 800, 300, 100

def strategy(t_SB, t_BE, t_mine_extra, go_mine):
    """返回 (剩余资金, 补给明细)。比价原则：便宜站 B 之后的需求全在 B 买。"""
    t_after_B = (t_BE + t_mine_extra) if go_mine else t_BE
    buy_S = t_SB * c                  # 只带够走到 B
    buy_B = t_after_B * c             # B 之后全部在 B 买
    spend = buy_S * pS + buy_B * pB
    left = M0 - spend + (G if go_mine else 0)
    return left, buy_S, buy_B, spend

# 策略1 直行；策略2 去矿（B->M 1天 + 采1天 + 返1天）
r1 = strategy(t_SB=2, t_BE=3, t_mine_extra=0, go_mine=False)
r2 = strategy(t_SB=2, t_BE=3, t_mine_extra=3, go_mine=True)
print(f'直行: 剩余 {r1[0]}  (买S {r1[1]}kg, 买B {r1[2]}kg, 支出 {r1[3]})')
print(f'去矿: 剩余 {r2[0]}  (买S {r2[1]}kg, 买B {r2[2]}kg, 支出 {r2[3]})')
print(f'结论: 去矿更优' if r2[0] > r1[0] else '结论: 直行更优')
print(f'矿山收益阈值 = {r2[3] - r1[3]} 元（绕行多花的钱，收益超过它才划算）')
```

## 5. 运行结果（真实数字）

| 策略 | 买 S | 买 B | 支出 | 剩余资金 |
|---|---|---|---|---|
| 直行 | 8 kg | 12 kg | 216 | **584** |
| 去矿 | 8 kg | 24 kg | 336 | **764** |

**最优 = 去矿**，剩余资金 764 元。

## 6. 检验（三层）

**① sanity check**——每次采购 ≤100kg（负重可行 ✓）；剩余资金随采购价递减、随矿收益递增，方向对 ✓。

**② 比价交叉验证**——不套"便宜站买够"原则，改用暴力枚举 S/B 各自购买量并满负重上限取下，结果与比价解一致（证明原则不是巧合）。

**③ 灵敏度（收益阈值）**——去矿相对直行多花 336−216=**120 元**，靠矿收益 300 反超；因此仅当矿山收益 **>120 元**（即覆盖绕行的额外补给成本）时绕行才划算——这 120 元就是"绕行的成本线"。"阈值"本身就是一个可写进论文的量化结论：矿收益降到 100 元时，直行反超。

## 7. 成文摘要（带数字）

> 针对穿越沙漠最优策略，本文建立"沿路比价 + 分叉决策"的动态规划模型：补给遵循"越靠便宜站越该买够"——起点只带 2 天物资 8kg，村庄一次补足后续需求；枚举直行与绕行矿山两条分支，得直行支出 216 元、剩余 584 元，去矿支出 336 元、叠加 300 元矿收益后剩余 764 元，故最优为绕行矿山。灵敏度显示仅当矿山收益超过 120 元（覆盖绕行多花的补给成本）时绕行才划算，结论稳健。

## 9. 两个带走的启示

1. **B 题先把"规则"形式化成目标/约束**——"剩余资金最大"= M0 − 支出 + 收益；在此基础上比价原则一句话就把补给策略讲清了，比套一堆智能算法更见功力。
