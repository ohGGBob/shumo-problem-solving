# BAO 论文撰写对标进阶（从真实 O 奖/国奖范文反推写作动作）

> 定位：把「规范不出错」（`paper-skeleton.md` / `figures-and-abstract.md` / `writing-deai-dedup.md`）再往前推一档到「写得像国一」。方法是照着 Baseline→Advanced→Outstanding 三档范文逐条对表，把 O 奖的写作动作搬进自己的稿子。以下技法**全部从真实获奖论文提炼**（数据挖掘 C 题国奖 C052、美赛 2019-C 1901213、2023-C 2307946 等），不是想象；工作区若带 Math-Modeling-BAO 数据集，可随时抽同题 B/A/O 三档对照读。

## 一、BAO 三档写作梯度（先看清差在哪）

| 维度 | Baseline（能交） | Advanced（正确） | Outstanding（讲透） |
|---|---|---|---|
| 标题 | 通用"XX 问题研究" | 点题到数据/对象 | 「实词 + 命名模型」，如 `基于 RFMS 指标的会员画像数据挖掘` |
| 摘要 | 罗列方法、无数字 | 每问有数字 | 每问「命名模型 + 公式 + 量化结论 + 检验」，敢写负结果 |
| 问题分析 | 一句"本题属 XX 类问题" | 提到数据字段 | 写成「数据→字段匹配→方法→指标」操作链 |
| 建模段 | 摆模型名 | 模型 + 参数 + 结果 | 给模型起名 + 讲评分体系设计意图 + 表图三件套 |
| 检验 | 一句话"模型合理" | 有灵敏度 | 随机抽样 + 打分类别评价 + 对接业务对象 |
| 优缺点 | 套话 | 具体 | 优点动作化、缺点机制化，诚实写负结果 |
| 落点 | 无 / 一句"可推广" | 定性建议 | 面向决策者的可执行建议（对谁/做什么/预期效果） |

**写论文时对表做三个「更进一步」**：① 每个模型起名字 + 讲清"为什么这么设计"；② 每个结论配量化数字 + 一份实证检验；③ 优缺点 / 灵敏度写成证据链，模型落点是"给谁、做什么、预期效果"。

## 二、标题（3 秒定调）

- 国赛：`基于<关键指标/方法>的<对象><任务>`，把最出彩的指标或模型写进去（RFMS / TOPSIS / 马尔可夫链 / Apriori）。忌 `XX 问题的研究与分析` 这种空标题。
- 美赛：`<主标题：抓眼球的比喻或动词短语>`，副标题补方法（`Take Me Home: Preventing Journeys Down the Opioid Addiction Road`；`Words Behind Wordle: Puzzle Game Analysis Using Machine Learning and Time Series Theory`）。
- 通用原则：标题里出现 1–2 个「方法实词」，评委一眼知道你用了什么。

## 三、摘要（半页/一页定生死）

### 写法 A：国赛逐问式

句式骨架：`针对问题 X，构建了<模型名>，通过<关键动作>得出<量化结论>。`

- 每问独立一段：**模型名 + 核心公式/指标 + 具体数字**三要素齐。
- 数字必须落地：占比、准确率、误差、区间、激活率，并带单位/置信（`C3=1.000`、`62.5%`、`激活率超 10%`）。
- 结尾两句：灵敏度结论（"在 ±10% 扰动下结论稳健"）+ 推广（点到为止，别空喊"重要意义"）。

### 写法 B：美赛 bullet 式

- 第一段：问题 + 数据范围 + 一句话总思路。
- 中间 bullet（●）每点 = 一个 sub-problem 的「方法 + 结果 + 验证」，逐点带数字。
- 显式给误差/置信：`error on the order of 10⁻⁵ reports per capita`、`[10139.23, 30808.07] (80% confidence)`。
- 收尾：sensitivity / strengths / limitations 各一句。

### 摘要三必须

1. **必须有可记忆的模型名**（FMS、RF、Model I/II/III）——评委靠它抓方法脉络。
2. **结论必须量化**——把"较好/较高/显著"全部替换成数字。
3. **敢写负结果**——`data augmentation… fails to achieve the expected effect` 这类诚实比报喜更可信、更显严谨。

## 四、问题重述 vs 问题分析（别混成一章）

- **重述**：转述背景 + 把各问压成一句动宾（"建立/计算/分析/比较…"），不整段抄题面。
- **分析**：逐问一小节，写成「数据→字段匹配→方法→指标」操作链，而非"本题属于评价类问题"的空判定。
  - 国一范本原味：`以附件 1 卡号 kh 作为唯一识别特征，与附件 3 消费明细匹配，筛出本地会员；以频次、总额、平均金额、单次最高 4 个消费行为指标分析特征`。
  - 直接在分析里引 [文献] 佐证方法选择（如选 RFM 中的 F/M/S 三指标并给出理由）。

## 五、假设（写成"一句可辩护的判断"）

- 每条 = 一个具体、可辩护的**数值规则或独立性判断**，尽量挂理由/文献：
  - `假设时间窗口以半年为单位增减，会员半年中的消费行为能代表其长期习惯`；
  - `假设非活跃会员的激活主要受促销次数与力度影响，与主观因素无关`（独立性假设配好后果口径）。
- 忌 `忽略次要因素`、`假设数据可靠` 这类空话；写成 `忽略 X，因其量级约 <1%` 才有意义。

## 六、建模与求解（论文主体，最该下功夫）五件套

1. **给模型起名**：FMS 购买力模型、RF 状态模型、Model I/II/III——起了名后面才能反复引用、讨论、对比。
2. **讲设计意图**：评分/阈值体系要写清「怎么定 + 为什么这么定」。
   - 范本：`评分相乘使状态值由 1~5 拉大到 1~25，更有区分度`；`R、F 比 M、S 更能反映消费状态，故用 RF 而非 RFM`。
3. **表/图三件套**（每张图表都配）：引出句（"如表 5 所示"）→ 三线表/图（带完整表注）→ 解读句（量化结论：百分比、人数、排名）。图注独立传达结论（见 `figures-and-abstract.md`）。
4. **检验写成实证**，别只写"模型合理"。范本：`在 43940 条记录中随机抽 8 条打分，5 条(62.5%)评优、3 条(37.5%)中上、无中等以下`，并把评分等级与业务对象（铂金/黄金/白银/青铜）对接。
5. **结论量化 + 落业务**：`铂金型占 21.4%、黄金 34.5%…级别越高价值越高，管理者应优先维护高级别会员`——把数学结果翻译成"给谁、做什么"。

## 七、模型评价：优点「动作化」、缺点「机制化」

- **优点** = 具体做了什么 + 对本题解决了什么（忌"模型全面、实用性强"）。范本：`创建 FMS 模型，把促销从定性提升为定量研究`。
- **缺点** = 具体局限 + 机制 + 后果（+ 补救）。美赛 O 奖缺点写得极诚实质化：
  - `epicenter 计算不区分流入/流出，故它衡量的是总扩散而非纯向外扩散`；
  - `阈值一刀切：略低于 1σ 的县不被判为感染区，从而漏掉近临界目标`。
- **落点**：写成给决策者的可执行建议（美赛 Policy Strategies / Policy Letter），每条 = 对谁 + 做什么 + 预期效果 + 数据/文献支撑。范本：`对 65 岁以上与 18 岁以下共居家庭投放"药品上锁"宣传，降低青少年误用长辈处方阿片`。

## 八、灵敏度：逐问展开，别一锅烩

- 逐问/逐模型回顾关键参数并摄动：`问题1 权重 ±10%`、`问题2 聚类数 K`、`问题3–4 时间窗口 T`、`问题5 促销强度权重`；标出最敏感项，落到「结论是否稳健」。
- 美赛把灵敏度单列一章（Tweaking external / internal factors），并说明对策略的影响。

## 九、参考文献（真实 + 一一对应）

- GB/T 7714 著录；正文引用键与文末逐条对应（铁律，见主 SKILL）。
- 方法级引用（RFM、马尔可夫假设等）挂在「问题分析/假设」处，别全堆结尾；国一范本常用《数学模型（第四版）姜启源》压轴，属真实可核验文献。

## 十、美赛特有（别拿国赛模板硬套）

- 25 页硬上限（含 Summary Sheet / 目录 / 正文 / 参考文献 / 附录 / 代码）内设 **Contents**（目录）。
- **Assumptions 每条带小标题**：`4.1 As a disease`、`4.2 The Markovian assumption`，评委扫标题即懂。
- 引言用**醒目统计 + 引用**开头：`In 2015, 33,091 people died… more than 60%… [1]`。
- 收尾可以是 **Policy Letter / 给利益相关方的信**（按题要求），措辞面向非技术决策者。

## 十一、逐节自检清单（写完对照勾）

| 章节 | 写什么 | 不写什么 |
|---|---|---|
| 标题 | 「基于XX的YY」或「主:副」+ 方法实词 | "XX 问题研究" |
| 摘要 | 逐问「命名模型 + 公式 + 量化结论 + 检验」，敢写负结果 | "首先/其次/最后"套娃、"重要意义"、无数值 |
| 问题分析 | 数据→字段匹配→方法→指标 操作链，挂文献 | "本题属于 XX 类问题"空判定 |
| 假设 | 一句可辩护的数值规则/独立判断 + 理由 | "忽略次要因素""数据可靠" |
| 建模段 | 模型起名 + 设计意图 + 表图三件套 + 实证检验 + 落业务 | 只摆公式不写"怎么算/为什么" |
| 优缺点 | 优点动作化、缺点机制化 + 诚实负结果 | "全面/科学/实用"套话 |
| 灵敏度 | 逐问摄动 + 敏感项 + 结论稳健性 | 缺失或一锅烩 |
| 参考文献 | 真实可核验 + 引用键一一对应 + GB/T 7714 | 编造 / 凭记忆填字段 |

## 十二、全文级改前 / 改后对照（把"句法学到手"落到"整段会写"）

同为 2018 C「会员画像」题（国奖 C052 的模型），看同一段内容"拉胯 / 国一"的差距怎么靠上面几条动作补齐。

### 建模结果段（问题 2：购买力识别）

> ❌ 改前：本文通过聚类分析对会员进行了细分，得到了几个簇，结果比较理想，能够较好地识别会员价值，说明模型是有效的。

（没有模型名、没有簇数、没有指标、没有"怎么识别的"；"比较理想/有效"零信息。）

> ✅ 改后：以频次 F、总额 M、单次最高消费 S 构成 FMS 购买力评分，按百分位把三个指标各映射到 1–5 分，相乘后取值 1~125，对应铂金/黄金/白银/青铜四档。对 43940 条记录随机抽 8 条打分：5 条(62.5%)评优、3 条(37.5%)中上、无中等以下；四档占比铂金 21.4%、黄金 34.5%、白银 22.1%、青铜 22.0%。据此管理者应优先维护"三高"铂金型会员。

（模型起名 → 设计意图"1~5 分怎么定、为什么相乘" → 实证检验"抽样+百分比" → 落业务，四步全在。）

### 优缺点段

> ❌ 改前：本模型的优点是比较全面、科学合理；缺点是还不够完善，未来可以继续改进。

> ✅ 改后：优点是 FMS 只用利润贡献最直接的频次与金额维度，评分可复现、可解释，无需黑箱训练。缺点是 F 与 M 之间存在相关性，且单次最高消费 S 大并不必然带来利润（如团购），对"金额高但频次低"的会员可能高估；后续可在 M 上追加利润率权重修正。

（优点 = 做法 + 作用；缺点 = 具体局限 + 机制 + 后果 + 补救。）

### 摘要收尾句

> ❌ 改前：综上，本文模型具有重要的理论意义和实践价值。

> ✅ 改后：权重 ±10% 摄动下，会员价值档位划分不变；时间窗口由半年拉长到三年时，激活率趋势稳健，结论可信。模型可平移至电商、电信等领域的会员分层与促销优化。

（既给了灵敏度量化结论，又点到为止地推广，不空喊意义。）

> 一句话记法：**改前是"形容词 + 套话"，改后是"命名模型 + 数字 + 为什么 + 给谁做什么"。** 下笔先问四个词——叫什么模型、得多少、凭什么、给谁用。

## 十三、美赛 A / B / C 题型写法差异（同一套「讲透」动作，落点不同）

三类 O 奖共通的仍是前几节的"命名模型 + 逐题方法→结果→验证 + 数字 + sensitivity + strengths/weaknesses"，但**各题型的写作重心不同**（据 2023-A 2309229、2023-B 2315379、2019-C/2023-C 提炼）：

| | A 题（连续/机理） | B 题（离散/优化） | C 题（数据洞察） |
|---|---|---|---|
| 标题调性 | 比喻 + 对象（"The Warriors against Drought"） | 愿景/方案（"common paradise for humans and wildlife"） | 对象 + 方法（"Words Behind Wordle… ML & Time Series"） |
| 前置准备 | 物种分类 + **参数估计**专节 | 网格划分 + **定量定义模糊概念** | 数据清洗 + 字段匹配/特征 |
| 正文主线 | **机理链推导**：基础方程 → 逐项加约束 → 命名模型 | **决策变量/目标/约束**三段式 + 多方案择优 | 模型 + 特征 + 结果，重可解释 |
| 结果量纲 | 生物量/稳定度/多样性指数（物理量） | **钱/收益/分配方案**（$154M vs $130M） | 准确率/误差/预测区间 |
| 求解工具 | 数值求解 ODE + 仿真 | Lingo/求解器 + 图算法（Dijkstra） | sklearn/statsmodels + 交叉验证 |
| 灵敏度 | 改物理参数（竞争强度/吸水率），报"对谁敏感" | 权重摄动，报"结论是否稳健" | 参数/特征摄动，对照基准 |
| 收尾交付 | 长期可持续性策略 | **2 页非技术报告（给决策者）** | 业务/运营可执行建议 |

**三条要义**：

1. **A 题**：别只甩方程——写清"每个参数从哪来、为什么模型要加这一项"，并做**定性分析 → 定量分析**两层（先讲趋势机制，再给数值指标，如 biomass / CV / Shannon-Wiener 指数）。
2. **B 题**：必须给**算例 + 经济量纲 + 多方案对比择优**；先把题里模糊词（"机会损失""负向交互"）定量定义再建模；结尾写一段**面向非技术决策者**的话或 2 页报告。
3. **C 题**：把「数据→字段→方法→指标」链路写进问题分析，敢写负结果，落点是给运营/决策者的可执行动作。
