## 2024 A 题：「板凳龙」闹元宵（螺线行进、速度与调头路径）

### 交付目标

- **一句话总目标**：用「刚性板凳链 + 阿基米德螺线」刻画舞龙队的几何—运动关系，给出盘入全程、盘入终止时刻、调头与盘出路径上的各节点位置/速度，并满足「无碰撞 + 速度约束 + 时间预算」。
- **逐小问交付**（小问口径以官方为准，核心内容如下）：
  - **问 1**：给定龙头沿螺线匀速盘入，输出龙头、龙身若干、龙尾各**把手中心**「位置 $(x,y)$ + 速度 $(v_x,v_y)$」的时间序列，写入 `result1.xlsx`（可能另有 `result2.xlsx` 对应不同速度/初始条件，**待核实**）。
  - **问 2**：给出**盘入终止时刻**（龙头再盘入即发生「板凳相碰」）及该时刻各把手位置/速度。
  - **问 3**：设计**调头路径**（受最小转弯半径 / 曲率约束、与螺线光滑衔接、无碰撞），给出调头时间与各把手位置/速度。
  - **问 4**：在速度范围（常见 $0.5\le v\le1.5\ \text{m/s}$，**待核实**）与总时间预算（常见 $300\ \text{s}$）内完成「盘入→调头→盘出」全程，求可行/最优速度方案与最短时间。

### 问题拆解与建模思路

**关键数据（已核实）**：螺线为**等距螺线（阿基米德螺线）**，螺距 $d=55\ \text{cm}$，故极坐标方程
$$\rho(\theta)=a+\frac{d}{2\pi}\theta=a+b\theta,\quad b=\frac{0.55}{2\pi}\approx0.0875\ \text{m/rad}.$$
板凳龙由 **223 节** 板凳组成（龙头 1 节 + 龙身 221 节 + 龙尾 1 节，**节数待核实**），**每节长 $L=2.2\ \text{m}$（220 cm）、宽 $0.3\ \text{m}$（30 cm）**（已核实）；相邻两节通过**把手**铰接，龙头前把手为跟踪参照点。

#### 问 1：本质是「螺线弧长参数化 + 链式定位」

- **龙头前把手**以线速度 $v=1\ \text{m/s}$ 沿螺线盘入。设 $t=0$ 时龙头位于 $\theta_0$，弧长
$$s(t)=s(\theta_0)+v t,\qquad s(\theta)=\int_{\theta_0}^{\theta}\sqrt{\rho^2+b^2}\,d\theta.$$
  $\rho=b\theta$（$a=0$）时弧长有解析式：
$$s(\theta)=\frac b2\Big[\theta\sqrt{1+\theta^2}+\operatorname{asinh}\theta\Big].$$
  由 $s(t)$ **反解 $\theta(t)$**（单调 → 二分/`brentq`），得龙头位置 $\mathbf P_0(t)=\rho(\theta)(\cos\theta,\sin\theta)$。

- **龙身/龙尾各把手定位**（关键区分点）：板凳是**刚性弦**，不是等弧长。给定 $\mathbf P_i$，求 $\theta_{i+1}<\theta_i$ 使
$$\bigl|\mathbf P(\theta_{i+1})-\mathbf P_i\bigr|=L_i \quad(\text{弦长=板凳长}).$$
  对 $\theta$ 单调，用一维求根逐步迭代，得所有把手位置 $\{\mathbf P_i\}$。

- **速度**：整条龙沿曲线平移，故每个把手速度**大小约为 $v$**、**方向沿各自位置的螺线切线**：
$$\mathbf v_i=v\,\hat{\mathbf t}(\theta_i),\quad \hat{\mathbf t}=\frac{d\mathbf P/d\theta}{|d\mathbf P/d\theta|},\quad \frac{d\mathbf P}{d\theta}=b(\cos\theta,\sin\theta)+\rho(-\sin\theta,\cos\theta).$$

#### 问 2：本质是「几何碰撞判定的终止时刻搜索」

- 盘入越往中心，相邻圈间距（=螺距 55 cm）相对板凳宽 30 cm 越紧。终止准则：**龙头前把手到达螺线最内侧可行半径**，或**任意两段板凳（线段）之间最小距离 < 0.3 m 即碰撞**。
- 做法：沿时间推进（或对极径二分），每步计算**线段—线段最小距离**（含宽度阈值），找到首次越限的时刻 $t_{\rm end}$，输出该时刻各把手位置/速度。

#### 问 3：本质是「曲率受限的最短调头曲线 + 无碰撞约束」

- 龙头无法继续盘入时需 180° 调头盘出。设最小转弯半径 $R_{\min}$（由铰接结构与板凳长/螺距推出，或题目给定），要求调头曲线曲率 $\kappa\le 1/R_{\min}$，且与盘入螺线终点、盘出路径起点**至少一阶连续（切线连续）**。
- 标准构造：**两段半径 $R_{\min}$ 的圆弧组成的 S/U 形（Dubins 型路径）**，或克洛索（Clothoid）曲线保证曲率连续。路径长度按弧长积分求，调头时间 $=(\text{路径弧长})/v$。同时逐点验证龙身不与已盘入的龙身碰撞。

#### 问 4：本质是「带速度/时间约束的全程运动规划」

- 把盘入、调头、盘出三段按弧长拼接，令速度分段可调、满足 $v_{\min}\le v(t)\le v_{\max}$ 与总时间 $T\le T_{\max}$；求最短全程时间或最优速度曲线（例如最小化时间、或给定时长下最小速度峰值）。

### 求解算法与 Python 要点

| 步骤 | 方法 | 库/函数 |
|---|---|---|
| 螺线上 $s\leftrightarrow\theta$ 互转 | 解析式 + 求根 | `scipy.optimize.brentq`；弧长解析 `(b/2)*(θ*sqrt(1+θ²)+asinh(θ))` |
| 弧长数值积分（防备解析复杂） | 自适应积分 | `scipy.integrate.quad` / `quad_vec` |
| 逐把手「弦长定位」 | 一维求根迭代 | `scipy.optimize.brentq`（对 $\theta$ 单调） |
| 位置→速度 | 切线单位向量解析求导 | `numpy` 直接算向量 |
| 碰撞判定 | 线段—线段最小距离 | 手写取投影区间，或 `scipy.optimize.minimize_scalar` |
| 调头曲线 | Dubins/双圆弧参数点列 | 手写圆参数 + 相切条件；`scipy.optimize.fsolve` 求切点 |
| 输出 Excel | DataFrame 写表 | `pandas.DataFrame.to_excel(..., engine='openpyxl')` |
| 可视化/核对 | 螺线 + 龙形轨迹 | `matplotlib`（静态图 + 帧动画） |

**与代码模板关系**：主流模板即「螺线点生成 → 弧长反解 → 弦长迭代定位 → 差分/解析求速度 → 写 xlsx」。你只需保证「弦长=板凳长」的迭代定位正确（这是网传模板最常糊弄的地方）。

### 模型检验与灵敏度（必做）

1. **弧长 vs 弦长一致性**：对同一把手，同时用「弧长 $=L$」与「弦长 $=L$」两种模型计算，展示螺距 55 cm、板凳长 2.2 m 时两模型的定位偏差（约毫米级，需**定量报告**并说明选择了弦长模型）。
2. **链长与螺线自洽**：核对 $\sum_i L_i$（总长≈223×2.2 m）是否与盘入经历的总弧长一致；速度核对——各把手速度模长≈$v$、方向为切线。
3. **碰撞临界性质**：对 $t_{\rm end}$ 做 ±Δ 扰动，验证「刚好相切」是临界点（$t_{\rm end}-\varepsilon$ 无碰撞、$t_{\rm end}+\varepsilon$ 碰撞）。
4. **调头路径光滑性**：数值检查关键点处一阶导数连续性、曲率不超界；参数摄动 $R_{\min}$、螺距看调头时间与无碰撞区变化。
5. **时间/速度灵敏度**：总时间、$v_{\max}$ 变动 5%–10%，报告全程可行性变化。

### 国一亮点建议

1. **明确区分「弦长/弧长」并给出误差分析**：这是本题第一区分点——说明刚性板凳定位必须用弦长迭代，同时量化弧长近似的截断误差。
2. **碰撞用「线段—线段最小距离（含 30 cm 宽度）」而非把手点重合**：配一张盘入终止瞬间局部放大图，展示临界相切。
3. **调头给「曲率受限 + 一阶光滑衔接」的构造（Dubins/克洛索）**，并给出全程轨迹动图/逐帧龙形，直观呈现无碰撞与滑顺调头。

### 高频失分点

1. **速度当标量**：回答只给速率不给方向矢量，或方向不是各自切线（用差分求速度时步长没对弧长做、符号方向乱）。
2. **弧长当弦长直接等分**：导致后续把手**系统性错位**且不自知；这是最普遍的硬伤。
3. **碰撞判据粗糙 / 调头不满足最小转弯半径或不连续**：碰撞只看「把手距离<宽度」而非线段最短距离；调头曲线与螺线衔接不光滑 → 物理不可行。

## 2024 B 题：电子产品生产过程中的质量决策（检测 / 次品 / 拆解）

### 交付目标

- **一句话总目标**：把「是否检测零配件、是否检测（半）成品、不合格品是否拆解/回收」建模为**期望成本（或利润）最小的 0-1 决策**，并对给定情形给出决策方案与量化指标；高阶问引入**抽样检验与统计不确定性**。
- **逐小问交付**（口径以官方为准，核心逻辑如下）：
  - **问 1**：对给出的 **6 种情形**（参数：零配件 1/2 次品率、单价、检测成本、装配成本、成品售价、成品检测成本、拆解成本、调换（退回）损失等；具体数值**待核实/官方表**），分别给出「零配件 1/2 是否检测、成品是否检测、不合格品是否拆解」的最优方案及对应指标（期望成本/利润）。
  - **问 2**：推广到 **$m$ 个零配件 + $n$ 道工序**（多级半成品/成品）的流水线，建立一般决策模型并给出方案。
  - **问 3**：检测方式引入**抽样检验**，设计满足给定显著性水平/置信度（已核实官方思路用约 **95% 信度**，具体 α/β 待核实）的最小检测量抽样方案，并与决策联立。
  - **问 4**：回到问 1 的 6 种情形，假设**零配件/成品次品率未知、需抽样估计**，设计抽样方案并重新给出最优决策。

### 问题拆解与建模思路

**统一工具：期望成本分解**。设：
- 零配件 $i$：次品率 $p_i$、单价 $c_i$、检测成本 $d_i$。
- 装配成本 $A$；装配后成品为次品的概率 $p_{\rm asm}$（由各零配件是否次品 + 装配工序自身引入次品率决定，例如「任一关键零配件为次品 → 成品次品」或组合逻辑，**具体依赖关系以官方为准**）。
- 成品售价 $P$、成品检测成本 $D$、不合格品退回/调换损失 $W$（客户退回再损失）、拆解成本 $R$、拆解后可回收价值 $S$。

决策变量（0-1）：$x_i$（是否检测零配件 $i$）、$y$（是否检测成品）、$z$（不合格成品是否拆解）、$w$（是否回收/报废）。

#### 问 1：本质是「枚举/阈值比较的确定性决策」

- 对 2 个零配件，决策空间仅 $2^3=8$（×拆解选项），可直接**全枚举**取期望成本最小；更重要的是给出**解析阈值**：
  - 检测零配件 $i$ 的收益 = 不检测时次品流入下游导致的期望损失 $E_i$（下游整改成本/成品损失）与检测成本 $d_i$ 比较 → 当 $p_i E_i \ge d_i$ 时检测。
  - 拆解 vs 直接退回：比较「拆解回收净值」$S-R$ 与「调换损失」$-W$。
- 期望成本（示意，需按官方成本项补全）：
$$C=\sum_i (c_i + x_id_i) + A + yD + (1\!-\!y)\text{[次品外流损失]} + z\,(R-S)\cdot \Pr(\text{检出次品}) + \ldots$$

#### 问 2：本质是「多阶段决策树 / 动态规划 / 等价整数规划」

- 状态 = 各零配件/半成品是否已检测；阶段 = 各装配工序。次品向下游**传播**，每道工序可执行「不检测 / 全检」。
- 建模为**决策树**逐层算期望成本，或写成**0-1 整数规划**（目标线性、约束为「每级只能选一种检测策略」），直接交给 MILP 求解器。

#### 问 3：本质是「抽样验收（OC 曲线）设计」

- 抽样方案 $(n,c)$：抽 $n$ 件，次品数 $X$，若 $X\le c$ 则接收。**OC 曲线**
$$L(p)=\Pr(\text{接收}\mid p)=\sum_{k=0}^{c}\binom nk p^k(1-p)^{n-k}.$$
- 要求：在**合格质量水平 AQL $p_0$** 处 $L(p_0)\ge1-\alpha$（$\alpha$ 生产者风险），在**极限质量 LTPD $p_1$** 处 $L(p_1)\le\beta$（$\beta$ 消费者风险）。求**最小 $n$ 及对应 $c$**（$n$ 小时用二项分布精确算，勿盲目用正态近似）。

#### 问 4：本质是「抽样估计 + 决策闭环」

- 先用题给显著性/置信度反推（$n,c$）得到次品率**区间估计/点估计**，再把这些估计代入问 1 的期望成本模型，使「检测不确定性」进入决策；报告抽样量与期望成本的关系。

### 求解算法与 Python 要点

| 步骤 | 方法 | 库/函数 |
|---|---|---|
| 问 1 枚举 | 笛卡尔积全枚举 | `itertools.product([0,1], repeat=k)` |
| 问 2 决策树/DP | 手写期望递归 或 图遍历 | `networkx`（可选）；或直接 MILP |
| 整数规划 | 0-1 线性规划 | `scipy.optimize.milp`（≥1.9）或 `pulp`/`ortools`（推荐 PuLP+CBC，变量可命名） |
| 抽样 OC 曲线 | 二项分布 CDF | `scipy.stats.binom.cdf(c,n,p)`、`.sf`；小 $p$ 可用 `poisson` |
| 反解 $(n,c)$ | 枚举 $n,c$ 找满足 α/β 最小 $n$ | 双重循环 + `binom.cdf`；或 `scipy.optimize` |
| 置信区间 | 抽样比例区间 | `scipy.stats.binomtest` / `proportion_confint`（`statsmodels.stats.proportion`） |
| 蒙特卡洛验证 | 过程仿真 | `numpy.random` 按次品率逐级抽样，统计期望成本 |

**与代码模板关系**：问 1 直接枚举（8 种方案）即可；问 2 用 PuLP 写 0-1 MILP 最省事、可扩展；问 3/4 的关键是**正确用 `binom.cdf` 构造 OC 曲线**，而不是抄错 α/β 不等式方向。

### 模型检验与灵敏度（必做）

1. **期望成本分解核对**：拆出「采购 / 检测 / 装配 / 成品检测 / 拆解 / 调换损失」六项，验证加总 = 总期望；把每种决策组合的表格列出，说明最优方案是全局而非局部。
2. **决策断点分析**：画「检测与否」随 $p_i$（次品率）与 $d_i$（检测成本）变化的**相图/断点**，说明阈值 $p_iE_i=d_i$ 两侧决策翻转。
3. **抽样方案自洽**：用蒙特卡洛在 AQL/LTPD 处抽样，验证实际风险 ≈ α、β。
4. **问 4 闭环**：抽样样本量 $n$ 变化 → 次品率估计误差 → 期望成本变化，报告「检测投入 vs 决策不确定性」的权衡曲线。

### 国一亮点建议

1. **解析阈值 + 枚举双轨呈现**：既给出「边际比较」的解析判据（可解释性强），又用枚举/求解器验证，体现模型不是「暴力算出来的黑箱」。
2. **OC 曲线与 α/β 精确、图可视化**：明确使用二项/超几何而非正态近似，画出 OC 曲线与 (n,c) 选取过程；问题 4 做「抽样—决策」闭环。
3. **蒙特卡洛仿真与解析期望互证**：用随机仿真复现期望成本（附置信区间），增强说服力（已见国二解法采用仿真路线，可参考）。

### 高频失分点

1. **决策方向错误 / 漏成本项**：没算清「不检测 → 次品流入下游的更大损失」，或漏掉拆解回收价值、调换损失的概率加权、装配工序自身引入的次品。
2. **期望成本公式不闭环**：各项没有按「是否发生」的概率相乘（把调换损失当固定发生、或把拆解成本当无条件发生）。
3. **抽样检验方向/近似错误**：把 OC 曲线的 α、β 对应关系写反；$n$ 较小时用正态近似导致 $(n,c)$ 不可行或不满足风险要求。

## 2024 C 题：农场农作物种植策略（面积分配与收益/风险权衡）

### 交付目标

- **一句话总目标**：以「分类耕地 + 多作物 + 销量/价格/亩产约束（含轮作与土地利用规则）」建立种植面积优化，从单年线性规划 → 多年「预测 + 优化」→「风险/稳健优化」逐级深化。
- **逐小问交付**（口径以官方为准）：
  - **问 1**：在「**超出预期销量的超额产量滞销（打折/浪费）**」假设下，求 **2024 单年**最优种植面积分配与最大净收益（各作物、各土地类型分配明细）。
  - **问 2**：利用往年数据**预测 2025–2030 各年**销量/价格/亩产，逐年（或多年联动）给出 6 年最优方案，说明轮作等跨年约束的影响。
  - **问 3**：**放开假设**（价格波动、滞销处理、存储、替代作物等），引入**收益风险/稳健性**，给出 2024–2030 综合方案，并量化比参考情形（或问题 2）**收益提升/风险改善**的百分比。

### 问题拆解与建模思路

**数据要素**（具体值**待核实/官方附件**）：
- 土地类型：**平旱地、梯田、水浇地、大棚**（大棚分编号与类型，常见约 16 个，总面积约 1200 亩量级）；附件给出每块地的**类型与面积**。
- 作物：粮食（小麦、玉米、**大豆**）、**水稻**（限水浇地/大棚）、蔬菜若干（黄瓜/番茄/豆角等）、**食用菌**（限大棚）。
- 每作物参数：**亩产、种植成本、平均售价、预期销量**，以及**作物—土地适配矩阵**（哪些作物可在哪类地种）。附件另给往年的价格/销量/亩产（用于问题 2 预测）。

**核心决策变量**：$x_{c,f}$ = 作物 $c$ 在地块 $f$ 上的种植面积（亩）；问题 3 可能需要 0-1 变量 $y_{c,f}$（是否种植）以表达轮作/单一大棚整块约束。

#### 问 1：本质是「线性规划（分段线性收益处理滞销）」

- 目标：最大化净收益 $\sum_{c,f}(\text{销售收入}-\text{成本}\cdot\text{面积})$。
- 关键技巧——**滞销的分段线性化**：单块收益 = 正常价 $\times\min(\text{产量},\text{销量})$ + 折价 $\times\max(0,\text{产量}-\text{销量})$。引入**虚拟「废弃/折价量」$u_c\ge0$** 与约束 $\text{产量}_c + u_c = \text{销量}_c + \text{折价量}_c$ 等，写成纯线性（避免 $\min$ 非光滑）。
- 约束：
  - $\sum_c x_{c,f}\le A_f$（每块地面积）；
  - `适配矩阵`：不适配的 $c,f$ 取 $x_{c,f}=0$；
  - 各作物总种植面积 $\le$ 其可在用的土地上限（分类型汇总）。

#### 问 2：本质是「时间序列/回归预测 + 逐年联动优化（预测—优化闭环）」

- 对销量、价格、亩产做预测：数据点少 → 常用**线性趋势/指数平滑/Holt-Winters/简单 ARIMA**（`statsmodels`）；务必做**留出验证**并报告 MAPE/RMSE，不要只给外推线。
- 逐年优化并在年份间加入**轮作递推**：地块 $f$ 第 $t$ 年种什么，约束第 $t+1$ 年（如大豆种植后 2–3 年内不得重茬、水稻/蔬菜需轮作等，**规则以官方为准**）。

#### 问 3：本质是「风险建模：均值—方差/CVaR/鲁棒/多情景随机规划」

- 把价格、亩产、销量视为随机变量（可基于问题 2 预测分布生成**情景集**）。
- 目标改为「期望收益最大化，同时控制风险」：
  - **均值—方差**：$\max\ \mathbb E[Z]-\lambda\operatorname{Var}(Z)$（二次规划或线性化）；
  - **CVaR**（条件风险价值）：引入参数 $\alpha$ 与辅助变量，化为线性；
  - **鲁棒优化 / 多情景**：对最坏情景或 $\min\text{–}\max$ 目标做稳健解。
- 需**明确比较基线**：与问题 2（或附件参考情形）比收益提升 $\%$ 与风险下降 $\%$，并解释新增因素（存储延期销售、作物可替代、价格波动）如何改变分配。

### 求解算法与 Python 要点

| 步骤 | 方法 | 库/函数 |
|---|---|---|
| 问 1 LP | 线性规划 | `scipy.optimize.linprog`（标准形）或 **`pulp`（推荐，变量/约束可读）** |
| 问 1 滞销线性化 | 引入折价/废弃变量 | 手写约束；目标分段线性化 |
| 适配矩阵/土地分型 | 变量下界=0 + 约束 | 直接用字典批量加约束 |
| 问 2 预测 | 时间序列/回归 | `statsmodels`（`Holt`/`ExponentialSmoothing`/`ARIMA`）、`sklearn.linear_model`；交叉验证 |
| 问 2 逐年联动 | 多年 LP（递推） | `pulp` 循环年份建变量/约束 |
| 问 3 风险 | 均值—方差/CVaR/情景 | CVaR 线性化手写；或 `cvxpy`；蒙特卡洛情景生成 `numpy.random` |
| 大模型备选 | 遗传算法（一般不需要） | `deap`/`geatpy`（仅当规模大/非线性时） |

**与代码模板关系**：问 1 是经典 LP（PuLP+CBC 秒解）；问题 2 的难点不在求解器而在**预测合理性与轮作跨年约束是否写全**；问题 3 是体现区分度的关键，建议用 CVaR/多情景而非简单加一个方差惩罚。

### 模型检验与灵敏度（必做）

1. **约束完整性核对**：逐类土地（平旱地/梯田/水浇地/大棚）打印面积利用率，确认适配矩阵与「大豆适宜梯田、水稻限水浇地/大棚、食用菌限大棚」等**题目显式规则都落实**。
2. **滞销收益核对**：对某作物手工算一个「产量<销量」与「产量>销量」的收益，验证分段线性表达正确。
3. **预测—优化闭环**：报告预测误差（MAPE/RMSE）；做「预测值 ±5%/±10% 摄动下最优收益如何变」的敏感性，说明方案稳健性。
4. **风险/稳健性**：给出收益分布直方图、不同风险厌恶参数 $\lambda$/不同 CVaR 水平 $\alpha$ 下的方案变化（有效前沿），证明不是单点结论。

### 国一亮点建议

1. **滞销显式线性化并说明「折价比率」设定的依据**（不同假设下的分配对比），而不是含糊地截断。
2. **预测—优化闭环 + 多情景/鲁棒优化**：不只线性外推；给出「预测误差→收益损失」的定量关系与稳健方案；问题 1 与问题 3 的**收益提升百分比**要算清并解释来源。
3. **轮作/重茬用 0-1 变量严格建模**，给出逐年种植甘特图/热力图，直观展示「豆类轮作 + 不重茬」是如何被满足的。

### 高频失分点

1. **土地约束漏写/适配错误**：把总耕地当单一上限，忽略**分类土地**（每类有各自上限）与作物—土地适配矩阵，导致方案「水稻种在旱地」等不可行解。
2. **轮作/重茬未建模或跨年脱节**：问题 2/3 最易漏「前一年种植决定下一年约束」的递推耦合，只做独立单年。
3. **滞销收益算错 / 风险空谈**：把超额产量按全价计收益；风险部分只用定性文字没有可复算的 CVaR/方差指标。

## 2024 难度与选题提示

| 题 | 核心能力 | 上手难度 | 区分度所在 | 选题建议 |
|---|---|---|---|---|
| **A 板凳龙** | 微分几何/运动学 + 数值求根 + 几何碰撞 | **中高**（门槛最高） | 弦长 vs 弧长、碰撞精确判定、曲率受限调头 | 编程+几何强、能画动图的队选它上限最高；但要写深才有国一，浅做易平庸 |
| **B 质量决策** | 期望成本/决策树 + 抽样检验(OC 曲线) | **中**（模型最标准） | 期望成本不漏项、OC 曲线 α/β 精确、抽样—决策闭环 | 求稳、想拿高且可复制的队首选；模型清晰、评分点显式 |
| **C 种植策略** | 线性/整数规划 + 预测 + 风险 | **中低**（上手最快，易同质化） | 风险建模(CVaR/鲁棒)、预测严谨性、轮作约束完整 | 想快速出结果可选，但**同质严重**，国一要靠问题 3 的风险/稳健深化拉开差距 |

> **直觉**：B 模型最「标准答案化」、性价比高，适合大多数本科队；C 结果好出但易同质；A 上限最高但门槛与几何细节多。建议按「编程/几何能力 vs 稳健性偏好」选。
